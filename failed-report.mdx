## Overview

**Sidebar path:** Dashboards → OPERATING → CX & Reviews → **Failures** tab (`/dashboard/cx`)

The **CX Reasons Report** answers "what's blocking orders" so the team can fix the top objections and convert more. It is the default tab of CX & Reviews; the other tab is **Reviews**.

## Filters

| Control | Description |
| --- | --- |
| **Refresh** | Reloads the report. |

## What the screen shows

### KPI cards

| Card | Meaning |
| --- | --- |
| **Total Failures** | Failed orders in scope. |
| **Vendor Initiated** | Failures caused by vendors (count and %). |
| **Customer Initiated** | Failures or cancellations by customers. |
| **Abandoned Carts** | Leads that started but did not become orders. |

### Actionable Insights

Auto-generated hints, for example "failures due to communication issues — improve customer follow-up" or "vendor-initiated failures exceed customer-initiated — review vendor training".

### Panels

| Panel | Contents |
| --- | --- |
| **Failure Categories** | Communication, Availability, Trust Issues, Price Issues, Device Issues, Lost to Competitor. |
| **Vendor vs Customer Failures** | Donut with the total in the centre: Vendor Failed, Customer Cancelled and Cashkr Failed, each with count and %. |
| **Top Cancellation Reasons** | Reason text with vendor vs customer counts. |
| **Daily Failures Trend** | Failures per day. |
| **Detailed Status Breakdown** | Status, Count, % of Total — for example NotReachableOrResponding, CustomerOutOfTownArea, BetterPriceElsewhere, NotInterestedInSelling, WasJustChecking, AreaNotServicable, SoldDeviceElsewhere, WrongModel, CloneDevice, IncorrectInfo, RescheduledMultipleTimes, FinancePhone, RoadSidePickup, RequotePriceNotAccepted, FailedByCustomer. |
| **Abandonment by Stage** | Abandoned leads by stage (for example Initiated, Failed). |

### Fix Strategy

A closing panel lists the recommended focus: address price objections in FAQ and site copy, improve vendor training for common failure scenarios, and add trust signals for "just checking" customers.

## Actions

The report is read-only.

<Callout kind="tip">
Use **Detailed Status Breakdown** to pick the top three reasons each week, then track whether their share falls in the next period.
</Callout>
