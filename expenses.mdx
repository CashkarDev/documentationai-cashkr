## Overview

**Sidebar path:** Finance → Expenses (`/finance/expenses`)

The Expenses page lets admins record, track and manage all business expenses in one place. Expenses can be added one at a time or uploaded in bulk from an Excel/CSV file.

---

## What the screen shows

### Summary cards

| Card | What it shows |
| --- | --- |
| **Total Expenses** | Total value of expenses matching the filters |
| **Total Entries** | Number of expense records |
| **Top Category** | Category with the highest total spend |
| **Categories** | Number of categories in use |

Card values update with the active date range, category and payment method filters.

### Expenses table

| Column | Description |
| --- | --- |
| **Date** | Date the expense was incurred |
| **Title** | Expense title, with the description shown below it |
| **Category** | Category badge (e.g. Rent, Bills, Salaries) |
| **Amount** | Expense amount |
| **Payment** | Payment method used |
| **Created By** | Admin who logged the expense |
| **Recurring** | Whether the expense is recurring (- if not) |
| **Actions** | **⋯** menu with **Edit** and **Delete** |

### Category Breakdown

Below the table, the **Category Breakdown** panel shows the total spend per category for the filtered period.

---

## Filters & search

| Control | Options / behaviour |
| --- | --- |
| **Pick a date range** | Filter by expense date |
| **Search** | Search title or description (press **Enter**) |
| **Category** | All Categories, Salaries, Rent, Bills, Costs, Marketing, Operations, Miscellaneous |
| **Payment method** | All Methods, Cash, UPI, Bank Transfer, Card, Cheque |
| **Export** | Download the filtered expense list |
| **Refresh** (icon, top right) | Reload the data |

---

## Actions

### Add Expense

Click **+ Add Expense** to open the form:

| Field | Description |
| --- | --- |
| **Title** \* | e.g. `Office Rent - January` |
| **Amount (INR)** \* | Expense amount |
| **Date** \* | Defaults to today |
| **Category** \* | One of the categories listed above |
| **Payment Method** | Cash, UPI, Bank Transfer, Card or Cheque |
| **Description** | Optional notes |
| **Transaction ID** \* | Bank transaction ID / reference number |
| **Receipt / Invoice** | Upload an image of the receipt or invoice |

Click **Add Expense** to save, or **Cancel** to close.

### Upload Excel (bulk import)

Click **Upload Excel** to open **Upload Expenses**:

- Drag and drop or click to upload a **.xlsx**, **.xls** or **.csv** file.
- Use **Download Template** to get the correct format.
- **Required columns:** Title, Amount, Category, Date
- **Optional columns:** Payment Method, Description, Recurring
- **Categories:** Salaries, Rent, Bills, Costs, Marketing, Operations, Miscellaneous

Click **Upload** to import.

<Callout kind="alert">
Category values in the file must match the allowed categories exactly, otherwise rows may fail to import.
</Callout>

### Edit / Delete

Use the **⋯** menu on a row to **Edit** the expense or **Delete** it. Deleted expenses are permanently removed and no longer appear in reports.

---

## Recurring expenses

Expenses marked **Recurring** (set via the Excel upload's Recurring column) are regular costs such as rent, salaries or subscriptions. Review them periodically to make sure they are still active and the amounts are current.

---

## Admin responsibilities

- Log expenses promptly and with the correct category.
- Always record the transaction ID and attach the receipt where available.
- Review the **Top Category** card and Category Breakdown to spot the highest spend areas.
- Export expense data monthly for reconciliation.

---

## Connections to other modules

- **Cash In Hand** — cash expenses are reflected in cash tracking.
- **Reports** — expense data feeds Profit & Loss and Money Flow reports.

<Callout kind="info">
Expenses here are internal business costs only. They are not linked to vendor orders or device transactions.
</Callout>
