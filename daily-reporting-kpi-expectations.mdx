## Overview

Daily reporting sets clear expectations for **Inbound Sales**, **Follow-Up**, **CX**, **Business Development (BD)**, **Operations (Ops)**, and **Management** teams at Cashkr.

This SOP defines:

- What must be reported daily by each team
- Which KPIs each team owns and is accountable for
- Expected benchmarks for performance and discipline

Daily reporting matters because it enforces ownership, keeps everyone aligned on real numbers, and directly supports higher lead to order conversion.

<Callout kind="info">

If it is not reported daily, it is not being managed.

</Callout>

## Purpose of daily reporting

Daily reporting exists to:

- Create visibility into real performance
- Identify issues before they become losses
- Enforce ownership at individual and team level
- Improve lead to order conversion consistently
- Enable fast corrective action

## Why daily reporting matters at Cashkr

Cashkr operates on **high-intent leads** and **time-sensitive pickups**. Daily reporting helps answer:

- Are leads being called on time?
- Are callbacks respected?
- Are orders being created?
- Are coverage or vendor issues blocking conversion?
- Which cities or agents are underperforming today (not next week)?

## Daily reporting ownership

| Team       | Reporting owner      | Primary purpose                   |
| ---------- | -------------------- | --------------------------------- |
| Sales      | Sales lead or manager | Conversion and calling discipline |
| CX         | CX lead              | Complaint and failure control     |
| BD         | BD or area manager   | Coverage and demand gaps          |
| Ops        | Ops lead             | SLA and pickup reliability        |
| Management | Ops or data lead     | Overall business health           |

## Team-wise daily reporting

<Tabs>

<Tab title="Sales" icon="bar-chart">

### Daily metrics to report

- Total leads assigned
- Calls attempted
- Connected calls
- Not connected calls
- Callbacks scheduled
- Callbacks completed
- Orders created
- High-end orders created

### KPI expectations

| KPI                     | Expected                              |
| ----------------------- | ------------------------------------- |
| First call TAT          | Same day                              |
| Connected %             | ≥ 40–50%                              |
| Callback adherence      | ≥ 90%                                 |
| Lead → Order conversion | City-dependent (targeted improvement) |
| High-end conversion     | Higher than normal leads              |

</Tab>

<Tab title="CX" icon="users">

### Daily metrics to track

- Orders tracked
- Complaints received
- Complaints resolved
- Open complaints
- Failed orders
- Failure reasons
- Pickup delay cases

### KPI expectations

| KPI                      | Expected        |
| ------------------------ | --------------- |
| Complaint resolution     | Same or next day |
| Repeat complaints        | Minimal         |
| Pickup delay escalations | Tracked daily   |
| Customer satisfaction    | Improving trend |

</Tab>

<Tab title="BD / Area Management" icon="folder">

### Daily metrics to track

- Leads from non-serviceable areas
- Pincodes with vendor shortage
- Orders blocked due to coverage
- High-demand new areas identified

### KPI expectations

| KPI                    | Expected               |
| ---------------------- | ---------------------- |
| Non-serviceable lead % | Downward trend         |
| Vendor coverage gaps   | Flagged same day       |
| Expansion inputs       | Weekly actionable list |

</Tab>

<Tab title="Operations" icon="settings">

### Daily metrics to track

- Orders assigned
- Pickups completed
- SLA violations
- Reassignments
- Vendor no-shows

### KPI expectations

| KPI                 | Expected        |
| ------------------- | --------------- |
| Pickup success rate | High and stable |
| SLA violations      | Below threshold |
| Reassignments       | Minimal         |
| Vendor response     | Same day        |

</Tab>

<Tab title="Management" icon="monitor">

### Daily metrics to review

Management focuses on **signals, not noise**. The daily snapshot includes:

- Total leads vs orders
- Conversion % (overall and city-wise)
- SLA health
- Coverage issues
- Major escalations

Management uses this to:

- Trigger training
- Push BD expansion
- Correct Ops bottlenecks
- Optimize sales effort

</Tab>

</Tabs>

## Red flags that require immediate action

<Callout kind="alert">

Escalate these red flags on the same day:

- Missed callbacks
- Zero orders from high-end leads
- High non-serviceable closures
- Spike in pickup delays
- Sharp drop in connected %

</Callout>

## Reporting discipline rules

<Callout kind="alert">

Reporting discipline rules (non-negotiable):

- Submit reports daily
- Do not inflate or fake numbers
- Add notes to explain anomalies
- Match data with the Admin Panel
- Expect action for repeated non-reporting

</Callout>

## How daily reporting improves conversion

Daily reporting enables:

- Faster follow-ups
- Better agent coaching
- Reduced lead leakage
- Improved coverage planning
- SLA correction before churn

> Conversion improves when yesterday’s mistake is fixed today.
