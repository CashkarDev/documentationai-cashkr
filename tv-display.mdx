## Overview

**Sidebar path:** System → ADMIN → **Live Ticker** (`/ticker`)

The Live Ticker is a full-screen, TV-friendly display of today's headline numbers. It opens without the admin sidebar and is designed to run on an office screen all day.

## What the screen shows

| Area | Description |
| --- | --- |
| **Header** | Cashkr logo, the current date (for example *Monday, 12 October 2026*) and a live IST clock. |
| **Total Users** | Large flip-counter digits showing the total customer count. |
| **Received** | Flip counter for orders received today. |
| **Completed** | Flip counter for orders completed today. |
| **Converted** | Flip counter for leads converted to orders today. |
| **LIVE strip** | A scrolling ticker along the bottom, marked with a red **LIVE** badge. |

### Live strip metrics

| Label | Meaning |
| --- | --- |
| **USERS** | Total users |
| **ORD·RCVD** | Orders received |
| **ORD·CMPL** | Orders completed |
| **ORD·CNV** | Orders converted from leads |
| **PHONE / TABLET / LAPTOP / MAC** | Orders by device category |
| **NEW·VENDORS** | Vendors onboarded |
| **CMPL%** | Completion rate |
| **CNV%** | Conversion rate |
| **MARKET** | Market status (for example *OPEN*) |

## Actions

| Control | What it does |
| --- | --- |
| **Enter fullscreen** (expand icon, top-right) | Switches the browser to full-screen mode for TV use. |

<Callout kind="tip">
Open the ticker on the TV's browser, click **Enter fullscreen**, and leave it running. The numbers match the **Overview** dashboard for today.
</Callout>

<Callout kind="info">
The ticker is display-only. It has no filters or editable data.
</Callout>
