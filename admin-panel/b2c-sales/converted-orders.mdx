## Overview

Open **B2C Sales → Outcomes → Converted Orders** (breadcrumb *Dashboard / B2C Sales / Converted Orders*). This list shows every lead that was converted into an order, so you can track what happened to it after conversion. The total count is shown at the top right (for example *364 orders*).

## What the table shows

| Column | Description |
| --- | --- |
| **Converted At** | When the lead was converted to an order |
| **Model** | Device model |
| **Customer** | Customer name and order token (with copy button) |
| **City** | Pickup city |
| **Type** | Device category badge |
| **Quoted Price** | Quoted price (₹) |
| **Vendor** | Vendor handling the order |
| **Status** | Current order status, for example Completed, Pickup Delayed, Failed By Customer, Failed By Vendor |

The list is paginated (20 rows per page).

## Filters and search

- **Search by token, name, phone, model...** box with a **Search** button.
- Click **Filters** to open:
  - **All Statuses** — Generated, Assigned, In Progress, Completed, Failed
  - **All Types** — Mobile, Laptop, Tablet, Mac, Watch, Desktop, TV, Camera, Console, Drone, Headphone, AC
  - **Clear Filters**

<Callout kind="tip">
  A high share of failed statuses here means leads are being converted before intent is confirmed — review call notes with the team.
</Callout>
