## Overview

The Laptop page (**Laptop Management**, route `/laptop`) is the master catalog for all laptop models available for buyback. It has six tabs: **Models**, **Brands**, **Classes**, **Pricing**, **Credits**, and **Components**. Credits and Components exist only for laptops. Laptop pricing is built from a base price plus component values (processor, RAM, storage) adjusted by the class, so laptops have no storage/RAM variants.

### Add

Click **Add New Class** ("Create a new pricing model for Laptop devices"). Fill Basic Info (Class Type*, Tier, Credit, Dead Price), then the Warranty, Battery, Screen, Physical, and Accessories tabs, and click **Create Class**. **Export CSV** downloads the classes.

<Tab title="Pricing">

### What you see

The laptop Pricing tab is a **Laptop Pricing Matrix**, not age brackets. Each row is a laptop model with its brand and class, **Base Price**, **Bonus**, and one price column per processor generation (AMD Ryzen 3/5/7/9 and Pro generations, Intel Core i3/i5/i7/i9 4th–14th Gen, Intel Core Ultra 7, Ryzen AI 7/9 300 Series).

The matrix header shows the formula used for each cell:

```text
(Base + Processor + 8GB RAM [₹500] + 256GB SSD [₹900] + S2 + A2 + A3) − W3% − B2%
```

Standard scenario: above 11 months (W3), B2, 13–14" screen (S2), and A2 + A3 accessories present. Percentages are applied on the accumulated total. The RAM and SSD values come from the Components tab.

### Controls

- **BuyBack bonus** switch and **Bulk bonus**, shared with other categories.
- **Bonus** filter (Any), **Search laptops… (press Enter)**, and **Refresh**.
- **Bonus** cells show the model bonus or **+ Add**.

- **Device Type** — Laptop
- **Price Range** — For example ₹1 – ₹10,000
- **Credit Amount**

The **Filters** panel has **Search… (press Enter)** and **Device Type** (Laptop).

### Add

<Steps>
  <Step title="Open the add credit algorithm form" icon="plus">

  Click **Add Credit Algorithm**.

  </Step>
  <Step title="Define the price range">

  Set the minimum and maximum INR values for the bracket.

  </Step>
  <Step title="Set credit amount">

  Enter the **Credit Amount** for a laptop order in this range.

  </Step>
  <Step title="Save the algorithm">

  Save so it applies to future laptop buyback orders.

  </Step>
</Steps>

### Edit and delete

Use the row actions to edit the price range or credit amount, or to delete a bracket.

<Callout kind="alert">

Deleting a credit algorithm can leave price ranges uncovered. After deletion, check that every price range maps to exactly one credit rule.

</Callout>

### How components affect laptop pricing

During evaluation, the system takes the laptop's base price, adds the values for its processor, RAM, storage (and graphics card where applicable) from this tab, then applies the class adjustments. Keep component prices current, because they directly change every cell in the Pricing matrix and every laptop offer.
