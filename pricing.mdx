## Overview

**Sidebar path:** Dashboards → OPERATING → Inventory & Pricing → **Pricing** tab

**Pricing & Models** helps identify pricing gaps, model health issues and conversion problems caused by quotes or requotes.

## Filters

| Control | Description |
| --- | --- |
| **Date range** | Defaults to the last 30 days. |
| **Refresh** | Reloads the data. |
| **AI Analyst Insight → Analyze Data** | Generates an AI summary. |

## What the screen shows

### KPI cards

Leads, Orders, Completed, Conversion, Requotes, Avg Drop, High Drop, Rev Lost.

### Pricing Health

A score with a *Critical* → *Healthy* bar summarising CVR, Drop, High Drop and catalog utilisation.

### Panels

| Panel | Contents |
| --- | --- |
| **Conversion Analysis** | Total Leads, Orders Won, Completed, Conversion Rate, Lost Leads. |
| **Price Drop Analysis** | Avg Drop, High Drop Share (drops over 20%), Requotes, Revenue Lost. |
| **Catalog Health** | Total Models, Utilization, and models with leads vs total per category (Mobile, Laptop, Tablet). |
| **Risk Indicators** | Condition downgrades at pickup — Body Condition (B1 → B2) and Screen Condition (S0 → S1) — count and %. |
| **Daily Lead / Order Trend** | Leads, orders and requotes per day. |
| **Device Type Performance** | Type, catalog size, Leads, Orders, Conv %, Drop %, Avg Price. |
| **By Price Bracket** | Conversion per bracket: under ₹5K, ₹5K–10K, ₹10K–20K, ₹20K–50K, ₹50K+. |
| **Top Converting Models** | Models with the best conversion. |

### Biggest Pricing Problems

Switch between four tables:

| Tab | Shows |
| --- | --- |
| **All Models** | Sorted by most lost leads: Model, Type, Leads, Orders, Lost, Conv %, Requotes, Avg Price, Drop %. |
| **Brand Analysis** | The same metrics by brand. |
| **City Breakdown** | The same metrics by city. |
| **Requote Reasons** | Why vendors changed the price. |

A **Definitions** section at the bottom explains each metric.

## Actions

The tab is read-only. To change device prices, use the **Devices** catalog (Phone, Tablet, Laptop and so on).

<Callout kind="tip">
Models with many lost leads and a high **Drop %** usually have an over-quoted base price. Review them with the pricing team before changing catalog values.
</Callout>
