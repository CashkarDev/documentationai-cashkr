title: Categories
---
**What It Shows:**

- Overview of categories used to organize articles, including names and associated content.

- create new entries for adding new categories.

- search and filter button to searching and filtering categories.

**User Flow:**

- Navigate to the Content Manager and select the “Categories” collection type. Search or filter categories by name, add new ones with “Create new entry,” update details, or delete by confirming removal.

**System Logic:**

- Category updates reflect in article filtering immediately. Deleted categories are removed from articles.

**Connections:**

- Integrated with the website’s Article. Connected to the Content Manager for article categorization.

- If categories of article changes here then it will be reflected in website article also.
