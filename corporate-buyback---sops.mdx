## Overview

Corporate Buyback on the Cashkr website lets users submit a request form so the admin team can follow up on their buyback query.

## Flow

<Steps>

<Step title="Open the Corporate Buyback page" icon="monitor">

The user navigates to the Corporate Buyback page on the Cashkr website.

</Step>

<Step title="Fill in the request form" icon="edit">

The user enters all required details in the Corporate Buyback form.

</Step>

<Step title="Submit the form" icon="upload">

The user submits the completed form to create a corporate buyback request.

</Step>

</Steps>

<Callout kind="info">

After the form is submitted, an admin reviews the request and follows up with the user based on the provided contact details.

</Callout>

## Form fields

The Corporate Buyback request form includes these fields and typical example values:

- **Name** — for example, Rahul Sharma
- **Job Title** — for example, IT Manager
- **Email** — for example, yourname@company.com
- **Mobile Number** — for example, +91 9876543210
- **State** — for example, Maharashtra
- **City/District** — for example, Mumbai
- **Pincode** — for example, 400001
- **Subject** — for example, Corporate Device Buyback
- **Buyback Details**
