## Overview

**Sidebar path:** Dashboards → LEADERSHIP → **Leadership** (`/dashboard/leadership`)

Leadership is the one-screen summary for founders and leads: *"The headline numbers, with drill-downs to the full reports."*

## Filters

| Control | Description |
| --- | --- |
| **Week / Month / Quarter** | Period toggle. Cards compare against the previous period of the same length. |
| **Refresh** | Reloads the numbers. |

## What the screen shows

### Headline cards

| Card | Meaning |
| --- | --- |
| **Revenue** | B2C commission + B2C buyback profit + B2B buyback profit. |
| **Completed pickups** | Orders that reached Completed in the period, with % change vs previous. |
| **Failure rate** | Failed ÷ resolved orders; the change shown is in failed orders. |
| **Paid vs organic** | % of leads from paid channels, with paid, organic and unattributed counts. |

### Revenue by engine

Separate cards for **B2C commission**, **B2C buyback profit** and **B2B buyback profit**.

### Channel mix

| Column | Meaning |
| --- | --- |
| **Channel** | Paid or Organic. |
| **Leads** | Leads in the period. |
| **Completed** | Completed orders. |
| **Completion** | Completed ÷ leads. |
| **Revenue** | Revenue from that channel group. |

A note shows the % of leads with no attribution, which are excluded from the split.

## Actions — drill-down links

| Link | Opens |
| --- | --- |
| **Full CEO report** | Executive dashboard, CEO tab |
| **CFO report** | Executive dashboard (switch to the CFO tab) |
| **Operations / SLA** | Operations / SLA dashboard |
| **Channel attribution** | Channel Attribution page (see below) |

## Channel Attribution

`/dashboard/channel-attribution` — reached from the Leadership link (it is not listed in the sidebar). It shows per-channel leads, completion % and revenue.

| Block | Contents |
| --- | --- |
| **Date range** | Defaults to the last 30 days. |
| **Paid channels / Organic / direct** | Leads, Completion, Revenue for each group. |
| **All channels** | Channel, Type (Paid/Organic), Leads, Completion, Avg quote, Avg order, Revenue. |
| **Daily leads by top channel** | Line chart of the top channels. |
| **Top campaigns (by leads)** | Campaign, Channel, Leads, Completion, Revenue. |

<Callout kind="tip">
Use Leadership for the weekly review, then open the Executive report only when a headline number needs explaining.
</Callout>
