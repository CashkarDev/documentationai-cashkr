## Manage watch devices

The Watch page (**Watch Management**, route `/watch`) in **Admin Panel → Devices** controls every smartwatch model available for buyback. It has four tabs: **Models**, **Brands**, **Classes**, and **Pricing**, using the shared device layout described on the [Phone](/phone) page. Watch variants are based on **case size** (mm) instead of storage/RAM.

Watch devices use the `mobilePriceEvaluation` strategy with these deduction groups: **age** `W1`–`W4`, **body** `B1`–`B4`, **screen** `S1`–`S4`, **physical** `P4` (Display Changed), **technical faults** `T1`–`T10`, and **accessories** `A1`–`A4`.

<Callout kind="info">

Watch devices do not support additions. Pricing is calculated only from the base price and the deductions stored in the assigned class.

</Callout>

<Tabs>
  <Tab title="Models" icon="watch">

  ### What you see

  The Models tab lists watch models, 20 per page.

  | Column | Description |
  | --- | --- |
  | Checkbox / expand | Select rows; expand to see case-size variants |
  | Model | Image, model name with case size in brackets, and brand • series |
  | Code | Unique code, for example `AWAT100034` |
  | Price | Base buyback price |
  | Class | Assigned class |
  | Variants | Number of variants, or "-" when there are none |
  | Actions | Row menu |

  ### Search and filters

  - **Search models…** with **Filter**, and a refresh icon.
  - **All Brands** — Apple, Google, OnePlus, Samsung.

  ### Row and bulk actions

  Row menu: **Edit Model**, **Add Variant**, **View SEO**, **Duplicate**, **Delete**. Selecting rows shows **Update Class**, **Regenerate SEO**, and **Clear Selection**.

  ### Add

  <Steps>
    <Step title="Open the form" icon="plus">

    Click **Add Model** ("Add a new watch model").

    </Step>
    <Step title="Basic Info" icon="edit">

    - **Brand***
    - **Model Name*** — for example Apple Watch Series 9.
    - **Series (Optional)** — for example SE, Ultra.
    - **Image** — URL or Upload.
    - **Case Size (mm)*** — Dial/case size in millimetres, for example 41 or 45.

    </Step>
    <Step title="URL & Code and SEO" icon="link">

    Generate or enter **Base URL** and **Model Code**. Use **Auto-Generate SEO** or fill Page Description, H1 Heading, Variant Title, and Variant Description.

    </Step>
    <Step title="Pricing" icon="bar-chart">

    Enter **Base Price (₹)***, choose **Pricing Class***, and optionally use **Bulk Add Variants** to add other case sizes.

    </Step>
    <Step title="Save" icon="check-circle">

    Click **Create Model**.

    </Step>
  </Steps>

  <Callout kind="alert">

  If the model is already referenced in pricing, reporting, or transaction history, think carefully before deleting it.

  </Callout>

  </Tab>
  <Tab title="Brands" icon="bookmark">

  ### What you see

  Watch brands: **Apple**, **Google**, **OnePlus**, and **Samsung**. The table shows Brand ID, Brand Name, Device Type, Brand Link, Brand Image, and Title.

  Search, Filters, **Add New Product** (Add New Brand dialog), and Brand Details (Edit, Delete) work as on the Phone Brands tab. Set **Device Type** to Watch.

  <Callout kind="alert">

  Do not delete a brand that is still assigned to watch models. Reassign dependent models first.

  </Callout>

  </Tab>
  <Tab title="Classes" icon="settings">

  ### What you see

  The **Watch Classes** table has five classes (A–E) with ID, Class Type, Credit, Dead Price, Tier, and these codes:

  | Group | Codes | Options |
  | --- | --- | --- |
  | Warranty | `W1`–`W4` | 0–3 months, 3–6 months, 6 to 11 months, above 11 months |
  | Body | `B1`–`B4` | Scratchless, Good, Average, Below Average |
  | Screen | `S1`–`S4` | Scratches on Screen, Cracked Screen, Faulty Screen, Screen Not Usable |
  | Physical | `P4` | Display Changed |
  | Technical | `T1`–`T10` | Restart, Sensors, Microphone, Speaker, Bluetooth, Wifi, Vibration, Charging, Battery/Service, Motherboard problems |
  | Accessories | `A1`–`A4` | Charger, Strap, Box, Bill |

  ### Add

  <Steps>
    <Step title="Open the form" icon="plus">

    Click **Add New Class** ("Create a new pricing model for Watch devices"). Tabs: Basic Info, Warranty, Body, Screen, Physical, Technical, Accessories.

    </Step>
    <Step title="Basic Info" icon="bar-chart">

    Enter **Class Type***, **Tier**, **Credit**, and **Dead Price** (the payout floor).

    </Step>
    <Step title="Deductions" icon="settings">

    Fill each tab. Each field accepts a flat amount or a percentage ("e.g. 500 or 10%"). Technical faults are cumulative when several apply.

    </Step>
    <Step title="Save the class" icon="check-circle">

    Click **Create Class**.

    </Step>
  </Steps>

  Use the row menu to **Edit** or **Delete**, and **Export CSV** to review values in bulk.

  <Callout kind="alert">

  Do not delete a class that is still attached to active watch models. Reassign the models first.

  </Callout>

  </Tab>
  <Tab title="Pricing" icon="bar-chart">

  ### What you see

  The Watch Pricing tab uses the shared layout: Pricing Overview, BuyBack bonus and Bulk bonus, Filters, All Brands, search, Export, and Import. Each row shows Model, Specs (case size), Class (dropdown), Base Price (✎), Bonus, and the **3-6 Months**, **6-11 Months**, and **11+ Months** prices with % change. The row menu has **Price History**. Select rows to use **Update Price** or **Update Class**.

  ### Deduction groups

  | Deduction group | Codes | Notes |
  | --- | --- | --- |
  | Age | `W1`–`W4` | One age deduction applies |
  | Body | `B1`–`B4` | One body deduction applies |
  | Screen | `S1`–`S4` | One screen deduction applies |
  | Physical | `P4` | Display changed |
  | Technical faults | `T1`–`T10` | Sum all applicable technical fault deductions |
  | Accessories | `A1`–`A4` | Deduction for each missing accessory |

  ### Pricing formula

  ```text
  finalPrice = basePrice - age(W) - body(B) - screen(S) - physical(P) - technical(T) - missingAccessories(A)
  finalPrice = max(finalPrice, deadPrice)
  ```

  Change the model's base price when only one device needs a new starting price. Change the class when deduction amounts need to change for every model using it.

  </Tab>
