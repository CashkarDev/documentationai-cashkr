## Notes on connections

<Callout kind="info">

Connections describe which other Cashkr surfaces share data or behavior with a given Customer App feature. For example, order status and pickup slots flow from the Admin Panel and Vendor App, while profile and auth details are shared with the Customer Website.

</Callout>

Most Customer App features rely on a common backend, so changes in Admin Panel configuration or Vendor App operations reflect directly in the app experience. When you design or modify flows, always consider how Website, Admin Panel, Vendor App, and Cashkr Wallet consume or update the same data.
