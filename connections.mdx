## Overview

The Connections page lets admins configure third-party analytics integrations and rebuild the device search index after catalog changes.

Open it from **System → Admin → Connections** in the left sidebar (route `/dashboard/settings`).

## What the screen shows

| Section | Description |
| --- | --- |
| Google Analytics 4 | "Connect for real-time traffic and event tracking." Shows a **Connected** / **Not Connected** badge and a **Configure Integration** button |
| Google Search Console | "Connect for SEO keywords, impressions and ranking data." Shows a status badge and a **Configure Integration** button |
| Update Search Index | Rebuilds the device search index after adding, updating or removing models |

## Third-party integrations

Clicking **Configure Integration** expands an inline form inside the card. Each form has **Cancel** and **Save Configuration** buttons.

### Google Analytics 4

GA4 tracks real-time website and app traffic, device searches, order events and other platform interactions. Once connected, data is collected automatically — no manual sync is needed.

| Field | Description |
| --- | --- |
| Property ID | Numeric GA4 property ID (e.g. `345678901`) |
| Service Account Email | Email of the Google Cloud service account with access to the property |
| Private Key (JSON) | The `private_key` value from the service account JSON (masked, with a show/hide icon) |

Use GA4 data to monitor traffic, track behaviour through device evaluation and checkout, measure search-to-order conversion, find drop-off points and analyse traffic sources. Unserviced-pincode failed checks shown in **Areas & Zones → Unserviced** also come from GA4.

### Google Search Console

Search Console provides SEO keywords, impressions and ranking data.

| Field | Description |
| --- | --- |
| Site URL | The property URL, e.g. `https://www.example.com` or a `sc-domain:` property |
| Service Account Email | Email of the service account added as a user on the Search Console property |
| Private Key (JSON) | The `private_key` value from the service account JSON (masked) |

<Steps>
<Step title="Open the form" icon="settings" title-type="p">
Click **Configure Integration** on the GA4 or Search Console card.
</Step>
<Step title="Enter credentials" icon="key" title-type="p">
Fill in the property identifier, service account email and private key.
</Step>
<Step title="Save" icon="save" title-type="p">
Click **Save Configuration**. The badge changes to **Connected** once the credentials are valid. Click **Cancel** to close without saving.
</Step>
</Steps>

<Callout kind="alert">
Service account keys are secrets. Never share them in chat, tickets or screenshots.
</Callout>

## Update search index

**Update Search Index** re-syncs all device types into the search table. It takes about 1–3 seconds.

Run it:

- After adding, editing or deleting device models in the Devices catalog
- After bulk importing device data via Excel
- When customers or vendors report that new devices are missing from search

<Callout kind="alert">
Always run Update Search Index after any device catalog change. Otherwise newly added or updated models may not appear in customer search results, even when they were added correctly.
</Callout>

## Admin responsibilities

- Keep GA4 and Search Console **Connected**; a Not Connected badge means no data is flowing for that service.
- Reconfigure an integration immediately if credentials expire or are rotated.
- Run **Update Search Index** as the final step after every catalog update.

## Connections to other modules

- **Devices catalog** — Run Update Search Index after model changes.
- **Coupons** and **Orders** — GA4 tracks coupon and order events used in analytics reports.
- **Areas & Zones** — GA4 failed pincode checks feed the Unserviced tab.
