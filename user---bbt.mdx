## User - BBT overview

Manage BigboldTech team member accounts in Strapi, including their email, role, and access levels, from the User collection in the Content Manager.

## What the page shows

The User collection view displays:

- A list of team users with details such as email, role, and access levels.
- A search and filter bar to quickly find users by email or role.
- An action to create a new user entry.
- A settings icon to configure how the user list view is displayed.

## Main user flow

<Steps>
  <Step title="Open the User collection" icon="folder">
    Access the Content Manager from the Strapi sidebar, then select the <kbd>User</kbd> collection type to view all existing team users.
  </Step>

  <Step title="Search and filter users" icon="search">
    Use the search and filter controls to narrow users by email address or role so you can quickly locate specific accounts.
  </Step>

  <Step title="Create a new user" icon="plus">
    Select <kbd>Create new entry</kbd> to add a new user, then enter their email, assign a role, configure access levels, and save the entry.
  </Step>

  <Step title="Update an existing user" icon="edit">
    Open an existing user entry, adjust profile details such as role or access levels, and save your changes to update their account.
  </Step>

  <Step title="Delete a user" icon="trash">
    Choose a user to remove, trigger the delete action, and confirm the removal when prompted to deactivate their account.
  </Step>
</Steps>

<Callout kind="alert">

User changes affect login access immediately. When you delete a user, the system deactivates the account, and Strapi authentication will no longer allow that user to log in.

</Callout>

## UI elements

Use these controls on the User collection page:

- **Search and filter bar** – Search users by email and apply filters such as role to refine the list.
- **Create new entry button** – Add a new user record with email, role, and access levels.
- **View settings icon** – Configure how the user list is displayed, such as visible columns and layout preferences.

## System logic and connections

Strapi applies all user profile changes in real time, so updates to roles or access levels immediately impact what a user can access after their next interaction. The User collection integrates with Strapi authentication to control who can log in and which areas of the system they can reach.
