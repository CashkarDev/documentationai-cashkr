## Adding a new tool

When you add a new sales tool, capture these fields in the table:

- **Tools**: The exact name of the tool as used in the team.
- **Use Case**: A short phrase describing what the tool is for, written from a sales perspective.
- **Example**: One clear, practical example of when and how a sales rep would use the tool.

Aim for concise entries that help someone quickly decide which tool to open for a specific task.
