## Overview

**Sidebar:** Inventory & Catalog → Stock → **All Inventory** (`/inventory/all`). The page heading reads **Unified Inventory — Manage B2C, Excess, and B2B stock**.

Use this screen to see all devices that have been completed by internal vendors, received into stock and are available for resale, and to sell them to dealers with **Punch Sale**.

<Callout kind="info" collapsed="false">
  Only devices completed through internal vendor orders appear in All Inventory. Externally completed vendor orders do not show in this module.
</Callout>

The screen has two tabs:

| Tab | Purpose |
| --- | --- |
| **Inventory Lists** | Devices in stock, with Punch Sale. |
| **Customers (Dealers)** | Customers and dealers you can sell stock to. |

---

## Inventory sources

<Tabs>
  <Tab title="B2C In-house" icon="home">
    **B2C In-house** covers devices completed by in-house B2C vendors — devices purchased from individual customers through B2C operations and processed by the internal vendor network.
  </Tab>

  <Tab title="B2C Excess" icon="package">
    **B2C Excess** tracks excess stock from B2C operations — devices that remain in stock after B2C purchase and processing.
  </Tab>

  <Tab title="B2B Buybacks" icon="briefcase">
    **B2B Buybacks** includes devices received through corporate B2B buyback orders, typically in bulk from business clients.
  </Tab>
</Tabs>

## Inventory Lists

### Filters and controls

| Control | Description |
| --- | --- |
| **Search** | Device name or serial number — press <kbd>Enter</kbd> to apply. |
| **Source** | All Sources, B2C In-house, B2C Excess, B2B Buybacks. |
| **Show Old Inventory** | Checkbox to include older stock no longer in active circulation — useful for tracing history or reconciling past sales. |
| **Export** | Downloads the current filtered list. |
| **Refresh** (top right) | Reloads the latest inventory data. |

### Table columns

| Column | Description |
| --- | --- |
| Checkbox | Select devices for Punch Sale. |
| Date | Date the device was added to inventory. |
| Device | Device name and model. |
| Spec / Condition | Chips for RAM, storage and other variant details. |
| Serial | Serial number / IMEI. |
| Source | B2C In-house, B2C Excess or B2B Buybacks badge. |
| Price | Cost price of the device. |

The list is paginated (20 per page) with Previous / Next.

### How devices enter inventory

Devices move into All Inventory automatically when an internal vendor completes an order. No manual entry is required.

```plaintext
Internal vendor completes order
        ↓
Device added to All Inventory
        ↓
Source tagged (B2C In-house / B2C Excess / B2B Buybacks)
```

## Punch Sale

Use **Punch Sale** to sell one or more devices from inventory to a customer or dealer.

<Callout kind="tip" collapsed="false">
  Before you punch a sale, confirm the device details and source are correct, the buyer exists in **Customers (Dealers)** (or you are ready to add them), and you know the selling price, amount received and payment method.
</Callout>

<Steps>
  <Step title="Select device rows" icon="check-square" title-type="p">
    Tick the checkbox of each device to sell. A **Punch Sale (n)** button appears at the top right showing how many are selected.
  </Step>

  <Step title="Click Punch Sale" icon="shopping-cart" title-type="p">
    The **Punch Sale** dialog opens: "Select a customer to sell n items to."
  </Step>

  <Step title="Select the customer" icon="user" title-type="p">
    Search for an existing customer/dealer, or click **Add New** to create one.
  </Step>

  <Step title="Set selling prices" icon="indian-rupee" title-type="p">
    Each device shows its **Cost**; enter the **Sale Price**. Remove items with the remove icon, or add more devices by name, serial or IMEI. **Total Sale Value** updates automatically.
  </Step>

  <Step title="Payment details" icon="wallet" title-type="p">
    - **Amount Received** — enter the amount collected, or click **Full Amount**. Leave empty for fully paid.
    - **Sale Date** — defaults to today; pick an earlier date to backdate the sale.
    - **Payment Method** — e.g. Cash.
  </Step>

  <Step title="Confirm Sale" icon="check-circle" title-type="p">
    Review everything and click **Confirm Sale**. The devices leave inventory and a sale record is created in **Device Sales**.
  </Step>
</Steps>

<Callout kind="alert" collapsed="false">
  Once you confirm a sale, the device is removed from All Inventory and cannot be sold again from this view. Use the Device Sales module to review or audit confirmed sales.
</Callout>

```plaintext
Device selected → Punch Sale → Customer selected → Sale confirmed
        ↓
Device removed from All Inventory
        ↓
New entry created in Device Sales
```

## Customers (Dealers)

A list of buyers you can punch sales to.

| Column | Description |
| --- | --- |
| Name | Customer / dealer name. |
| Phone | Contact number. |
| Email | Email, if provided. |
| Type | **Customer** or **Dealer** badge. |

**Filters:** search by name or phone; type filter (All Types, Customer, Dealer).

**Add Customer** opens **Add New Customer** ("Add a new dealer or customer to the system"):

| Field | Notes |
| --- | --- |
| First Name / Last Name | Buyer name. |
| Phone Number | 10 digits. |
| Type | Customer or Dealer. |
| Email | Optional. |

Click **Save Customer** to add.
