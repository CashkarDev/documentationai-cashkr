## Objective

To plan, launch, and execute engaging giveaways or contests on Cashkr’s social media platforms that boost engagement, attract new followers, and increase app activity.

## Roles and responsibilities

| Role                                   | Responsibility                                             |
| -------------------------------------- | ---------------------------------------------------------- |
| **Social Media Executive**             | Plans contest mechanics, drafts posts, coordinates entries |
| **Graphic Designer**                   | Designs promotional creatives                              |
| **Marketing Manager**                  | Approves concept, prizes, terms & conditions               |
| **Tech/CRM (if reward is app-linked)** | Enables wallet cash or coupon for winners if applicable    |

## Platforms suitable for giveaways

- Instagram
- Facebook
- Threads
- X (Twitter)
- YouTube Community
- LinkedIn (only professional/insight contests)

## Step-by-step process

<Steps>
  <Step title="Step 1: Define Giveaway Goal">
    | Goal Type       | Examples                            |
    | --------------- | ----------------------------------- |
    | Engagement      | Likes, comments, shares             |
    | Follower Growth | Tag friends, follow account         |
    | App Traffic     | Install app, use a feature          |
    | Awareness       | Share experience, post with hashtag |
  </Step>

  <Step title="Step 2: Finalize Format & Mechanics">
    | Type          | Example                             |
    | ------------- | ----------------------------------- |
    | Tag & Win     | “Tag 2 friends & follow us to win” |
    | Answer & Win  | “Comment your best phone memory”   |
    | UGC Challenge | “Post a reel with #CashkrChallenge” |
    | App-Based     | “Sell any device this week & win ₹500” |

    Mechanics must include:

    - Clear participation steps
    - Start and end date (typically 3–5 days)
    - Winner count & reward type
    - Platform-specific variation if needed
  </Step>

  <Step title="Step 3: Decide Rewards">
    | Type               | Notes                      |
    | ------------------ | -------------------------- |
    | Wallet Cash        | Easiest and most effective |
    | Coupons / Bonuses  | App-integrated discounts   |
    | Shoutout / Feature | Good for UGC or cultural content |

    Marketing Manager must approve rewards & cost impact.
  </Step>

  <Step title="Step 4: Create Creative & Caption">
    **Creative must include:**

    - Contest Name
    - Key steps (Tag 2 friends, Follow, etc.)
    - Prize & Deadline
    - Cashkr branding

    **Caption Structure:**\
    1️⃣ Hook (Why they should join)\
    2️⃣ Steps to participate\
    3️⃣ Prize details\
    4️⃣ CTA (“Comment now”, “Tag & win”)\
    5️⃣ Hashtags (#CashkrGiveaway, etc.)
  </Step>

  <Step title="Step 5: Post & Promote">
    - Schedule the post via **Robin Reach**
    - Share on:
      - Feed
      - Stories (with countdown or question box)
      - WhatsApp broadcast (if relevant)
    - Pin the post on IG/Facebook during contest period
  </Step>

  <Step title="Step 6: Monitor Entries">
    - Track comments, tags, or UGC submissions
    - Maintain a **Giveaway Tracker Sheet** with:
      - Username
      - Entry time
      - Validity check (followed rules or not)
  </Step>

  <Step title="Step 7: Select & Announce Winners">
    | Method             | Notes                               |
    | ------------------ | ----------------------------------- |
    | Manual Pick        | Use if quality-based (answers, UGC) |
    | Random Picker Tool | Use for tag/comment contests        |
    | App-based          | Pull from CRM if contest is in-app  |

    - Announce via comment + story shoutout
    - DM winners with claim instructions
    - Reward via app (wallet/coupon) or manual transfer
  </Step>

  <Step title="Step 8: Post-Campaign Reporting">
    After 2–3 days of closing:

    | Metric                             | Track                      |
    | ---------------------------------- | -------------------------- |
    | Comments                           | Total received             |
    | Follower growth                    | Net increase               |
    | App activity                       | If linked to in-app action |
    | Cost per lead (if paid promo used) | ROAS comparison            |

    Maintain results in monthly campaign tracker.
  </Step>
</Steps>

## Do’s and Don’ts

| ✅ DO                                 | ❌ DON’T                          |
| ------------------------------------ | -------------------------------- |
| Keep steps super simple              | Add 5+ participation steps       |
| Mention end date & rewards clearly   | Run unannounced contests         |
| Monitor entries daily                | Miss announcing winners          |
| Stay transparent in winner selection | Fake winners or misleading terms |
