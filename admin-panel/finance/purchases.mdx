## Overview

**Sidebar path:** Finance → Records → Purchases (`/finance/purchases`)

**Purchase History** is a read-only record of **All Completed Orders** — every device purchased through completed orders, with its value. Use it to look up a past purchase or export purchase records for accounting. To add a manual purchase, use [Device Purchases](/device-purchases).

---

## What the screen shows

The **All Completed Orders** table (paginated with **Previous** / **Next**):

| Column | Description |
| --- | --- |
| **Date** | Date the order was completed |
| **Type** | Purchase type badge, e.g. **B2C**, **B2B** |
| **Device** | Device name / model |
| **Description** | Specs such as RAM / storage |
| **Serial** | Serial / IMEI number |
| **Vendor** | Vendor who completed the order |
| **Value** | Purchase value of the device |

---

## Filters & search

| Control | Description |
| --- | --- |
| **Search** | Search by device or serial (press **Enter**) |
| **Pick a date range** | Limit records to a date range |
| **Vendor** | **All Vendors** or a specific vendor |
| **Export** | Download the filtered records |

<Callout kind="info">
This screen has no add, edit or delete actions. Corrections are made from Device Purchases or Returns → Purchase Returns.
</Callout>
