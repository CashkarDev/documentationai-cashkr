## Overview

Contact Messages lists enquiries submitted through the Cashkr contact form.

Open it from **System → Admin → Contact Messages** in the left sidebar (route `/contact`).

## Filters & search

The filter bar at the top contains:

| Control | Description |
| --- | --- |
| Search | Free-text search across messages |
| Status | Filter by message status |
| City | Filter by the sender's city |
| From Date / To Date | Limit to a date range |
| Clear | Reset all filters |

## What the screen shows

The **Contact Message** table has these columns:

| Column | Description |
| --- | --- |
| Date | When the message was submitted |
| Full Name | Sender's name |
| Email | Sender's email address |
| Category | Enquiry category selected on the form |

When there are no messages, the table shows only its header row.

<Callout kind="info">
Contact messages contain customer personal data. Reply through approved support channels and do not copy details into other tools.
</Callout>
