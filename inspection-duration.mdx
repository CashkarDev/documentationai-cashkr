## Overview

**Sidebar:** Vendors → Roster → **Inspection Durations** (`/settings/inspection-durations`)

Inspection Durations sets how long an inspection takes for each device type. The screen describes it as "Used to size vendor pickup slots". The same per-device duration is used by the inspection timer: when a vendor starts an inspection in the Out for Pickup flow, a countdown begins, and if it expires the vendor must select a delay reason before completing or failing the order.

## What the screen shows

A single card, **Time per device type** — "Minutes, between 1 and 1440. Device types left blank have no configured duration."

| Column | What it shows |
| --- | --- |
| Device Type | Mobile, Tablet, Laptop, Camera, Headphone, Console, Drone, TV, AC, Desktop, Mac, Watch. |
| Inspection Time (Minutes) | Editable number field (1–1440). Leave blank for no configured duration. |
| Last Updated | Date and time the value was last saved. |
| Actions | **Save** this row (disk icon) and **Reset** to the saved value (undo icon). |

## Editing durations

<Steps>
  <Step title="Open Inspection Durations" icon="timer" title-type="p">

  Go to **Vendors → Roster → Inspection Durations**.

  </Step>
  <Step title="Enter the minutes" icon="pencil" title-type="p">

  Type a value between 1 and 1440 in the device type's field.

  </Step>
  <Step title="Save" icon="save" title-type="p">

  Click the row's save icon to save one device type, or the **Save** button at the top of the card to save all changes. Use the reset icon to discard an unsaved edit.

  </Step>
</Steps>

## How changes take effect

Changes apply to new inspections and slot sizing from the moment they are saved. The value is read when the vendor taps `Inspection Started` in the Vendor App.

## Important notes

<Callout kind="info">

Inspections already in progress keep the duration that was in effect when they started.

</Callout>

<Callout kind="alert">

Very short durations make vendors hit the timer often and pick delay reasons, and make pickup slots too tight. Very long durations reduce how many pickups fit in a vendor's day. Keep values realistic for each device type.

</Callout>
