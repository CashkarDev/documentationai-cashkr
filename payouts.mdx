## Overview

**Sidebar path:** Marketing → Referral Payouts (`/referral-payouts`)

The Referral Payouts page lists every withdrawal request customers raise from their referral wallet in the customer app. Admins transfer the money manually to the customer's UPI ID and record the result so wallets stay in sync with actual payouts.

Header buttons: **Export CSV** and **Refresh**.

## Status tabs

**All**, **Pending**, **Approved**, **Processing**, **Completed**, **Rejected**, **Failed** — each with a count badge.

## Table columns

| Column | What it shows |
| --- | --- |
| **Customer** | Customer name, phone and customer ID. The filter icon next to the name shows only that customer's payouts. |
| **Amount** | Amount requested (sortable). |
| **UPI ID** | Where the money should be sent. |
| **Wallet** | Customer's wallet balance at the time of the request. |
| **Status** | Pending, Approved, Processing, Completed, Rejected or Failed. |
| **Requested** | Request date and time (sortable). |
| **Payment** | Transaction reference, processed time and the admin who processed it. |
| **⋮** | Row actions. |

## Filters

- **Search** by Customer ID (or use a row's filter button).
- **Requested between** — from / to dates.
- **Sort:** Newest first, Oldest first, Largest amount, Smallest amount.

## Actions

**View details** (⋮ menu) opens **Payout request**: amount, UPI ID, status, customer, wallet balance, requested and processed times, processed by, transaction ref, remarks, payout ID and customer ID.

Requests that are still open (Pending / Approved / Processing) are moved forward from the row menu; completed requests only offer **View details**.

## Process a withdrawal

<Steps>
<Step title="Pick a pending request" icon="banknote" title-type="p">
Open the **Pending** tab. Check that the **Amount** does not exceed the **Wallet** balance.
</Step>
<Step title="Verify UPI ID and amount" icon="shield" title-type="p">
Open **View details** and confirm the UPI ID belongs to the right customer.
</Step>
<Step title="Transfer manually" icon="send" title-type="p">
Send the exact amount to the UPI ID through your bank or payment gateway and keep the reference.
</Step>
<Step title="Record and complete" icon="circle-check" title-type="p">
Update the request with the **transaction reference** and remarks and mark it completed. The Payment column then shows the reference, time and admin. Use **Rejected** for requests that should not be paid.
</Step>
</Steps>

<Callout kind="alert">
Payouts are fully manual. Double-check the UPI ID and amount before transferring — wrong payments cannot be reversed by the platform.
</Callout>

## Customer wallet context

The wallet in the customer app shows **Total Balance**, **Total Earned** and **Total Withdrawn**. The balance increases when referrer rewards are approved in **Referral Transactions** and decreases when a payout is completed. A wallet balance cannot go below zero.

## Admin responsibilities

- Process **Pending** requests promptly and keep an eye on **Processing** so nothing gets stuck.
- Only complete a payout after confirming the customer actually received the money.
- Always enter the correct transaction reference for audit and reconciliation.
- Use **Export CSV** for finance reconciliation.

## Connections to other modules

- **Referral Transactions** — approved rewards fund the wallet.
- **Referral Programs** — program rules decide how much customers can earn.
- **Customer app** — customers raise withdrawals and see their updated balance.
