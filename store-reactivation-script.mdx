## Overview

- **Team:** Store Onboarding / Channel Operations (B2CH)
- **Purpose:** Re-engage stores that were previously active (created orders earlier) but have stopped using the Cashkr Store App for some time.
- **When to use:** Store has been inactive (no orders) for 7+ days.
- **Tone:** Polite, motivating, partnership-oriented — focus on reminding benefits and offering support to restart smoothly.

<Callout kind="info">

Always start by understanding why the store became inactive and offer support (demo or in-store visit) instead of pushing for orders. Use the script as a guide, not a rigid checklist.

</Callout>

## Usage notes

- Use this script for stores that have been inactive for **7+ days**.
- Always ask the reason for inactivity before suggesting next steps.
- After the reactivation call, schedule a **demo or in-store visit** where possible.
- Mark the outcome in the tracker as one of: *Reactivated* / *Pending Visit* / *Not Interested*.

## After-call checklist

- Record the **reason for inactivity** in your notes or tracker.
- **Schedule a demo or in-store visit** with the associate if the store needs support.
- **Update the outcome** in the tracker: Reactivated, Pending Visit, or Not Interested.
- **Resend the reminder link** for the Cashkr Store App if needed so they can start creating orders again.
