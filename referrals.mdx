## Overview

**Sidebar path:** Dashboards → OPERATING → **Referrals** (`/referral-dashboard`)

The **Referral Dashboard** tracks orders that came through customer referral links and the rewards they generate.

## Filters

| Control | Description |
| --- | --- |
| **Date range** | Defaults to the last 30 days. |
| **Refresh** | Reloads the data. |

<Callout kind="info">
**All-Time Orders**, **Programs** and **Reward Txns** are all-time figures and do not follow the date range.
</Callout>

## What the screen shows

### Summary

| Item | Meaning |
| --- | --- |
| **Conv** ring | Conversion for the period. |
| **All-Time Orders** | Referral orders ever placed. |
| **Programs** | Live programs out of total (for example *1 live / 6*). |
| **Avg Quoted Price** | Quote at order time across all referral orders. |

### Period cards

| Card | Meaning |
| --- | --- |
| **Applied** | Referral orders created (with % change). |
| **Completed** | Reward-eligible completed orders. |
| **Failed** | Referral orders that failed. |
| **In Progress** | Referral orders still open. |
| **Referral Links** | Distinct referral IDs used. |
| **Order Value** | Amount paid to customers. |
| **Avg Order** | Per completed order. |
| **Conversion** | Completed ÷ applied. |

### Reward transactions (all-time)

Count and amount for **Pending**, **Approved**, **Paid Out** and **Cancelled** reward transactions.

### Charts and tables

| Block | Shows |
| --- | --- |
| **Conversion Funnel** | Orders that ever reached each stage: Orders created → Assigned to a vendor → Out for pickup → Completed. |
| **Status Breakdown** | Referral leads by status. |
| **Device Breakdown** | Referral leads by device. |
| **Top Cities** | Cities by referral leads. |
| **Daily Referral Trend** | Created, completed and failed per day. |
| **Top Referral Links** | Referral IDs with the most orders. Names live in the referral service, not on this page. |

## Actions

The dashboard is read-only. Manage programs, transactions and payouts under **Marketing → Referral Programs**, **Referral Transactions** and **Referral Payouts**.
