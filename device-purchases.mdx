## Overview

**Sidebar path:** Finance → Device Purchases (`/finance/internal-buyback`)

Use the Device Purchases page to track all device buying costs and keep a clean audit trail for inventory and accounting. It lists completed internal vendor orders, manual offline purchases, B2C and B2B deals, and excess stock buys in a single table.

<Callout kind="info">
  Use Device Purchases alongside **Device Sales**, **B2B**, and **Reports - Finance** to understand margins, reconcile payments, and validate inventory intake against vendor activity.
</Callout>

---

## What the screen shows

### Summary cards

| Card | What it shows |
| --- | --- |
| **Total Purchase Value** | Sum of the purchase price of all purchases matching the current filters |
| **Total Items** | Number of purchased devices matching the current filters |

### Purchases table

Each row is one purchased device.

| Column | Description |
| --- | --- |
| **Date** | Purchase date (for automatic entries, the date the vendor completed the order) |
| **Type** | Purchase type badge: **B2C**, **B2B** or **Excess** |
| **Device** | Device name / model |
| **Description** | Specs such as RAM / storage (— if none) |
| **Serial** | Serial / IMEI number |
| **Vendor** | Vendor or party the device was bought from |
| **Price** | Buying cost of the device |

---

## Filters & search

| Control | Description |
| --- | --- |
| **Pick a date range** | Limit rows and summary cards to a date range |
| **Type** | **All Types**, **B2C**, **B2B** or **Excess** |
| **Vendor** | **All Vendors** or a specific vendor |
| **Search** | Search by device or serial (press **Enter**) |
| **Export** | Export the filtered list |
| **Refresh** | Reload the latest purchase data |

## Add Purchase (manual entry)

Click **+ Add Purchase** to record purchases that did not come through the normal vendor order completion flow — for example an offline buy, a direct bulk deal with a vendor, or a stock correction.

The **Add Purchases** dialog lets you add **multiple devices at once**: fill in the common details, then add one row per device.

### Common details

| Field | Description |
| --- | --- |
| **Purchase Date** \* | Actual buying date (defaults to today) |
| **Purchase Type** \* | **Walk-in**, **Requirement**, **CashKr Vendor** or **External Vendor** |
| **Payment Method** \* | **Cash**, **Bank Transfer** or **UPI** |
| **Purchased From** \* | Pick an existing contact (searchable by name or phone) or use **+ Add Contact** to create one |

### Device rows

| Column | Description |
| --- | --- |
| **Device Name** \* | e.g. `iPhone 13 Pro Max 256GB` |
| **Price** \* | Purchase price for this device |
| **Serial/IMEI** \* | IMEI or serial number |
| **Description** | RAM, storage, condition, etc. |
| **Actions** | Duplicate or delete the row |

Use **Add Row** to add more devices. The footer shows the item count and total. Click **Save All Purchases** to save, or **Cancel** to discard.

<Steps>
  <Step title="Open the form" icon="plus" title-type="p">
    Go to **Finance → Device Purchases** and click **+ Add Purchase**.
  </Step>
  <Step title="Fill the common details" icon="edit" title-type="p">
    Set the purchase date, purchase type, payment method and the contact you purchased from.
  </Step>
  <Step title="Add devices" icon="list" title-type="p">
    Enter device name, price and IMEI/serial for each device. Use **Add Row** or the duplicate icon for more devices.
  </Step>
  <Step title="Save and verify" icon="check-circle" title-type="p">
    Click **Save All Purchases**, then confirm the new rows appear and **Total Purchase Value** / **Total Items** are updated.
  </Step>
</Steps>

## Business logic

### Automatic purchase entry

```plaintext
Order Completed (Internal Vendor)
        ↓
Purchase Record Created
        ↓
Added to Device Purchases
        ↓
Added to Inventory
```

<Callout kind="info">
  Only eligible internal vendor order completions flow into Device Purchases automatically. Use this page to verify that completed internal orders have matching purchase entries.
</Callout>

### Manual purchase entry

```plaintext
Admin → Add Purchase → Enter common details + devices → Save All Purchases
        ↓
Purchase records created and visible in Device Purchases
```

<Callout kind="alert">
  Treat changes on this page as finance-impacting. Always confirm with finance before adjusting historical purchase entries, especially for closed accounting periods.
</Callout>

---

## Notes

- The **Price** field stores the buying cost, not the selling price. It feeds purchase value and margin calculations.
- **Total Purchase Value** and **Total Items** recalculate from the active filters.
- To send a purchased device back to the seller, use **Finance → Returns → Purchase Returns**.

---

## Connections to other modules

- **Orders / Internal Vendors** — automatic source of purchase records when internal vendors complete orders.
- **All Inventory** — purchased devices become available inventory.
- **Device Sales** — purchase cost is used to calculate sale margin.
- **Reports** — purchase data feeds Profit & Loss, GST and Money Flow reports.
