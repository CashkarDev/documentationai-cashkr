title: Operating Principles
description: Shared execution rules that define how Cashkr teams work day to day, complementing the culture code that describes who we are.
---

<Callout kind="info">

Operating principles guide how we work across roles, levels, and teams. The culture code defines who we are; these principles define how we execute.

</Callout>

<ExpandableGroup>

<Expandable title="1. Every Lead is a Potential Order">

Treat every customer touchpoint with urgency. A ₹0 lead today could be a ₹50K referral tomorrow.

</Expandable>

<Expandable title="2. Own the SLA">

If you commit to a pickup, payout, or resolution — it must be closed on time. No excuses.

</Expandable>

<Expandable title="3. Don’t Wait to Escalate">

If you’re blocked — escalate immediately. Delay kills momentum, trust, and targets.

</Expandable>

<Expandable title="4. Build with Audit in Mind">

Logs, reports, status histories — everything should be trackable and auditable without hunting.

</Expandable>

<Expandable title="5. Communicate Proactively">

Don’t wait for someone to follow up. Be the first to update, confirm, or push forward.

</Expandable>

<Expandable title="6. Feedback Flows Up & Down">

Don’t wait for review cycles — if something can be improved, share it. Feedback is a growth loop.

</Expandable>

<Expandable title="7. Clear Is Better Than Clever">

In UI, messages, SOPs — make things obvious, not complicated. Clarity scales. Cleverness doesn’t.

</Expandable>

<Expandable title="8. Small Wins Stack">

You don’t need big leaps every week. One fix, one system, one better message every day = compounding growth.

</Expandable>

<Expandable title="9. Automation = Time Saved">

If you’ve done it twice, it should be systemized. Look for ways to automate, even manually at first.

</Expandable>

<Expandable title="10. The User Never Forgets">

Every glitch, delay, or miscommunication is remembered. Build as if every user is watching.

</Expandable>

</ExpandableGroup>
