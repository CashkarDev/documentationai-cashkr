## Overview

**Sidebar path:** Dashboards → OPERATING → Growth → **Sales** tab (`/dashboard/growth?tab=sales`)

**Sales & Pipeline** tracks the B2C lead pipeline, revenue and conversion for the selected period.

## Filters

| Control | Description |
| --- | --- |
| **Date range** | Defaults to the last 30 days. Cards show % change vs the previous period. |
| **AI Analyst Insight → Analyze Data** | Generates an AI summary. |

## What the screen shows

### KPI cards

Total Leads, Revenue, Completed, Avg Order Value, Conversion (with a label such as *Very Low*), Fail Rate (with failed count), Active Rate (in progress), Price Drop (generated → final price).

### Health

A *Critical* → *Optimal* bar combining Conversion, Fail, Active and Drop.

### Panels

| Panel | Contents |
| --- | --- |
| **Pipeline Stages** | New, Generated, In Progress, Completed, Failed — counts and %. |
| **Revenue Metrics** | Total Revenue, Avg Order Value, Completed Orders, Failed Orders, Reserved. |
| **Conversion Analysis** | Conversion Rate, Active Rate, Avg Price Drop (Gen → Final), Pickup Delayed. |
| **Failure Breakdown** | Failed count and top reasons with % (for example *Not reachable or responding*, *Customer out of town/area*, *Better price elsewhere*, *Not interested in selling*, *Was just checking*). |
| **Daily Pipeline Trend** | Leads, completed, failed and conversion % per day. |
| **Device Performance** | Leads, completed and conversion per device type (Mobile, Tablet, Watch, Mac, Console, Laptop, Headphone) with a band (*Low*, *Avg*). |

### Detail tables

Switch between four tables:

| Tab | Columns |
| --- | --- |
| **Top Vendors** | Vendor, Completed, Revenue, Avg Value |
| **City Performance** | Per-city leads, completion and revenue |
| **Top Models** | Best-selling device models |
| **Failure Analysis** | Failure reasons in detail |

## Actions

The Sales tab is read-only.

<Callout kind="info">
B2B deals and corporate buyback pipelines are managed under **Channels → Buyback B2B** and **Channels → Corporate Buyback**, not on this tab.
</Callout>
