## Overview

The Master Logs page ("Track all admin panel activity") records every action performed by any admin user across the admin panel. Every create, update, delete, assignment and status change appears here with the admin's name and the exact timestamp.

Open it from **System → Admin → Master Logs** in the left sidebar (route `/admin-logs`). The total number of logs is shown under the title.

<Callout kind="info">
Every action performed in the admin panel is recorded automatically; admins never need to create log entries manually.
</Callout>

## What the logs show

Logs are shown as cards, newest first, 50 per page. Each card includes:

- **Action type tag** — The operation, as a coloured tag such as `CREATE` (green), `UPDATE` (blue), `DELETE` (red) or `STATUS_CHANGE`.
- **Entity tag** — The module or record affected, with a short record ID where available (for example `ORDER #1a2b3c4d`).
- **Description** — A short summary such as `Create pincode`, `Update area`, `Update banner: <name>` or `Order audit: approve_with_remark`.
- **Admin name** — Who performed the action.
- **Date and time** — When it happened, to the minute.

Click a card to expand it. The expanded view shows **by &lt;admin&gt;**, the IP address and the browser used.

A footer shows the range being displayed (e.g. "Showing 1 - 50 of …") and the page count.

## Action types

The **Action** filter lists every action type with its count. Common types:

| Action | Meaning |
| --- | --- |
| UPDATE | A record was edited |
| STATUS_CHANGE | A record's status changed (e.g. lead or order status) |
| CREATE | A new record was created |
| ASSIGN | A lead or order was assigned |
| DELETE | A record was deleted |
| UPDATE_MAX_LEADS, UPDATE_STATUS, UPDATE_VENDOR_TYPE, UPDATE_DEVICES, UPDATE_CREDIT | Specific vendor / settings updates |
| APPROVE, REJECT | Approval decisions |
| IMPORT, BULK_UPDATE | Bulk operations (e.g. Excel imports) |
| BROADCAST | Notifications broadcast |
| DUPLICATE, DUPLICATE_ORDER, REORDER | Record duplication and reorders |
| VENDOR_PHONE_CHANGED | A vendor's phone number was changed |
| UPDATE_AREA_COVERAGE | Pincodes were added to or removed from a vendor's service coverage (logged against the `Vendor` entity, e.g. "Added 1 pincode") |

## Entity types

The **Entity** filter lists every entity with its count. Examples include `LEAD`, `PRICING`, `ORDER`, `AREA`, `PINCODE`, `ZONE`, `DEVICE_CLASS`, `MODEL`, `VARIANT`, `B2B_LEAD`, `B2B_DEAL`, `VENDOR`, `VENDOR_PAYMENT`, `STORE_VENDOR`, `CREDIT`, `CUSTOMER`, `ADMIN`, `SETTINGS`, `SALE`, `INVENTORY`, `COUPON`, `BANNER`, `NOTIFICATION`, `TERMS`, `CX_CASE`, `PLATFORM_REVIEW`, `EXPENSE`, `PURCHASE_ORDER`, `PETROL_SURGE_CLAIM` and `INTEGRATION`.

## Search

Use the search box (**Search logs by description, action, entity...**) and click **Search**.

Examples:

- `inventory` — all inventory-related actions
- `banner` — all banner changes
- An order or record ID fragment — the history of one record

## Filters

<Steps>
<Step title="Open Filters" icon="filter" title-type="p">
Click **Filters** at the top right to open the filter panel.
</Step>
<Step title="Set criteria" icon="sliders-horizontal" title-type="p">
Choose any combination of **Action**, **Entity**, **Admin**, **From Date** and **To Date**. The Action and Entity dropdowns show the number of logs for each option.
</Step>
<Step title="Apply" icon="check" title-type="p">
Click **Apply Filters**. Use **Clear All** to reset.
</Step>
</Steps>

Combine filters with search for high-volume investigations.

## Use cases

- **Audit and accountability** — Find who changed a price, deleted a record or changed a status, and when.
- **Troubleshooting** — Identify the action behind an unexpected change before escalating to the tech team.
- **Compliance and reporting** — Use the log as the record of admin activity for reviews.
- **Team monitoring** — Filter by **Admin** to review a team member's activity.

## Connections to other modules

Every module writes to Master Logs, including Orders, Leads, Vendors, Credits & Payments, Areas & Zones (AREA, PINCODE, ZONE), Devices catalog and pricing (MODEL, VARIANT, PRICING, DEVICE_CLASS), Inventory and Sales, Coupons, Banners, Notifications, Terms & Conditions (TERMS), CX cases and Admin Users.

## Important notes

<Callout kind="alert">
Master Logs are read-only. Entries cannot be edited, deleted or hidden, so treat them as the source of truth for admin activity.
</Callout>

<Callout kind="info">
Expanded entries include IP address details. Treat them as internal data and do not share them outside the team.
</Callout>
