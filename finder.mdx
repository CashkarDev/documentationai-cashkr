## Overview

<Callout kind="info">

Finder is Cashkr’s device discovery and research section. It is separate from the Sell flow and is powered by two Strapi collection types: `Device` and `DeviceType`.

</Callout>

Finder lets users browse, filter, search, and compare electronic devices across Laptops, Smartphones, and Tablets. The section includes category browsing, brand and model listings, detailed specification pages, device search, and side-by-side comparison.

At a high level, `DeviceType` defines the top-level category structure, while `Device` supplies the actual brand, model, specification, score, and comparison data shown across the section.

## Strapi data model

<Tabs>
  <Tab title="DeviceType" icon="folder">

  `DeviceType` defines the top-level categories shown throughout Finder. Each entry maps to a category tab such as Laptop, Smartphone, or Tablet and drives category navigation, brand grouping, and search or compare selectors.

  ### How DeviceType powers Finder

  - Category buttons on Finder Home are pulled from `DeviceType` entries.
  - The URL segment `deviceType` maps to the `DeviceType.slug` value.
  - Each `DeviceType` groups the brands and devices shown in that category.
  - The Search page category toggle uses `DeviceType` entries.
  - The Compare page category selector also uses `DeviceType` entries.

  ### Suggested fields

  Display name, for example `Laptop`, `Smartphone`, or `Tablet`.
  </ParamField>

  <ParamField body="slug" param-type="uid" required="true" show-location="false">
  URL-safe key generated from `name`, for example `laptop`, `smartphone`, or `tablet`.
  </ParamField>

  <Tab title="Device" icon="database">

  `Device` is the primary content type behind Finder. Every device card, brand listing, specification page, search result, and comparison slot comes from a `Device` entry.

  ### How Device powers Finder

  - Each `Device` entry appears as a card on `/finder/{deviceType}/{brand}`.
  - Each `Device` entry has a detail page at `/finder/{deviceType}/{brand}/{slug}`.
  - Devices with `is_trending: true` appear in the Trending Devices carousel on Finder Home.
  - Devices also populate the Popular Right Now sidebar widget.
  - Search filters query `Device` fields such as brand, price, RAM, storage, and OS.
  - Compare loads multiple `Device` entries side by side.

## How data maps to Finder pages

### Finder Home — `/finder`

| UI section | Data source |
| --- | --- |
| Category tabs | `DeviceType` collection, all published entries |
| Popular Brands | Distinct `brand` and `brand_logo` values from `Device`, filtered by selected `device_type` |
| View all brand link | Built from `DeviceType.slug` and distinct `Device.brand_slug` |
| Device cards in browse grid | `Device` collection filtered by `device_type` |
| Trending Devices carousel | `Device` entries where `is_trending = true` |
| Popular Right Now sidebar | `Device` entries, top 5 trending or most viewed |

### Category page — `/finder/{deviceType}`

| UI element | Data source |
| --- | --- |
| Page heading | `DeviceType.name` |
| Sub-heading | `DeviceType.description` |
| Brand cards | Distinct `Device.brand`, `Device.brand_slug`, and `Device.brand_logo` filtered by `device_type.slug = {deviceType}` |
| Brand card link | `/finder/{DeviceType.slug}/{Device.brand_slug}` |

### Brand listing — `/finder/{deviceType}/{brand}`

| UI element | Data source |
| --- | --- |
| Page heading | `Device.brand` plus `DeviceType.name` |
| Model count | Count of `Device` entries where `device_type.slug = {deviceType}` and `brand_slug = {brand}` |
| Device cards | `Device` entries filtered by `device_type` and `brand_slug`, paginated with infinite scroll |
| Release year badge | `Device.release_year` |
| Card link | `/finder/{DeviceType.slug}/{Device.brand_slug}/{Device.slug}` |

### Device detail — `/finder/{deviceType}/{brand}/{model-slug}`

| UI element | Data source |
| --- | --- |
| Breadcrumb | `DeviceType.name`, `Device.brand`, and `Device.name` |
| Device image | `Device.image` |
| Brand and category labels | `Device.brand` and `DeviceType.name` |
| Device name | `Device.name` |
| Availability note | `Device.availability_note` |
| Release date | `Device.release_date_label` |
| Market status | `Device.market_status` |
| Spec highlight row | `Device.display_size_inches`, `Device.chipset`, `Device.ram_base_gb`, `Device.storage_options`, `Device.os_name`, `Device.os_version` |
| Scores | `Device.score_*` fields |
| Pros and cons | `Device.pros` and `Device.cons` |
| Full specifications | All relevant `Device` spec fields per category |
| Sell on Cashkr CTA | Links to the sell flow for the relevant device |

### Device search — `/finder/search`

| UI element | Data source |
| --- | --- |
| Category toggle | `DeviceType` collection |
| Brand filter checkboxes | Distinct `Device.brand` values for selected `DeviceType` |
| Price range slider | `Device.price_launch` range |
| RAM filter | Distinct `Device.ram_base_gb` values |
| Storage filter | Distinct `Device.storage_base_gb` values |
| Operating system filter | Distinct `Device.os_name` values |
| Search results grid | `Device` entries matching all applied filters |

### Device compare — `/finder/compare`

| UI element | Data source |
| --- | --- |
| Category selector dropdown | `DeviceType` collection |
| Add Device modal | Searches `Device` collection by name |
| Side-by-side spec rows | All `Device` spec fields for each added device |

## User-facing page behavior

### Finder Home — `/finder`

**Page Title:** `Device Finder | Find Your Phone, Laptop or Tablet | Cashkr`

Finder Home is the main discovery surface. It combines category browsing, brand shortcuts, device browsing, editorial content, and trending devices in a single landing page.

#### Region 1 — Hero banner and featured articles carousel

- Full-width image carousel showing featured articles
- Each slide includes a background image, category badge such as `ARTICLE`, headline, short description, and `Read More` CTA button
- Thumbnail strip below the main slide for quick navigation
- Left and right arrow buttons for manual navigation

#### Region 2 — Browse by category

- Heading: `Browse by Category`
- Subheading: `Select a category to explore the latest models`
- Category toggle buttons: **Laptop**, **Smartphone**, **Tablet**

- **Filter** button opens the filter drawer and links into `/finder/search`

#### Region 3 — Latest Tech News

- Heading: `Related Articles`

### Add or update Finder content in Strapi

<Steps>
  <Step title="Add a new DeviceType" icon="plus">

  DeviceTypes define the top-level categories such as Laptop, Smartphone, and Tablet. This is usually a one-time action unless Finder adds a new device category.

  1. Go to **Strapi Admin → Content Manager → DeviceType → Create new entry**
  2. Enter `name`, for example `Smartwatch`, and `slug`, for example `smartwatch`
  3. Optionally upload an `icon` and add a `description`
  4. Click **Save → Publish**
  5. The new category appears on Finder Home and in Search and Compare selectors

  </Step>

  <Step title="Add a new Device" icon="plus">

  1. Go to **Strapi Admin → Content Manager → Device → Create new entry**
  2. Fill in the required identity fields:
     - `name`
     - `slug`
     - `device_type`
     - `brand`
     - `brand_slug`
     - `image`
  3. Fill in optional classification fields such as `release_year`, `release_date_label`, `market_status`, `availability_note`, `available_colours`, `price_launch`, and `summary`
  4. Fill in the spec fields relevant to the device category:
     - **Laptop:** Display, Performance, Battery Wh, Connectivity, Build and Design, Software
     - **Smartphone / Tablet:** Display, Camera, Battery and Charging, Performance, Connectivity, Build and Design, Software
  5. If the device is a smartphone or tablet, fill in Scores and Pros or Cons for the Expert Review block
  6. Toggle `is_trending: true` if the device should appear in Trending Devices
  7. Click **Save → Publish**

  After publishing, the device appears on:
  - `/finder/{deviceType}/{brand_slug}`
  - `/finder/{deviceType}/{brand_slug}/{slug}`
  - Search results when filters match
  - The Trending carousel if `is_trending = true`

  </Step>

  <Step title="Edit an existing Device" icon="edit">

  1. Go to **Strapi Admin → Content Manager → Device**
  2. Use search or filters to find the device by name or slug
  3. Open the entry
  4. Update any fields, including specs, scores, market status, or images
  5. Click **Save → Publish**

  Changes are reflected immediately on the live Finder pages.

  </Step>

  <Step title="Mark a device as trending" icon="check-circle">

  1. Open the `Device` entry in Strapi
  2. Set `is_trending` to **true**
  3. Click **Save → Publish**
  4. The device appears in the Trending Devices carousel and the Popular Right Now widget
  5. To remove it, set `is_trending` back to **false**

  </Step>
</Steps>

### Additional content operations

#### Update market status

Devices move through lifecycle stages using `market_status`.

| Status | Meaning | Where it appears |
| --- | --- | --- |
| `upcoming` | Not yet released | Detail page shows expected release date label |
| `available` | Currently on sale | Detail page shows `Available in India` and Buy or Sell CTAs |
| `discontinued` | No longer sold | Detail page reflects discontinued status |

To update it, open the `Device` entry, change `market_status`, then save and publish.

#### Add a new brand

Brands are not a separate collection. Finder derives them from the `brand` and `brand_slug` fields on `Device`.

- Create one or more `Device` entries with the new `brand` name and `brand_slug`
- Upload a `brand_logo` image on each device entry, or at minimum on the first entry
- Publish the entries
- The brand appears automatically on `/finder/{deviceType}` and in Search filters

#### Manage the hero carousel

The Finder Home hero carousel shows featured articles. This content is managed separately through the Articles CMS or a `FinderPageConfig` single type.

- Go to **Strapi Admin → Single Types → FinderPageConfig**
- Add, remove, or reorder featured articles linked to the carousel
- Each item references an Article entry with image, title, excerpt, and link
- Save and publish

## Strapi REST API reference

| Purpose | Endpoint |
| --- | --- |
| All DeviceTypes | `GET /api/device-types?populate=*` |
| All Devices for a DeviceType | `GET /api/devices?filters[device_type][slug][$eq]=laptop&populate=*` |
| All Devices for a Brand within a DeviceType | `GET /api/devices?filters[device_type][slug][$eq]=laptop&filters[brand_slug][$eq]=asus&populate=*` |
| Single Device by slug | `GET /api/devices?filters[slug][$eq]=iphone-15&populate=*` |
| Trending Devices | `GET /api/devices?filters[is_trending][$eq]=true&populate=*` |
| Distinct brands for a DeviceType | `GET /api/devices?filters[device_type][slug][$eq]=smartphone&fields[0]=brand&fields[1]=brand_slug&fields[2]=brand_logo` |
| Search with Brand plus Price plus RAM filters | `GET /api/devices?filters[device_type][slug][$eq]=laptop&filters[brand][$in][0]=Apple&filters[ram_base_gb][$gte]=16&filters[price_launch][$lte]=150000&populate=*` |
| Compare multiple devices | `GET /api/devices?filters[slug][$in][0]=iphone-15&filters[slug][$in][1]=iphone-16&populate=*` |

## URL structure

```typescript
/finder
  └── /{deviceType}                          → Brand listing  (DeviceType.slug)
       └── /{brand_slug}                     → Model listing  (Device.brand_slug)
            └── /{slug}                      → Device detail  (Device.slug)

/finder/search?deviceType={deviceType}       → Filtered search
/finder/compare                              → Side-by-side compare
```
