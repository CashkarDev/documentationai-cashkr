## Overview

**Sidebar path:** Dashboards → OPERATING → CX & Reviews → **Reviews** tab (`/dashboard/cx?tab=reviews`)

**Reviews & Reputation** summarises customer reviews, NPS and service quality for the selected period.

## Filters

| Control | Description |
| --- | --- |
| **Date range** | Defaults to the last 30 days. |
| **Refresh** | Reloads the data. |
| **AI Analyst Insight → Analyze Data** | Generates an AI summary. |

## What the screen shows

### KPI cards

| Card | Meaning |
| --- | --- |
| **Total Reviews** | Reviews received. |
| **Avg Rating** | Average stars out of 5. |
| **NPS Score** | Promoters minus detractors, with a band (for example *Fair*). |
| **Review Rate** | Share of completed orders that got a review. |
| **Promoters** | 4–5 star reviews. |
| **Detractors** | 1–3 star reviews. |
| **With Comments** | Reviews that include text (count and %). |
| **Bad Reviews** | Low-rated reviews, with a level badge. |

### Reputation Health

A score with a *Poor* → *Excellent* bar, summarising Rating, NPS, Review Rate and Comment Rate.

### Panels

| Panel | Contents |
| --- | --- |
| **Rating Breakdown** | 5★ to 1★ share and count. |
| **NPS Breakdown** | Promoters (4–5), Detractors (1–3), 5-Star %, Low Rating %, Completed Orders. |
| **Device Performance** | Average rating and review count per device type. |
| **Geography Summary** | Total Cities, Total Zones, Unserviced Pincodes, top city — with **View All Cities**. |
| **Daily Review Trend** | Reviews and average rating per day. |

### Detail tabs

| Tab | Shows |
| --- | --- |
| **Best Rated Vendors** | #, Vendor, Rating, Reviews, 5★ %, Comment %. |
| **Worst Rated Vendors** | Same columns, lowest rated first. |
| **Bad Reviews** | Low-rated reviews to follow up. |
| **Cities** | Ratings by city. |
| **Zones** | Ratings by zone. |
| **Unserviced** | Pincodes without service. |
| **Recent Reviews** | Latest reviews. |

## Actions

The tab is read-only. To moderate or publish reviews, use **B2C Sales → Team → Reviews** or **Marketing → Platform Reviews**.
