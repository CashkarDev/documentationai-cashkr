## Overview

**Sidebar:** **Merchandise** → Catalog → **Products** (`/merchandise/products`) and Merchandise → Fulfillment → **Orders** (`/merchandise/orders`)

The Merchandise section controls the store vendors buy branded items from (apparel, packaging, accessories, starter kits). Use **Products** to maintain the catalogue and stock, and **Orders** to track and fulfil orders.

For the full feature overview and business rules, see [Merchandise Store](/merchandise-store).

## Products

The header shows the total number of products.

### Filters & search

| Control | Description |
| --- | --- |
| Search | By name, slug or category. |
| Filter by category | Type a category to narrow the list. |
| **Refresh** | Reloads the list. |

### Columns

| Column | Description |
| --- | --- |
| Image | Primary product image. Click it (zoom icon on hover) to open an enlarged preview. |
| Name | Product name and auto-generated slug. |
| Category | Category text (e.g. apparel, hoodies, Packaging, Accessories). |
| Variations | Number of variations. |
| Price | Single price, or a price range across variations. |
| Stock | Total stock across variations (low stock is highlighted). |
| Status | **Available** or unavailable. |
| Actions | **Edit** (pencil) and **Delete** (bin). |

### Add / Edit product

Click **Add product** (or the pencil on a row). The **New Merchandise Product** dialog says: "Create a product with at least one variation. Slug is auto-generated from the name."

| Field | Notes |
| --- | --- |
| **Name** | e.g. "Cashkr Hoodie". The slug is generated from it. |
| **Category** | Free-text category, e.g. "apparel". |
| **Description** | Shown to buyers. |
| **Available for sale** | Switch. Disabled products are hidden from customers. |
| **Minimum quantity (per size)** | Buyers must buy at least this many of each size — e.g. 2 = min 2 of XL, 2 of XXL. |
| **Images** | Drop or **Browse** — JPEG, PNG, WebP, GIF, max 5 MB each. Or paste an image URL and click **Add**. |
| **Variations** | At least one. Each has **SKU**, **Color**, **Size**, **Price** and **Stock**. Use **Add variation** for more, or the remove icon to delete one. |

Click **Create product** to save, or **Cancel**.

<Callout kind="tip">
Price and stock live on each variation, so a hoodie in three sizes is one product with three variations. The list shows the price range and the total stock.
</Callout>

## Orders

The header shows the total number of orders. Paginated with Previous / Next.

### Filters & search

| Control | Description |
| --- | --- |
| Search | By order #, name, email or phone — click **Search**. |
| Status | All statuses, PENDING, CONFIRMED, SHIPPED, DELIVERED, CANCELLED. |
| **Refresh** | Reloads the list. |

### Columns

| Column | Description |
| --- | --- |
| Order # | Sequential order number. |
| Customer | Buyer name and email. |
| Items | Number of items. |
| Total | Order total. |
| Status | Status badge. |
| Placed | Date and time placed. |
| **View →** | Opens the order detail page. |

### Order detail

`/merchandise/orders/<order-id>` shows the order number with its status badge and a **Refresh** button:

| Block | Contents |
| --- | --- |
| **Items** | Product (image, name, SKU), variant (colour · size), qty, price, subtotal and total. |
| **Shipment (Shiprocket)** | Shipment status (e.g. NOT_CREATED). Label and tracking appear once Shiprocket generates them. |
| **Actions** | **Cancel order** — cancelling restores stock for each variation in the order. Cancelled orders show "This order is cancelled — no further action" instead. |
| **Customer** | Name, email, phone and ID. |
| **Shipping address (warehouse)** / **Shipping address (shop)** | Delivery address and contact number. The label shows whether the order ships to the warehouse or to the vendor's shop. |
| **Meta** | Placed, Updated and Order ID. |

### Status lifecycle

```plaintext
PENDING ──► CONFIRMED ──► SHIPPED ──► DELIVERED
                │
                ▼
            CANCELLED (stock restored)
```

<Callout kind="info">
Shipping is handled through Shiprocket — the shipment block shows the label and tracking once a shipment is created.
</Callout>

## Common issues

| Issue | Cause | Resolution |
| --- | --- | --- |
| Product not visible to vendors | **Available for sale** is off or variations have no stock | Turn availability on and add stock to the variations. |
| Shipment shows NOT_CREATED | Shiprocket has not generated the shipment yet | Refresh later; escalate to tech if it stays NOT_CREATED. |
| Stock looks wrong after a cancellation | Cancel restores stock per variation | Re-check the variation stock in the product's Edit dialog. |
