## Overview

Access the Strapi admin panel to manage Cashkr website articles and recover your account if you forget your password.

## What it shows

The login screen displays fields for your email and password, along with a Forgot Password link for recovering access to the Strapi admin panel.

## Common tasks

Use this flow to log in or reset a forgotten password.

<Steps>

<Step title="Open the Strapi admin login page">

Go to the Strapi admin login URL for Cashkr articles:  
[mktg.stage.articles.cashkr.com](https://mktg.stage.articles.cashkr.com)

</Step>

<Step title="Log in with email and password">

Enter your registered email address and password, then select **Login** to access the Strapi admin panel.

</Step>

<Step title="Use Forgot Password to request a reset email">

If you do not remember your password, select **Forgot Password**, enter your registered email address, and submit the form to receive a reset email.

</Step>

<Step title="Follow the reset link to set a new password">

Open the password reset email in your inbox, select the reset link, and set a new password to regain access to Strapi.

</Step>

</Steps>

<Callout kind="info">

Password reset emails include a temporary link that expires after some time. If the link no longer works, request a new reset email from the Forgot Password screen.

</Callout>

## System logic

Login requires valid credentials stored in Strapi's user database. Password reset emails are generated by Strapi and contain a temporary link that lets you set a new password.

## Connections

Changes you make to articles in Strapi are reflected in the Articles section of the Cashkr website.
