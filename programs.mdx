## Overview

**Sidebar path:** Marketing → Referral Programs (`/referral-programs`)

The Referral Programs page lets you define the programs that reward existing customers (referrers) for bringing new customers (referees) to Cashkr. Each program controls what the referrer gets, what the referee gets, when the program runs, and the conditions that must be met.

<Callout kind="info">
Use this page to create, edit, switch on/off, review performance of, and delete referral programs.
</Callout>

## What the list shows

**Status tabs:** All, Live, Scheduled, Expired, Inactive.

| Column | What it shows |
| --- | --- |
| **Programme** | Program name with its description below (sortable). |
| **Status** | Live, Scheduled, Expired or Inactive. |
| **Referrer gets** | Flat amount (e.g. ₹100) or percentage, with the cap shown as "up to ₹X". |
| **Referee gets** | Flat amount or percentage, with "min order ₹X" when a minimum order value is set. |
| **Conditions** | Minimum completed orders (e.g. "1+ completed orders"), use limit ("No use limit" or "N uses each") and validity days. |
| **Runs** | Start → end window (e.g. "Immediately → No end"); sortable. |
| **On** | Switch showing whether the program is switched on. |
| **⋮** | Row actions menu. |

Pagination at the bottom shows "Showing X–Y of Z" with a **Per page** selector.

## Search and sort

- **Search** by name or description.
- **Sort:** Newest first, Oldest first, Name A–Z, Starting latest, Ending soonest.

## Actions

**Row actions (⋮):**

- **Edit** — open the program form with current values.
- **Performance** — shows how the program has performed since it started: Referrals, Completed, Referrer rewards, Referee discounts, Total cost, Avg referrer reward.
- **Switch off** / switch on — same as the **On** switch.
- **Delete** — permanently remove the program.

## Add a programme

Click **Add programme** (top right) to open **Create New Referral Program**.

<Steps>
<Step title="Basic Information" icon="pencil" title-type="p">
- **Program Name** — a descriptive name (e.g. *Summer Referral Program*).
- **Description** — detailed description of the program.
</Step>
<Step title="Schedule" icon="calendar" title-type="p">
- **Start Date & Time** (optional) — leave empty to start immediately.
- **End Date & Time** (optional) — leave empty to run until deactivated.

Times are in IST. An active program only applies to new referrals while the current time falls inside this window.
</Step>
<Step title="Referee (New Customer) Settings" icon="user-plus" title-type="p">
- **Discount Type** — Percentage or Flat Amount.
- **Discount Value** — e.g. 10 for 10%.
- **Minimum Order Value** (optional) — e.g. 1000.
- **Maximum Discount** (optional) — cap on a percentage discount, e.g. 500.

Example: 10% with a ₹300 cap on a ₹5,000 device price → 10% is ₹500, capped to ₹300, so the referee gets ₹5,300.
</Step>
<Step title="Referrer (Existing Customer) Settings" icon="gift" title-type="p">
- **Reward Type** — Percentage or Flat Amount.
- **Reward Value** — e.g. 100.
- **Maximum Reward** (optional) — cap on a percentage reward.

The reward is calculated after the referee completes their order and must be approved by an admin before it reaches the referrer's wallet.
</Step>
<Step title="Conditions & Limits" icon="sliders-horizontal" title-type="p">
- **Min Completed Orders** (optional) — e.g. 1.
- **Validity Days** (optional) — e.g. 30.
- **Max Uses Per Referrer** (optional) — e.g. 10; blank means no use limit.
</Step>
<Step title="Status" icon="toggle-right" title-type="p">
**Active Status** — enable or disable the program, then click **Create Program**.
</Step>
</Steps>

## How the referral code system works

Each existing customer has one permanent referral code. It never changes when new programs are created and works across all live programs.

- A new customer can use a referral code only once in their lifetime.
- Deleting an account and re-registering does not reset eligibility — the rule is enforced by phone number.

## Referral flow lifecycle

<Steps>
<Step title="Referrer shares code or link" icon="share" title-type="p">
The referrer shares their unique code or link with a friend.
</Step>
<Step title="New customer registers with the code" icon="users" title-type="p">
The code links permanently to that customer; they can never use another referral code.
</Step>
<Step title="Referee sells a device and gets the discount" icon="smartphone" title-type="p">
The referee discount is applied automatically to the device price at checkout.
</Step>
<Step title="Referrer reward is generated and approved" icon="circle-check" title-type="p">
After the referee's order completes, the reward appears in **Referral Transactions** as Pending. An admin approves it and it is added to the referrer's wallet.
</Step>
<Step title="Referrer withdraws" icon="wallet" title-type="p">
Withdrawal requests appear in **Referral Payouts** for admins to process.
</Step>
</Steps>

## Fraud and abuse prevention

- One permanent, non-transferable referral code per customer.
- One-time referral code use per new customer, tracked by phone number.
- Referrer rewards are only issued after order completion and admin approval.

<Callout kind="alert">
Keep only one program live at a time where possible. The same referral code works for every live program, which can lead to overlapping or unexpected rewards.
</Callout>

## Connections to other modules

- **Referral Transactions** — pending and approved referral rewards.
- **Referral Payouts** — referrer wallet withdrawal requests.
- **Customer app / website** — referral code validation and automatic referee discount at checkout.

## Important notes

- Referee discounts apply automatically and cannot be reversed after the order completes.
- Referrer rewards stay Pending until an admin approves them — check that the order genuinely qualifies first.
- Use **Performance** to monitor the total cost of a program before extending or re-running it.
