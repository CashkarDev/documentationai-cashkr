## Purpose

Daily attendance for partners (field vendors, store vendors, cashboys): the morning OTP login auto punches in, the app can punch in/out with selfie + GPS, send location heartbeats during the shift, and admins see a summary, live map, roster, CSV export, overrides and store geofences.

## Core Business Logic

1.  **Identity** (attendanceIdentity.ts): the principal is resolved from the login token only. Cashboy → CASHBOY. Otherwise vendorId is looked up in Vendors and StoreVendors (using userKind when present): StoreVendors → STORE_VENDOR with storeId; Vendors → VENDOR, or STORE_VENDOR when Vendors.userType === "Store" (no storeId). Customers get 403.

2.  **Auto punch-in at login** (otp/index.ts markAttendanceForLogin → AttendanceService.punchInFromLogin): partner sessions end at IST midnight, so the first OTP login of the day is the punch-in (punchInSource=LOGIN, time = login instant, selfie/coords optional). Retried 3 times (150 ms apart), never fails login. Idempotent for a second login the same day. Store vendors outside the geofence are flagged DISPUTED, not rejected.

3.  **Manual punch-in**: if today's row came from LOGIN and lacks selfie or coordinates, the call backfills them (completeLoginPunchIn; outside-geofence → DISPUTED + remark). Otherwise a new row: store vendors with a configured store geofence must be within geofenceRadiusMeters (default 100 m, Haversine) or get 403 "Punch-in failed: You are Xm away from &lt;store&gt;"; unconfigured store or missing location → remark only. Status PRESENT for store vendors, ON_FIELD for field vendors/cashboys; isLate if IST time &gt; ATTENDANCE_LATE_CUTOFF_IST (default 10:15); deviceMetadata.isMock → DISPUTED. Unique index catches races (P2002 → 409).

4.  **Punch-out**: computes totalHoursWorked (2 decimals), CHECKED_OUT unless DISPUTED.

5.  **Auto punch-out job**: autoPunchOutOpenShifts() closes every row with punchOutTime=null and date &lt;= today, capping each at 23:59:59.999 IST of its own day, appends remark "Auto punched out at day end", leaves coords/selfie null.

6.  **Selfies** (partnerSelfie.ts): accepts multipart file, base64 or data URI; types jpeg/png/webp/heic (sniffed from magic bytes if needed); max 5 MB; uploaded to partner-attendance-selfies/ (login uses partner-login-selfies/); only the URL is stored.

## Status / State Machine

AttendanceStatus = PRESENT, LATE, HALF_DAY, ON_FIELD, CHECKED_OUT, ABSENT, DISPUTED. Code transitions: new row → PRESENT (store) or ON_FIELD (field); mock GPS or outside geofence → DISPUTED; punch-out / auto punch-out → CHECKED_OUT (DISPUTED stays DISPUTED); admin override → any value. LATE, HALF_DAY, ABSENT are only set by admin override (isLate is the real lateness flag; ABSENT is also used by team-view filtering).

## Validations & Rules

parseCoordinates rejects non-finite, out-of-range and (0,0); punch-out and heartbeat require coordinates; address truncated to 500; remarks clamped to 500; geofence radius 10–5000; roster limit ≤ 1000; admin enum params validated (400). IST day boundaries via dayjs Asia/Kolkata (normalizeAttendanceDate, endOfAttendanceDay). Body vendorId/userType are ignored by design.
