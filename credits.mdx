## Overview

**Sidebar:** Vendors → Money → **Credits & Payments** (`/vendors/payments`)

Use this screen to approve or reject vendor credit purchase requests and to audit all historical credit purchases. **PhonePe payments are auto-approved**, so only manually paid requests (for example, Manual UPI with a payment screenshot) wait for admin action.

<Callout kind="info">
Treat this screen as the financial source of truth for vendor credit inflows. Every approval adds credits to the vendor's wallet and flows into Cash In Hand and finance reports.
</Callout>

The screen has two tabs:

| Tab | Purpose |
| --- | --- |
| **Credits Purchase** | Pending credit purchase requests waiting for admin approval or rejection. |
| **Purchase Logs** (`?tab=logs`) | Complete history of credit purchases with payment type, TXN ID, amount, credits and invoice download. |

## Credits Purchase (pending approvals)

Each pending request is shown as a card. A footer shows the page number and how many requests are pending, with **Prev / Next** pagination.

| Field | Description |
| --- | --- |
| Vendor name (vendor ID) | Vendor who submitted the request, with their system ID in brackets. |
| Payment ID | Internal payment reference number. |
| Date & time | When the vendor submitted the request. |
| Amount | INR amount paid, also shown in words (e.g. "Twenty Thousand Rupees Only"). |
| Credits | Credits that will be added to the vendor's wallet if approved. |
| Payment Screenshot | Proof of payment uploaded by the vendor. |

### Approve a request

<Steps>
  <Step title="Review the request" icon="eye" title-type="p">
Check the vendor, amount and credits, and open the **Payment Screenshot** to confirm the payment reference, amount and payer match.
  </Step>
  <Step title="Click Approve (enter TXN ID)" icon="check-circle" title-type="p">
Click **Approve (enter TXN ID)** on the card.
  </Step>
  <Step title="Enter the transaction ID" icon="edit" title-type="p">
Enter the **Transaction ID** from the screenshot or your bank / gateway records so it can be cross-checked later.
  </Step>
  <Step title="Confirm" icon="arrow-right" title-type="p">
Credits are added to the vendor account immediately and the request moves to **Purchase Logs** as **Approved**.
  </Step>
</Steps>

<Callout kind="alert">
Always cross-check the TXN ID and amount against bank or payment gateway records before approving. Incorrect approvals directly affect company cash and vendor credit balances.
</Callout>

### Reject a request

<Steps>
  <Step title="Review the request" icon="eye" title-type="p">
If the screenshot is missing, unclear, mismatched or looks fraudulent, reject the request.
  </Step>
  <Step title="Click Reject" icon="x-circle" title-type="p">
Click **Reject** on the card and confirm. The request moves to **Purchase Logs** as **Rejected** and no credits are added.
  </Step>
</Steps>

## Purchase Logs

A complete record of credit purchases (10 per page, with **Prev / Next** pagination and a "Showing X of Y" count).

### Filters & search

| Control | Description |
| --- | --- |
| Search | Search by **Payment ID / INV (invoice number) / TXN ID**. |
| Pick a date range | Limit logs to a start/end date — useful for monthly reconciliation. |
| Status | **All**, **Approved** or **Rejected**. |
| Payment type | **All payment types**, **PhonePe**, **Razorpay** or **Manual UPI**. |

### What each log entry shows

| Field | Description |
| --- | --- |
| Vendor name (vendor ID) | Vendor for the transaction. Vendors whose accounts were removed show as "Deleted Vendor". |
| Payment type badge | **PHONEPE**, **RAZORPAY** or **MANUAL UPI**. |
| Payment ID & date/time | Reference number and when the request was created. |
| TXN ID | Gateway transaction ID (Razorpay/PhonePe) or the ID entered by the admin at approval (Manual UPI). |
| Approved / Rejected time | When the request was actioned. |
| Amount / Credits | INR paid and credits issued. |
| Download Invoice | Icon to download the invoice for the transaction. |

### Statements

At the bottom of the tab:

- **Download statement** — exports the credit purchase statement.
- **Download GST Statement (for CA)** — exports a GST statement for the accountant.

## Business logic

```plaintext
Vendor buys credits
   ├─ PhonePe → auto-approved → logged automatically
   └─ Manual UPI → request appears in Credits Purchase (Pending)
            ↓
      Admin reviews screenshot → Approve (enter TXN ID) or Reject
            ↓
      Approved → credits added to vendor wallet | Rejected → no credits
            ↓
      Entry recorded in Purchase Logs
```

Each purchase converts INR to credits at the platform rate; the **Credits** value on each card or log row shows exactly what the vendor receives.

<Callout kind="tip">
Use Purchase Logs (with the date range and payment type filters) for monthly reconciliation, audits and dispute handling. Vendors running low on credits can be tracked on the **Low Credit** screen.
</Callout>
