## Overview

Manage team users for Cashkr Web Article Strapi from the User collection type in the Content Manager. Use this page to search for existing users, adjust their details, and control who has access.

## What it shows

The User collection page shows:

- A list of team users with details like email, role, and access levels.
- A search and filter area for finding users by email or role.
- An **Add new entry** button to create a new user.
- A settings icon that controls the view of the user page.

## Common tasks

Use the following flow to work with users in Strapi.

<Steps>

<Step title="Open the User collection type">

- Open the Content Manager.
- Select the **User** collection type.

</Step>

<Step title="Search and filter users">

- Use the search box to look up users by email.
- Apply filters to narrow users by role.

</Step>

<Step title="Create a new user">

- Click **Create new entry**.
- Add user details such as email, role, and access level.
- Save the new entry.

</Step>

<Step title="Update an existing profile">

- Select a user from the list.
- Edit fields such as email, role, or access levels.
- Save your changes.

</Step>

<Step title="Delete a user with confirmation">

- Select the user you want to remove.
- Use the delete action and confirm removal to complete the deletion.

</Step>

</Steps>

## System logic

<Callout kind="info">

User changes affect login access immediately after you save the entry.

</Callout>

<Callout kind="alert">

Deleted users are deactivated. Removal requires confirmation before the system applies the deletion.

</Callout>

## Connections

Integrated with Strapi’s authentication API.
