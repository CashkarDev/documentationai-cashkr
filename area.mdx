## Overview

Areas & Zones controls where Cashkr operates — which pincodes are serviceable, which device types are available in each area, how pincodes are grouped into zones, and how vendor coverage and order performance are distributed across cities.

Use this screen to expand into new locations, monitor coverage gaps, and align vendor onboarding with real customer demand.

## Where to find it

Open **System → Locations → Areas & Zones** in the left sidebar (route `/areas`). The breadcrumb shows **Dashboard / Areas**.

The screen is organized into eight tabs. The selected tab is kept in the URL (`?tab=matrix`, `?tab=zones`, and so on):

| Tab | Purpose |
| --- | --- |
| Matrix | Pincode and zone-wise demand, order performance and vendor capacity per device type |
| Zones | Create and manage named groups of pincodes |
| Map | Geographic coverage map of serviceable areas and vendors |
| Pincodes | Master list of serviceable pincodes (default list view) |
| Cities | City-level summary with a Toggle All control |
| Unserviced | Lost demand from pincodes with no coverage |
| Onboarding | Vendor onboarding funnel and live vendors by city |
| Reports | City completion and failure analysis |

<Callout kind="info">
The **Import Excel**, **Delete via CSV** and **Add New Area** buttons in the page header are shown only on the Pincodes tab.
</Callout>

## Tabs reference

<Tabs>
  <Tab title="Matrix">

The Matrix tab (**Area Matrix — Live & Verified**) shows pincode and zone-wise order performance, lead velocity and a vendor capacity matrix across all device types.

**Header controls**

- **Date range** — Defaults to the last 30 days.
- **Refresh** — Reload the matrix.
- **Export CSV** — Download the matrix.

**Summary cards**

| Card | Meaning |
| --- | --- |
| Tracked Pincodes | Total pincodes tracked, and the number of cities they span |
| Total Leads | Leads in the selected period |
| Completed Orders | Completed orders out of orders placed |
| Completion Rate | Completed ÷ placed, with the failed count |
| High Demand Zones | Zones with more than 5 leads per vendor |
| Uncovered Gaps | Pincodes with demand but 0 vendors (click to filter) |

**High-Demand Leaderboard**

A collapsible panel for the selected dates with two lists:

- **Top High-Demand Zones** — Ranked by lead volume. Each card shows city, pincode count, vendor count, completion %, leads, orders and the leads-per-vendor ratio (l/v). Hot zones carry a **High** badge.
- **Top High-Demand Pincodes** — Ranked by order velocity, with zone, vendor count, fulfilment %, ads status, leads and completed orders.

**Filters**

- **Search Area** — Search by pincode or location.
- **City**, **Zone**, **Device Type**, **Time Window** (time slot) dropdowns.
- **Full Power only (3+ vendors)**
- **High Demand only (≥ 3 leads)**
- **Gaps with 0 vendors only**
- **Show test data**

A counter shows how many pincodes match (for example, "Filtering: 2026 of 2026 pincodes").

**Table columns**

| Column | Meaning |
| --- | --- |
| Pincode / Location | Pincode with city and state |
| Zone | Zone the pincode belongs to |
| Total Leads | Leads in the period |
| Orders / Completed / Failed / Open | Order outcomes for the pincode |
| Comp % | Completion percentage |
| Ads Status | **Full Power** (3+ vendors), **Yes** or **No** |
| Phone, Tablet, Laptop, Mac, Console, Watch, Camera, Headphone | Number of live vendors covering each device type |
| Total Vendors | Total live vendors covering the pincode |

The table is paginated (25 rows per page by default, adjustable via **Rows per page**).

<Callout kind="info">
The Matrix counts only approved and live vendors. Vendors on hold or pending approval do not appear in the coverage numbers.
</Callout>

  <Tab title="Zones">

The Zones tab lets you create and manage geographic zones that group multiple pincodes under a named region.

**Table columns**

- **Name** — Zone name, with an optional description (for example, the localities it spans).
- **Location** — City and state.
- **Pincodes** — Number of pincodes in the zone.
- **Vendors** — Number of vendors in the zone.
- **Actions** — Edit and delete icons.

The list is paginated (10 zones per page).

**Add New Zone**

Click **Add New Zone** to open the **Create New Zone** dialog:

| Field | Notes |
| --- | --- |
| Zone Name * | e.g. "North Mumbai" |
| City * | Select from a dropdown |
| State * | e.g. "Maharashtra" |
| Description | Optional |
| Assign Pincodes | Search by pincode, city or state and add pincodes; the **Selected Pincodes** list shows what is assigned |

Click **Save Zone** to create it, or **Cancel** to close.

  <Tab title="Map">

The Map tab shows a **Coverage Map** of serviceable areas and vendor coverage.

**Controls**

- **Vendor** — All Vendors or a specific vendor.
- **View Mode** — **Status** (vendor live / hold colouring) or **Zones** (zone colouring).
- **Zone** — Limit the map to one zone.
- **Device** — All or a specific device type.
- **Clear** — Reset the filters.
- **Areas count** — Number of areas currently plotted.
- **Select Area** — Select an area directly on the map.
- **Fix Coords** — Correct coordinates for areas plotted in the wrong place.
- **+ / −** — Zoom.

  <Tab title="Pincodes">

The Pincodes tab is the master list of serviceable areas, one row per pincode.

**Table columns**

- **Select** checkbox (with select-all on page)
- **Pincode**, **City**, **State**
- **Device Types** — Chips for each enabled category (Mobile, Laptop, Tablet, Mac, Camera, Console, Watch, Headphone, etc.)
- **Serviceable** — Toggle showing whether the pincode accepts orders
- **Created At**
- **Actions** — **Edit** and **Delete**

**Search & filters**

- **Search by pincode, city, or state** and click **Search**.
- **Filters** — Additional filter options.

**Header actions**

<Steps>
<Step title="Add New Area" icon="plus" title-type="p">
Opens a dialog with **Pincode** (6-digit), **City**, **State**, **Device Types** checkboxes (Mobile, Tablet, Desktop, TV, Watch, Console, Drone, Smartwatch, Mac, Laptop, Camera, Headphone) and **Is Area Serviceable** (checked by default — "Enable this if the area is ready for service"). Click **Add Area** to save.
</Step>
<Step title="Import Excel" icon="upload" title-type="p">
Opens **Import & Update Areas from Excel**. Upload a .xlsx, .xls or .csv file — new pincodes are added and existing pincodes are updated. Required columns: **Pincode**, **City**, **State**; optional **Device Types** and **Serviceable** (Yes / No). **Download Sample Excel** gives a template, and **Validate & Preview** shows a full validation preview before anything is saved.
</Step>
<Step title="Delete via CSV" icon="trash-2" title-type="p">
Opens **Delete Pincodes via CSV / Excel**. Upload a file with a **Pincode** column listing pincodes to remove permanently. **Download Sample CSV** gives a template; **Validate & Preview** shows a preview before any data is deleted.
</Step>
</Steps>

<Callout kind="alert">
Disabling or deleting a pincode immediately stops new orders from that area. Existing orders are not affected. Deletions via CSV are permanent.
</Callout>

  <Tab title="Cities">

The Cities tab shows one card per city with:

- **City** and **State**
- **Total Pincodes** — Pincodes added under the city
- **Serviceable** — How many of those are currently serviceable
- **Toggle All** — Enable or disable every pincode in the city at once

The list is paginated (10 cities per page).

<Callout kind="alert">
Toggle All enables or disables every pincode in the city in one action. Confirm operational readiness before switching an entire city.
</Callout>

  <Tab title="Unserviced">

The Unserviced tab (**Unserviced Demand & Failed Pincodes**) identifies customer demand in pincodes with zero vendor coverage so you can prioritise expansion.

**Header controls** — Date range (defaults to the last 30 days) and **Export CSV**.

**Summary cards**

| Card | Meaning |
| --- | --- |
| Total Lost Demand | Combined unserviced leads and failed pincode checks |
| Unserviced Leads | Internal checkout attempts from unserviced pincodes |
| Affected Cities | Cities with lost customer demand |
| Failed Pincodes | Pincodes in your pincode list that are not yet serviced |

An info note explains that checks from pincodes **not** in your pincode list are counted separately and are not broken down by city (analytics only reports the visitor's location). Add such a pincode under Pincodes and its demand will appear in this list.

**Filters** — Search, **City**, **Device Type**, **Time Window**, **Show test data**.

**Views**

- **City-Wise Grouped** — Cities ranked by lost demand, each expandable (**Expand All / Collapse All**) to show its pincodes.
- **All Pincodes** — A flat list of every unserviced pincode.

**Pincode columns** — Pincode, Location, Unserviced Leads, GA4 Failed Checks, Total Demand, Detected Devices, and **Add Area** to onboard the pincode directly.

The Onboarding tab shows the **Vendor Onboarding Funnel** and **Live Vendors by City**.

- **Pending** — Vendors registered but not yet live.

  <Tab title="Reports">

The Reports tab (**City Completion & Failure Analysis**) shows where orders complete, where they fail, and who owns each failure.

**Header controls** — Date range and **Export CSV**.

**Summary cards**

| Card | Meaning |
| --- | --- |
| Orders | Orders in the period, with city and vendor counts |
| Raw Completion | Completed ÷ resolved orders |
| Operational Completion | Completion excluding pre-visit drops |
| Failures | Total failures split into **Vendor** and **Customer** |

A note explains that failures before a vendor engages (unreachable, not interested, just checking, duplicate, sold elsewhere) measure lead quality rather than execution, so **Operational Completion** excludes them — use it to judge vendors and cities.

**Filters** — Search city, **City**, **Vendor**, **Device**, **Show test data**.

**City Breakdown** — City, Orders, Completed, Failed, Open, Raw %, Operational %, Top Failure Reason.

**Vendor Pickup & Completion** — Vendor, City, Picked Up, Completed, Failed, Raw %, Operational %. Sort options include **Most orders picked up**, with a volume filter (**Any volume**).

  </Tab>

## Admin responsibilities

- Review the **Matrix** regularly for device coverage gaps and high-demand zones (high leads per vendor).
- Add new **pincodes** as the business expands, singly or via **Import Excel**.
- Use the **Cities** tab to pause or resume whole cities during operational changes.
- Monitor **Unserviced** to find high-demand pincodes and add them with **Add Area**.
- Keep **zones** updated as new pincodes are added.
- Use **Reports** to see which cities and vendors fail orders and why.
- Track the vendor funnel in **Onboarding**, especially in under-served cities.

## Related modules

- **Customer App and Website** — Customers in an unserviceable pincode cannot place new orders.
- **Vendors** — Vendor pincode assignments drive the Matrix coverage counts.
- **Leads** — Converted leads are assigned to vendors based on the customer's pincode.
- **Orders** — Orders are created only for serviceable pincodes with at least one live vendor.

## Important notes

<Callout kind="info">
Pincodes in the Unserviced tab represent real customer demand. Prioritise high-demand pincodes to capture missed business.
</Callout>

<Callout kind="info">
Test data is hidden by default on Matrix, Unserviced and Reports. Tick **Show test data** only when debugging.
</Callout>
