## Overview

The Banners section in the Admin Panel lists all marketing banners in both list and grid view. Each entry shows its image, type, device compatibility, platform targeting, current status, order, and slug.

<Callout kind="info">
  Use Banners to control which offers and visuals appear on the website and app, for which devices, and in what order.
</Callout>

## What the banner list shows

Each banner row/tile includes:

- **Banner image** – visual asset used on the website or app.
- **Banner type** – Regular or Offer.
- **Device compatibility** – which device types the banner supports.
- **Platform targeting** – Web Browser, Web Mobile View, or Mobile.
- **Status** – Active or Inactive.
- **Order** – position in the rotation (for example, 1, 2, 3).
- **Slug** – unique banner slug (for example, `home-banner`, `offer-banner`).

## Typical use cases

Marketing or operations teams use banners to:

- Push time-bound or permanent offers to specific audiences.
- Customize visual messaging per device or platform.
- Update or deactivate outdated banners.
- Control the display order of banners by assigning order as 1, 2, 3, and so on.

## Filters and search options

Use filters and search to quickly find specific banners:

- **Search by** – Banner Type, Platform, Device Type.
- **Filter: Banner Type** – Regular, Offer.
- **Filter: Device Type** – All Platforms, Mobile Landing, Laptop Landing, Tablet Landing, Mac Landing.
- **Filter: Platform** – Web Browser, Web Mobile View, Mobile.

## Admin workflow

<Steps>
  <Step title="Add new banner" icon="plus">
    Use this when you need to launch a new Regular or Offer banner.

    - **Upload banner image** – select the creative to display.
    - **Date** – set starting date and expiry date.
    - **Status** – choose Active or Inactive.
    - **Banner Type** – select Regular or Offer.
    - **Platform** – choose where the banner will appear based on customer touchpoint.
    - **Order** – set the order of the banner (for example, 1, 2, 3).
    - **Slug** – define the banner slug (for example, `home-banner`, `offer-banner`).
    - **Device Type** – choose where it will render (for example, browser vs mobile app). This is valid and available for offer banners only, and appears only when adding offer banners.
  </Step>

  <Step title="Update banner" icon="edit">
    Edit an existing banner when you need to adjust content, targeting, or timing.

    - Open the banner you want to modify.
    - Update any of the fields listed above (image, dates, status, banner type, platform, order, slug, or device type where applicable).
    - Save your changes so updates reflect on the website and app.
  </Step>

  <Step title="Delete banner" icon="trash">
    Remove banners that are no longer required.

    - Select the banner you want to remove.
    - Use the delete option to permanently delete the banner from the system.
  </Step>

  <Step title="Switch between list and grid views" icon="monitor">
    Change how banners are displayed for easier browsing.

    - Use the view toggle to switch between **List View** and **Grid View**.
    - Pick the view that makes it easier to scan images, statuses, and ordering.
  </Step>
</Steps>

## Connections and placement

Banners connect directly to:

- **Customer website and app** – banners render across key surfaces.
- **Placement logic** – ensures banners appear in the correct visual positions based on device type and page type.
