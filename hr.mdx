## Overview

Use this page to track HR-owned tools and platforms at Cashkr so HR and cross-functional teams know what exists, what it is used for, and who manages access. Keep this page lightweight and focused on the tools that are actually in use.

<Callout kind="info">

Keep each tool entry up to date with the current owner, access method, and any HR or compliance notes (for example, employee data, contracts, or payroll information).

</Callout>

## Adding a new tool

When you add a new HR tool to this page, capture:

- **Tool name** – The exact product name (for example, Workday, Zoho People).
- **Use case** – A short description of what the tool is used for (for example, payroll processing, leave management, social hiring).
- **Example or notes** – A concrete example, link, or note that helps others understand how HR uses it (for example, which HR process it supports or which team uses it most).
