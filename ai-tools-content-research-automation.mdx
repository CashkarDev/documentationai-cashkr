## Why this matters

<Callout kind="info">

AI tools help every team at Cashkr move faster without sacrificing quality. They reduce time spent on first drafts, research, and boilerplate code, so you can focus on judgment, review, and final decisions. Used well, they support freshers with examples, give seniors leverage to scale output, and keep responses consistent across channels.

</Callout>

## Tools we use

<Card title="ChatGPT" icon="code">

Use ChatGPT for written work that needs structure and clarity: SOPs, customer replies, ad copy, blog drafts, and lightweight code help. It is usually the first stop when you need a quick draft that you will then edit.

**Example:** When a customer asks *"Can I sell without a bill?"*, ask ChatGPT to draft a polite, accurate reply that matches our policy, then review and send from your official channel.

</Card>

<Card title="Perplexity AI" icon="search">

Use Perplexity AI for research-heavy questions where you need summarized answers with sources. It is more focused than a generic search engine and helps you see key points and references quickly.

**Example:** For a brief on *"top buyback platforms in India"*, use Perplexity to collect a concise summary with citations, then cross-check links and adapt the findings to Cashkr context.

</Card>

<Card title="Claude" icon="book-open">

Use Claude when you need longer-form, structured content such as scripts, detailed blog posts, explainers, or story-style content. It is strong at keeping a narrative consistent over many paragraphs.

**Example:** For a 1000-word blog on *"Why Recycling Phones Matters"*, outline the key points, share any existing Cashkr materials, and let Claude generate a flowing draft for you to refine.

</Card>

<Card title="Cursor AI" icon="terminal">

Use Cursor AI inside the editor for development work: writing new functions, refactoring, and debugging. It is most effective when you give it clear intent and relevant files.

**Example:** If you are stuck on an API endpoint, highlight the relevant code, describe the expected behavior, and let Cursor suggest or fix the function, then run tests and review the diff before merging.

</Card>

<Card title="Sora" icon="play-circle">

Use Sora for short, professional videos where we need a visual story without a full shoot. It works best when you provide a clear script and visual guidance.

**Example:** To create a quick ad video showing the *"Cashkr pickup process in 30 seconds"*, write a simple scene-by-scene script, feed it to Sora, then review the output for accuracy before using it in campaigns.

</Card>

## How we use these daily

- **Marketing team**
  - Drafts Instagram captions, ad copy, and hooks.
  - Generates blog outlines and first drafts.
  - Creates scripts for Sora videos and landing page sections.

- **Tech team**
  - Uses Cursor to debug issues and suggest fixes.
  - Generates test cases and example payloads.
  - Sketches API endpoints or utility functions before refining manually.

- **Operations team**
  - Drafts SOPs and internal process documents.
  - Prepares vendor training material and checklists.
  - Generates suggested customer replies, FAQs, and live chat prompts that are then reviewed.

- **Support and sales**
  - Uses ChatGPT to shape consistent, polite responses to common questions.
  - Adapts scripts for calls, WhatsApp, and email follow-ups.
  - Prepares variant replies for different customer scenarios while keeping policy consistent.

## Typical AI workflow at Cashkr

<Steps>
  <Step title="Define the task clearly" icon="edit">

  Start by writing the exact outcome you want: audience, channel, tone, length, and goal. For example, specify whether you need a WhatsApp reply, blog section, SQL query, or API helper function.

  </Step>

  <Step title="Provide context and constraints" icon="info">

  Share relevant background like Cashkr policies, links to existing docs, sample messages, or code files. Mention any hard rules such as legal constraints, brand voice, data accuracy, or performance limits.

  </Step>

  <Step title="Generate a draft, not the final answer" icon="play-circle">

  Ask the AI tool for a first draft or set of options. For larger tasks, generate sections incrementally (for example, outline → intro → body → conclusion, or interface → implementation → tests).

  </Step>

  <Step title="Review, verify, and adapt" icon="check-circle">

  Check facts, numbers, and code against trusted sources like our docs, dashboards, or repos. Edit for clarity, tone, and correctness. For code, run tests and reviews; for content, ensure it matches brand and policy.

  </Step>

  <Step title="Publish, ship, and reuse" icon="rocket">

  Once you are confident in the output, publish it in the right channel (campaign, SOP, ticket response, codebase). Save strong prompts and good outputs in our knowledge tools so others can reuse and improve them.

  </Step>
</Steps>
