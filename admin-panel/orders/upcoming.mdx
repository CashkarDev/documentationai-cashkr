## Overview

Open **Orders → Active → Upcoming** (breadcrumb *Dashboard / Orders / Upcoming*). This view lists orders whose pickup is still ahead, so you can prepare for the coming pickups before they become due.

When there are no matching orders the page shows **No Orders Found** — *There are no orders matching your current filters.*

## What the screen shows

The table uses the same layout as the other order lists (Created At, Model, City, Type, Status and SLA). Click any row to open the order detail drawer — see [All Orders → Order detail drawer](/all-orders#order-detail-drawer).

## Filters and search

- **Search orders...** box in the header.
- Click **Filters** to open the filter panel:

| Filter | Options |
| --- | --- |
| **Device Type** | Mobile, Laptop, Macbook, Tablet, AC, Desktop, Camera, Console, TV, Headphone, Watch, Drone |
| **City** | Serviceable cities |
| **From date / To date** | Date range |
| **Show orders with Test accounts** | Include test-account orders |

Click **Apply Filters** to apply or **Reset** to clear.

<Callout kind="info">
  Upcoming has no Status filter — the view itself defines which orders appear. Use **All Orders** if you need to filter by a specific status.
</Callout>
