## Overview

Use the Mac page (**Mac Management**, route `/mac`) to manage all Apple Mac product lines available for buyback: iMac, MacBook Air, MacBook Pro, Mac Mini, and Mac Studio. It has four tabs: **Models**, **Brands**, **Classes**, and **Pricing**. The layout follows the [Phone](/phone) page, but Mac classes use laptop-style condition codes and Mac pricing has only two age brackets after the base price.

## Tabs

<Tabs>
  <Tab title="Models">
    ### What you see

    The Mac model list (20 per page) has a checkbox, expand chevron, **Model** (image, name with RAM / storage in brackets, and product line • chip generation such as Intel 2017 or M1), **Code** (for example `IMAC0005`), **Price**, **Class**, **Variants**, and **Actions**. Mac models often have several variants because of chip, RAM, and storage combinations.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774777798526-ca19op2ifu-mac-models.mac models?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="838" alt="Admin Panel Mac Models tab listing MacBook, iMac, and other Mac models with variants, pricing, and actions" />

    ### Search and filters

    - **Search models…** with **Filter**, and a refresh icon.
    - **All Brands** — iMac, Mac Mini, Mac Studio, MacBook Air, MacBook Pro.

    ### Row and bulk actions

    Row menu: **Edit Model**, **Add Variant**, **View SEO**, **Duplicate**, **Delete**. Variant rows have edit and delete icons. Selecting rows shows **Update Class**, **Regenerate SEO**, and **Clear Selection**.

    ### Add

    <Steps>
      <Step title="Open the Add Model form" icon="plus">
        Click **Add Model** ("Add a new mac model").
      </Step>
      <Step title="Basic Info" icon="edit">
        **Brand*** (product line), **Model Name*** (for example MacBook Air M2), **Series (Optional)** (for example Air, Pro, Studio), **Image**, **Storage (GB)** (for example 256, 512, 1024), and **RAM (GB)** (for example 8, 16, 32).
      </Step>
      <Step title="URL & Code and SEO" icon="link">
        Generate or enter **Base URL** and **Model Code**, then use **Auto-Generate SEO** or fill the SEO fields (Page Title, Page Description, H1, Image Alt Text, Variant Title, Variant Description).
      </Step>
      <Step title="Pricing" icon="settings">
        Enter **Base Price (₹)***, choose **Pricing Class***, and optionally use **Bulk Add Variants** for other storage/RAM configurations.
      </Step>
      <Step title="Save" icon="check-circle">
        Click **Create Model**.
      </Step>
    </Steps>

    <Callout kind="alert">
      Before deleting a Mac model, check the inventory and order modules to ensure the model is not linked to active inventory or live orders.
    </Callout>
  </Tab>
  <Tab title="Brands">
    ### What you see

    For Mac, "brands" are the Apple product lines: **iMac**, **MacBook Air**, **MacBook Pro**, **Mac Mini**, and **Mac Studio**. The table shows Brand ID, Brand Name, Device Type, Brand Link, Brand Image, and Title.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774777839118-qmb0k6dofrg-mac-brands.mac brands?q=85&fm=auto&auto=compress%2Cformat" width="1915" height="830" alt="Admin Panel Mac Brands tab showing Apple Mac product lines" />

    Search, Filters, **Add New Product** (Add New Brand), and Brand Details (Edit, Delete) work as on the Phone Brands tab. Set **Device Type** to Mac.

    <Callout kind="alert">
      Verify that no active Mac models use a brand before deleting it, or reassign those models first.
    </Callout>
  </Tab>
  <Tab title="Classes">
    ### What you see

    The **Mac Classes** table has five classes (A–E) with ID, Class Type, Credit, Dead Price, Tier, and these condition codes:

    | Group | Codes | Options |
    | --- | --- | --- |
    | Warranty | W1–W3 | 0–3 months, 3–11 months, 11+ months |
    | Battery | B1–B4 | Excellent (80–100%), Good (60–80%), Average (40–60%), Poor (&lt;40%) |
    | Screen (size) | S1–S4 | 10–12 inch, 13–14 inch, 15–16 inch, 16+ inch |
    | Physical | P1–P16 | Display Changed, Keyboard Issues, Trackpad, Speaker, Wifi/Bluetooth, Fingerprint/TouchID, Charging, Battery, USB Port, TouchBar Issue, WebCam, Charger, Hard Disk, Display Issue, Hinge, Motherboard |
    | Accessories | A1–A3 | Bill, Box, Charger |

    There is no Technical tab for Mac.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774777990376-sfze9hj7ma-mac-classes.mac classes?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="822" alt="Admin Panel Mac Classes tab listing condition-based classes for Mac devices" />

    ### Add

    <Steps>
      <Step title="Open the Add Class flow" icon="plus">
        Click **Add New Class** ("Create a new pricing model for Mac devices").
      </Step>
      <Step title="Basic Info" icon="edit">
        Enter **Class Type***, **Tier**, **Credit**, and **Dead Price**.
      </Step>
      <Step title="Condition tabs" icon="settings">
        Fill the Warranty, Battery, Screen, Physical, and Accessories tabs. Each value accepts a flat amount or a percentage.
      </Step>
      <Step title="Save the class" icon="check-circle">
        Click **Create Class**.
      </Step>
    </Steps>

    Use the row menu to **Edit** or **Delete**, and **Export CSV** to download.

    <Callout kind="alert">
      Check which Mac models use a class before deleting it, and reassign them to avoid missing or incorrect pricing.
    </Callout>
  </Tab>
  <Tab title="Pricing">
    ### What you see

    The Mac Pricing tab uses the shared layout (Pricing Overview, BuyBack bonus and Bulk bonus, Filters, All Brands, search, Export, Import). Unlike Phone, it shows **two** age brackets after the base price:

    | Column | Description |
    | --- | --- |
    | Model / Specs | Model name, product line, storage, and RAM |
    | Class | Class dropdown |
    | Base Price | 0–3 month price with ✎ inline edit |
    | Bonus | Model bonus or **+ Add** |
    | 3-11 Months | Price after the class's 3–11 month deduction |
    | Above 11 Months | Price after the 11+ month deduction |

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774778035275-1kz0sdno9xt-mac-pricing.mac pricing?q=85&fm=auto&auto=compress%2Cformat" width="1918" height="830" alt="Admin Panel Mac Pricing tab showing age-bracket prices for Mac models" />

    ### Edit

    Edit the base price inline or change the class; the bracket prices recalculate. For many models, select rows and use **Update Price** or **Update Class**. Each row's **Price History** shows past changes.

    <Callout kind="alert">
      A Mac model without a price does not show a buyback value to customers. Always set the base price and class when you create a model.
    </Callout>
  </Tab>
</Tabs>

## Connections across device pages

- **Customer app and website** — Model, pricing, class, and brand changes reflect during device search and evaluation.
- **Brands** — Populate the brand dropdown when creating or editing models.
- **Classes** — Available for assignment during model creation and in the Pricing tab.
- **Pricing** — Updates the model's displayed price on the product page and during evaluation.

## Important notes

<Callout kind="alert">
  Do not leave any active model without pricing. Missing pricing stops customers from seeing buyback values and can block order creation.
</Callout>

Review classes whenever market conditions change so buyback prices stay competitive across device types.

<Callout kind="alert">
  Treat deletions for models, brands, and classes as destructive changes. Confirm that no live orders or inventory items depend on the entry before you remove it.
</Callout>
