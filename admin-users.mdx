## Overview

**Sidebar path:** Users → Admin Users (`/admin`). The page is titled **Admin Management** — *Manage administrative users, permissions, and team structure*.

Use it to add, edit, deactivate or delete admin accounts, assign roles and page permissions, see the reporting structure, assign leads and orders to team members, and audit admin actions. It has four tabs: **Admins**, **Hierarchy**, **Assignments** and **Activity**.

### Search and filters

- **Search admins** by name or email.
- **Filter:** All Users, Root Admins, Regular Admins, Active, Inactive. The list opens filtered to **Active**.

### Backfill lead assignment

**Backfill 3-day leads** re-runs automatic lead assignment for the last three days. The arrow next to it offers:

| Option | When to use |
| --- | --- |
| **Last 3 days (both)** | Routine catch-up. Safe to re-run. |
| **ALL unassigned — vendor onboarding only** | When a new vendor-onboarding agent joins, or to clear the existing backlog. |
| **ALL unassigned — sales leads only** | When a new sales agent joins. |
| **ALL unassigned — everything** | Nuclear option — distributes every unassigned lead in the system. |

<Callout kind="alert">
The "ALL unassigned" options redistribute leads across agents in bulk. Use them only when you intend to reassign the whole backlog.
</Callout>

### Add Admin

**Add Admin** opens **Create New Admin**:

| Field | Details |
| --- | --- |
| **Name**, **Email**, **Password** | Login identity; the email is the login. |
| **Role** | Super Admin (full system access & team management), Manager (team management & assignments), Team Lead (limited team management), Executive (individual contributor), Sales Agent (receives auto-assigned B2C/B2B leads), Vendor Onboarding Agent (receives auto-assigned vendor leads). |
| **Department** | B2B Sales, B2C Operations, Customer Support, Logistics, Finance, HR. |
| **Admin Type** | **Root Admin** (full system access) or **Regular Admin** (custom permissions). |
| **Page Permissions** | For Regular Admins: pick pages one by one (shown as "0 of N pages"), per group or with **Select All / Clear All**. Groups follow the sidebar: Dashboards, Orders, Vendors, Inventory & Catalog, Merchandise, Finance, Channels, Marketing, System, B2C Sales, HR — each with sub-groups and a **View** permission per page. |

Click **Create Admin** to save.

### Edit and delete

- **Edit** opens **Edit Admin** with the same fields, plus **New Password** (leave blank to keep the current one) and an **Account active** checkbox.
- **Delete** permanently removes the admin.

<Callout kind="alert">
To revoke access, untick **Account active** instead of deleting — a delete also wipes the admin's activity history.
</Callout>

**Team Hierarchy** shows the organisational structure and reporting lines.

- Switch between **Tree** and **List** views; use **Expand All** / **Collapse All**.

## Permission-based access control

- **Root Admins** can access every section.
- **Regular Admins** only see the pages ticked in **Page Permissions**; other sections are hidden from the sidebar or blocked.
- Permission changes take effect when saved.

<Callout kind="info">
Grant the minimum pages each person needs. This protects financial data, vendor management and operational tools.
</Callout>

## Admin responsibilities

- Review the list regularly; deactivate accounts of people who have left.
- Never share credentials — every team member gets their own account.
- Watch **Last Login** for unused accounts.
- Use **Activity** to audit sensitive changes (deletes, pricing, admin edits).
- Keep the number of Root Admins low.

## Connections to other modules

- **Master Logs** — admin actions also appear in Master Logs under the admin's name.
- **Leads / Orders** — Sales Agents and Vendor Onboarding Agents receive auto-assigned leads; Assignments and Backfill control distribution.
- **All modules** — page permissions decide which sidebar sections each admin can open.
