## What is Refer & Earn?

Refer & Earn lets existing customers earn rewards by inviting new customers to use Cashkr. When a new customer registers using a referral code and completes an order, both the referrer and the referee receive rewards.

<Callout kind="info">

- Customers invite friends using a **permanent referral code**.
- The new customer (referee) **registers once** with the referral code; the code is then locked to their account.
- Rewards trigger **after order completion**:
  - Referee reward is applied automatically at checkout.
  - Referrer reward is generated as **pending**, then credited to the Cashkr Wallet after admin approval.

</Callout>

## How Refer & Earn works

<Steps>
  <Step title="Generate the referral code" icon="zap" title-type="p">

  - Open the **Refer & Earn** section on the Cashkr website or in the customer app.
  - Click **Generate Code**.
  - The system generates a **unique referral code** for the customer.

  The referral code is permanent for that customer and works across all active referral programs.

  </Step>

  <Step title="Share the referral code" icon="arrow-right" title-type="p">

  - The customer shares their referral code with friends via:
    - WhatsApp
    - SMS
    - Social media
    - Copying and sharing the link

  </Step>

  <Step title="Friend registers using the code" icon="users" title-type="p">

  - The friend (a **new customer**) registers on Cashkr using the referral code.
  - The system locks that referral code to the new customer's account.
  - A referral code can be used **only once per new customer**.

  Deleting an account and re-registering does not reset the customer's referral eligibility.

  </Step>

  <Step title="Order completion and reward generation" icon="check-circle" title-type="p">

  **For the friend (referee)**

  - At checkout:
    - The system applies the reward automatically.
    - The discount depends on the **active referral offer**.
    - The discount is calculated based on the **device-generated price**.
  - The vendor pays the **final amount**.
  - The system approves the referee reward **instantly**.

  **For the referrer**

  - Once the referee completes an order:
    - The system generates a reward for the referrer.
    - The reward initially appears as **pending**.
  - After admin approval:
    - The system credits the reward to the referrer's **Cashkr Wallet**.
    - The reward amount is calculated based on the **final price** on which the vendor completed the order.

  </Step>
</Steps>

## Where you see referral earnings

### Refer & Earn section

Use the Refer & Earn section to track referral activity:

- View the customer's **referral code**.
- Track **referred users**.
- View each referral's **reward status**.

### Wallet section in customer app

Use the Wallet section in the customer app to see wallet-level aggregates:

- **Total Balance** – Amount currently available for withdrawal.
- **Total Earned** – Lifetime earnings from referrals.
- **Total Withdrawn** – Amount already withdrawn from the wallet.

## Important Refer & Earn rules

- Each customer has **one permanent referral code**.
- A new customer can use a referral code **only once**.
- Deleting an account and re-registering **does not** reset referral eligibility.
- The system grants rewards **only after**:
  - The order is completed.
  - All active referral program conditions are met.
- Referrer rewards require **admin approval** before crediting to the Cashkr Wallet.
