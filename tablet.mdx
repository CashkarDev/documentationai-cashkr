## Overview

Use the Tablet page under Admin Panel → Devices to manage all tablet models available for buyback on the Cashkr platform. The structure and functionality mirror the Phone page, with tabs for Models, Brands, Classes, and Pricing. Every change you make here updates tablet options and prices shown on the customer app and website in real time.

## Tabs

<Tabs>
  <Tab title="Models">
    ### What you see

    The Models tab lists all configured tablet models available for buyback.

    Each row typically includes:

    - Model name and storage variant (for example, iPad 9th Gen 64 GB)
    - Brand and series
    - Device image
    - Unique system code
    - Base buyback price
    - Assigned class
    - Number of variants
    - Available actions such as edit and delete

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774767147437-g2snqxhvjms-tablet-model-section.tablet model section?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="834" alt="Tablet models tab showing a list of configured tablet models with columns for brand, storage, class, base price, and actions." />

    All fields and capabilities are identical to the Phone Models tab, but scoped only to tablet devices such as iPads and Samsung Galaxy Tabs.

    ### Search and filters

    Use the controls at the top of the table to quickly locate specific tablet models:

    - **Search by model name** to find a particular tablet.
    - **Filter by brand** using the All Brands dropdown to narrow the list to a specific manufacturer.

    ### Add model

    Click **Add Model** in the Models tab to create a new tablet entry. The form has the same three sections as Phone models: Basic Info, Pricing and Variants, and SEO Information.

    <Steps>
      <Step title="Open the add model form" icon="plus">
        In the Tablet → Models tab, click Add Model to open the create model form.
      </Step>
      <Step title="Fill basic and pricing details" icon="edit">
        Enter model name, brand, series, storage variants, and base pricing, following the same structure as the Phone Models tab.
      </Step>
      <Step title="Set device type to Tablet" icon="settings">
        In the device configuration, ensure the Device Type field is set to Tablet so the model appears correctly in tablet flows.
      </Step>
      <Step title="Save and confirm" icon="check-circle">
        Review all details and save the model. The tablet becomes immediately available on the customer app and website for selection and price evaluation.
      </Step>
    </Steps>

    ### Edit model

    Edit any tablet model from the actions column in the table.

    - Update model details, pricing, variants, or assigned class as needed.
    - Keep Device Type set to Tablet to prevent the model from appearing in phone or other device categories.
    - Price changes you make in the Pricing tab automatically reflect on this model's product page and take effect immediately on the customer app and website.

    ### Delete model

    Use the delete action in the table to remove a tablet model that should no longer be available for buyback.

    <Callout kind="alert">
      Deleting a tablet model removes it from the Tablet catalog and from the customer app and website. Confirm that the model is no longer required for any ongoing or future campaigns before deleting it.
    </Callout>
  </Tab>

  <Tab title="Brands">
    ### What you see

    The Brands tab lists all tablet brands registered in the system, such as Apple, Samsung, Lenovo, and others.

    Each row typically includes:

    - Brand name
    - Device type scope
    - Status or visibility
    - Actions such as edit and delete

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774767169745-dh6tuh7xziv-tablet-brands-section.tablet brands section?q=85&fm=auto&auto=compress%2Cformat" width="1917" height="828" alt="Tablet brands tab listing available tablet brands like Apple and Samsung with options to add or edit brands." />

    All capabilities are identical to the Phone Brands tab, but applied to tablets.

    Brand data from this tab powers:

    - The brand dropdown during tablet model creation
    - Brand labels shown on the customer app and website

    ### Search and filters

    Use the search bar to find a brand by name. Filters are identical to those on the Phone Brands tab; use them as needed to narrow the list.

    ### Add brand

    Add a new tablet brand when you start buying back tablets from a new manufacturer.

    <Steps>
      <Step title="Open the add brand form" icon="plus">
        In the Tablet → Brands tab, click Add Brand to open the brand creation form.
      </Step>
      <Step title="Enter brand details" icon="edit">
        Fill in the brand name and any other required details following the same pattern as the Phone Brands tab.
      </Step>
      <Step title="Set device type to Tablet" icon="settings">
        Set the Device Type field to Tablet so this brand appears in tablet-specific brand dropdowns and listings.
      </Step>
      <Step title="Save and verify" icon="check-circle">
        Save the brand and confirm it appears in the Tablet Brands list and in the brand selector when adding or editing tablet models.
      </Step>
    </Steps>

    ### Edit brand

    Use the edit action in the Brands table to update brand details.

    - Adjust the brand name or display settings as needed.
    - Keep Device Type set to Tablet so tablet models continue to associate correctly with this brand.
    - Changes reflect automatically wherever the brand is shown on the customer app and website.

    ### Delete brand

    Delete a brand only when you no longer buy back tablets from that manufacturer and have handled any dependent models.

    <Callout kind="alert">
      If you delete a tablet brand that still has associated tablet models, those models may lose their brand association or become inconsistent. Review and update or remove dependent models before deleting a brand.
    </Callout>
  </Tab>

  <Tab title="Classes">
    ### What you see

    The Classes tab shows all condition-based classes configured for tablets.

    Classes work the same way as phone classes and typically cover:

    - Warranty condition
    - Battery condition
    - Screen condition
    - Physical condition
    - Technical condition
    - Accessories

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774767201637-6fwhf2sg1gg-tablet-classes-section.tablet classes section?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="827" alt="Tablet classes tab listing tablet condition classes with columns for condition rules and pricing impact." />

    All other fields and pricing logic are identical to the Phone Classes tab.

    ### Search and filters

    Use the search bar to find classes by name. Filters behave the same way as on the Phone Classes tab.

    ### Add class

    Create a new tablet class when you need a new condition profile that affects tablet pricing.

    <Steps>
      <Step title="Open the add class form" icon="plus">
        In the Tablet → Classes tab, click Add Class to open the class creation form.
      </Step>
      <Step title="Configure conditions and pricing" icon="edit">
        Define warranty, battery, screen, physical, technical, and accessories conditions, along with their pricing impact, following the same structure as phone classes.
      </Step>
      <Step title="Set device type to Tablet" icon="settings">
        Set the Device Type field to Tablet so the class appears only for tablets and not for other device categories.
      </Step>
      <Step title="Save and test" icon="check-circle">
        Save the class and verify that it appears for tablet models and that pricing updates as expected during tablet evaluation.
      </Step>
    </Steps>

    ### Edit class

    Edit an existing tablet class from the actions column to fine-tune condition rules or pricing logic.

    - Adjust condition thresholds or pricing values as business rules change.
    - Keep Device Type set to Tablet so the class remains scoped correctly.
    - Updates immediately affect tablet pricing wherever the class is used.

    ### Delete class

    Delete a class only when it is no longer needed for any tablet pricing logic.

    <Callout kind="alert">
      Removing a tablet class that is still assigned to models can disrupt pricing calculations. Before deleting, reassign affected tablet models to another class or update their configuration to avoid inconsistent customer pricing.
    </Callout>
  </Tab>

  <Tab title="Pricing">
    ### What you see

    The Pricing tab displays a table of all tablet models with their assigned class and warranty-based price slabs.

    You see:

    - Tablet model and brand
    - Assigned class
    - Four warranty brackets
    - Price values per warranty bracket

    The four warranty brackets and auto-update logic are identical to the Phone Pricing tab.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774767283958-cibenph4nh-tablet-pricing-section.tablet pricing section?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="826" alt="Tablet pricing tab showing tablet models with assigned classes and price slabs across warranty brackets." />

    ### Search and filters

    Use the controls at the top of the Pricing table to manage tablet pricing efficiently:

    - **Search by model name** to edit pricing for a specific tablet.
    - **Filter by device type** to confirm you are viewing only tablet models when adjusting tablet pricing.

    ### Add

    The Pricing tab does not create new models directly. New tablet models appear here automatically after you add them in the Models tab with Device Type set to Tablet and assign a class.

    ### Edit pricing

    Update tablet prices from the Pricing tab whenever buyback values change.

    - Select the tablet model row you want to update.
    - Edit the price slabs for each warranty bracket and confirm to save.
    - Changes reflect immediately on the customer app and website during tablet device evaluation and quote generation.

    <Callout kind="alert">
      Pricing changes on the Tablet Pricing tab apply instantly to all new tablet evaluations. Review updated prices carefully before saving, especially during large-scale updates or campaigns.
    </Callout>

    ### Delete

    Direct deletion is generally managed at the model level. To remove a tablet from pricing, delete or retire the underlying tablet model from the Models tab so it no longer appears for customer selection.
  </Tab>
</Tabs>
