## Adding a new tool

When you add a new tool to any section, create a new row in the relevant table and fill in:

- **Tools**: the exact tool name as used in billing or login.
- **Use case**: the primary job this tool does for marketing.
- **Example**: one concrete, real-world example of how we use it at Cashkr.

Keep descriptions short and action-focused so others can quickly understand when to use the tool.
