## Overview

Exporting data from the Admin Panel enables accurate reporting, analysis, audits, and day-to-day decision-making across teams.

Use exports for:

- Performance reviews and SLA tracking
- Vendor evaluation and compliance monitoring
- City and area planning, including pincode coverage
- Finance reconciliation and refunds audit
- Weekly and monthly business reviews and management reporting

## How to export data from the Admin Panel

<Steps>

<Step title="Open the relevant module" icon="arrow-right">

- Go to the required module: Orders, Leads, Vendors, Payments, SLA, or Areas.

</Step>

<Step title="Apply filters" icon="settings">

- Set the date range  
- Filter by city  
- Filter by vendor  
- Filter by status  
- Filter by device type  

Use the narrowest filters that still give the data you need to avoid oversized or noisy exports.

</Step>

<Step title="Trigger the export" icon="download">

- Click **Export** or **Download** in the module toolbar.

</Step>

<Step title="Choose file format" icon="file-text">

- Select **CSV** as the preferred format for analysis and dashboards  
- Use **Excel (XLSX)** if you need native Excel formatting  

After you confirm, the file downloads automatically to your system.

</Step>

</Steps>

## Data validation before analysis

<Callout kind="tip">

Validate every export before analysis or reporting:

- Check that the date range matches what you intend to analyze  
- Check for missing or obviously incorrect values  
- Verify key totals against the corresponding dashboard view  
- Confirm there are no duplicate rows in critical datasets  
- Cross-check critical metrics that feed management or finance reporting  

If you find any mismatch, raise it with the Tech or Data Analyst team before sharing or using the report.

</Callout>

- **Management decks** for weekly and monthly reviews  
- **Audit files** for compliance and external review  

## Data access and security rules

<Callout kind="alert">

Follow these rules whenever you export or share data:

- Only authorized users export data from the Admin Panel  
- Restrict finance-related exports to Finance and Management  
- Do not share vendor personal data outside the company  
- Keep an untouched master copy of every raw export and avoid editing it directly  
- Store export files only in approved internal drives or shared folders  
- Do not share sensitive data externally without explicit approval  

</Callout>

## Common mistakes to avoid

<Callout kind="alert">

Avoid these issues to keep reporting accurate and consistent:

- Exporting without filters and ending up with noisy or unusable data  
- Sharing outdated reports that no longer match the dashboard  
- Editing the raw export file instead of working on a copy  
- Using different date ranges across teams for the same review  
- Allowing a mismatch between dashboard metrics and exported numbers  

</Callout>
