## Adding a new tool

When you add a new IT tool to this page, capture at least:

- **Tool name** – Exact product or platform name.
- **Use case** – One-line summary of how the team uses it.
- **Example usage** – A concrete example that helps others recognize when to request this tool.

If the tool has a dedicated SOP or guide in this documentation, link to that page from the example usage cell.
