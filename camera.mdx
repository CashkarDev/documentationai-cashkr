## Manage camera buyback settings

The Camera page (**Camera Management**, route `/camera`) in **Admin Panel → Devices** controls every camera model available for buyback. It has five tabs: **Models**, **Brands**, **Classes**, **Pricing**, and **Lenses**. The first four use the shared device layout described on the [Phone](/phone) page; **Lenses** is camera-only.

Camera uses the `mobilePriceEvaluation` strategy. Camera classes use `W1`–`W4` for age, `B1`–`B4` for body, a single `P1` for functional issues, and `A1`–`A8` for accessories. Extra lenses add value instead of deducting it, so Camera is one of only two device types (with Console) where additions can raise the final price above the base price.

<Tabs>
  <Tab title="Models" icon="database">

  ### What you see

  The Models tab lists camera models, 20 per page.

  | Column | Description |
  | --- | --- |
  | Checkbox | Select rows for bulk actions |
  | Model | Image, model name, and brand • URL slug |
  | Code | Unique model code, for example `CCAM0038` |
  | Price | Base buyback price |
  | Class | Assigned condition class |
  | Actions | Row menu |

  Cameras have no variants, so there is no Variants column.

  ### Search & filters

  - **Search models…** with **Filter**, and a refresh icon.
  - **All Brands** — Canon, GoPro, Nikon, Sony.

  ### Row actions

  **Edit Model**, **View SEO**, **Duplicate**, **Delete**.

  ### Add

  <Steps>
    <Step title="Open the form" icon="plus">

    Click **Add Model** ("Add a new camera model").

    </Step>
    <Step title="Basic Info" icon="edit">

    - **Brand***
    - **Model Name*** — for example EOS R6 Mark II.
    - **Display Name** — Shown to customers. Falls back to the model name when left empty.
    - **Series (Optional)** — for example EOS, Alpha.
    - **Image** — URL or Upload.

    </Step>
    <Step title="URL & Code and SEO" icon="link">

    Generate or enter **Base URL** and **Model Code**. The camera SEO tab has only **Auto-Generate SEO** and **Image Alt Text** (no Page Title, Page Description, or H1 Heading fields).

    </Step>
    <Step title="Pricing" icon="bar-chart">

    Enter **Base Price (₹)*** and choose **Pricing Class***. The base price is the starting point before age, body, condition, accessories, and extra lenses are applied.

    </Step>
    <Step title="Save" icon="check-circle">

    Click **Create Model**.

    </Step>
  </Steps>

  <Callout kind="info">

  If you change the assigned class, the model immediately starts using the new class's values.

  </Callout>

  <Callout kind="alert">

  Deleting a model removes it from active admin use. Review any operational dependency before you delete it.

  </Callout>

  </Tab>
  <Tab title="Brands" icon="book-open">

  ### What you see

  Camera brands: **Canon**, **GoPro**, **Nikon**, and **Sony**. The table shows Brand ID, Brand Name, Device Type, Brand Link, Brand Image, and Title.

  Search, Filters, **Add New Product** (Add New Brand dialog: Brand Name, Device Type, Brand Link, Title, Description, Brand Image), and Brand Details (Edit, Delete) work as on the Phone Brands tab. Set **Device Type** to Camera.

  <Callout kind="alert">

  Do not delete a brand that still has associated camera models. Reassign or remove the models first.

  </Callout>

  </Tab>
  <Tab title="Classes" icon="shield">

  ### What you see

  The **Camera Classes** table has five classes (A–E) with ID, Class Type, Credit, Dead Price, Tier, and these codes:

  | Group | Codes | Options |
  | --- | --- | --- |
  | Warranty | `W1`–`W4` | 0–3, 3–6, 6–11, 11+ months |
  | Body | `B1`–`B4` | Flawless, Good, Average, Below Average |
  | Physical | `P1` | Has Functional Issues |
  | Accessories | `A1`–`A8` | Original Adapter, Original Battery, Original Box, Original Bag, Original Default Cable, Tripod, Bill, Original Memory Card |

  Camera does not use battery, screen, or technical fault codes.

  ### Add

  <Steps>
    <Step title="Open the form" icon="plus">

    Click **Add New Class** ("Create a new pricing model for Camera devices"). Tabs: Basic Info, Warranty, Body, Physical, Accessories.

    </Step>
    <Step title="Basic Info" icon="edit">

    Enter **Class Type***, **Tier**, **Credit**, and **Dead Price** (the payout floor).

    </Step>
    <Step title="Deductions" icon="edit">

    Fill the Warranty, Body, Physical, and Accessories values. Each field accepts a flat amount or a percentage ("e.g. 500 or 10%").

    </Step>
    <Step title="Save the class" icon="check-circle">

    Click **Create Class**.

    </Step>
  </Steps>

  Use the row menu to **Edit** or **Delete**, and **Export CSV** to download class data for audit.

  <Callout kind="alert">

  A class can be shared by many models. Review assigned models before changing values, and reassign them before deleting a class.

  </Callout>

  </Tab>
  <Tab title="Pricing" icon="bar-chart">

  ### What you see

  The Camera Pricing tab uses the shared layout: Pricing Overview, BuyBack bonus and Bulk bonus, Filters, All Brands, search, Export, and Import. Each row shows Model, Specs, Class (dropdown), Base Price (✎), Bonus, and the **3-6 Months**, **6-11 Months**, and **11+ Months** prices with % change. The row menu has **Price History**, and selected rows can be updated with **Update Price** or **Update Class**.

  ### Pricing rules

  | Group | Codes | Behavior |
  | --- | --- | --- |
  | Age | `W1`–`W4` | Deduction for the age bracket |
  | Body | `B1`–`B4` | Deduction for body condition |
  | Functional | `P1` | Deduction when the camera has functional issues |
  | Accessories | `A1`–`A8` | Deduction for each missing accessory |
  | Extra lenses | Lens add-on price | Addition from the **Lenses** tab for each included lens |

  ```text
  finalPrice = basePrice - age(W) - body(B) - functional(P) - missingAccessories(A) + extraLenses
  finalPrice = max(finalPrice, deadPrice)
  ```

  <Callout kind="info">

  Camera is one of only two device types, alongside Console, where additions can push the final price above the base price.

  </Callout>

  If a quoted price looks wrong, check three inputs first: the model's base price and class, the class values, and any lens add-ons.

  </Tab>
  <Tab title="Lenses" icon="aperture">

  ### What you see

  **Camera Lenses** lists the add-on price applied to a camera quote when the lens is included.

  | Column | Description |
  | --- | --- |
  | Brand | Lens brand, for example Canon |
  | Lens | Lens name, for example Canon 24-105MM f/4L IS USM |
  | Add-On Price | Amount added to the quote |
  | Actions | Edit and delete icons |

  The list is paginated (10 per page, with a total result count). Use **Search brand or lens…** to find a lens.

  ### Add

  <Steps>
    <Step title="Open the form" icon="plus">

    Click **Add Lens**.

    </Step>
    <Step title="Enter lens details" icon="edit">

    - **Brand*** — for example Canon, Nikon, Sony.
    - **Lens name*** — for example RF 50mm f/1.8 STM.
    - **Add-on price (₹)*** — Added to the camera quote when the seller includes this lens.

    </Step>
    <Step title="Save" icon="check-circle">

    Click **Add lens**.

    </Step>
  </Steps>

  <Callout kind="alert">

  Changing or removing a lens changes future camera quotes that include that lens.

  </Callout>

  </Tab>
</Tabs>
