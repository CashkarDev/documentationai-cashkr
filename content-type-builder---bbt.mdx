# Content Type Builder - BBT

Use the Content Type Builder in BigboldTech Strapi to design and manage the data architecture for articles and other content types.

## What it shows

The Content Type Builder provides a visual tool to define and update the fields used for articles and related content.  
You use it to control how article data is structured so it lines up with what the BigboldTech website expects.

## User flow

<Steps>
  <Step title="Open Content Type Builder" icon="folder">
    Navigate to the Content Type Builder from the Strapi sidebar to view available content types such as articles.
  </Step>
  <Step title="Select the article content type" icon="file-text">
    Choose the article content type to see its current fields and configuration.
  </Step>
  <Step title="Configure article fields" icon="settings">
    Click the configure view button to adjust which fields articles use and how they are structured.
  </Step>
</Steps>

## System logic

<Callout kind="info">
  When you change views in the Content Type Builder, the corresponding articles on the BigboldTech website update instantly.
</Callout>

The Content Type Builder connects to the website API so that any updates to the data structure are reflected directly in how article data is stored and served.
