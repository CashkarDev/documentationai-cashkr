## Overview

Coupons (**Marketing → Programs → Coupons**) let marketing and operations teams give customers an **extra amount (₹)** on top of their device quote when selling on the Cashkr website and app.

<Callout kind="info" collapsed="false">
  Use the Coupons screen to run time-bound, platform-specific, and user-segmented promotions while keeping usage and eligibility fully controlled.
</Callout>

## What the coupons screen shows

| Column           | Description                                                                                                                                                 |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Code / Title** | Coupon code (with a copy button), title, and device types it covers                                                                                         |
| **Status**       | Active, Upcoming, Expired, or Inactive                                                                                                                      |
| **Extras**       | Extra ₹ added to the order                                                                                                                                  |
| **Paid ≈**       | Approximate payout so far: completed orders × today's extra (— when nothing is paid yet)                                                                    |
| **Applies to**   | Platform (Website, App, or Website and app) and customer eligibility                                                                                        |
| **Usage**        | Uses, unique customers and devices sold, shown against the limit when one is set (for example, _2650 of 10000 uses_ / _2587 customers of 10000 · 785 sold_) |
| **Valid**        | Start → end date. Expired coupons show an **Extend** button                                                                                                 |
| **On**           | Quick on/off toggle                                                                                                                                         |

Each row also has an **Actions** menu. The **Code**, **Title**, **Extras**, **Usage** and **Valid** column headers can be clicked to sort. Use **Export CSV** to download the list.

**Bulk actions** – tick coupons (or the header checkbox to select all on the page) to open the bulk toolbar: **Switch on**, **Switch off**, **Extend**, **Delete**, and **Clear selection**.

## Status tabs

| Tab          | Shows                                      |
| ------------ | ------------------------------------------ |
| **All**      | Every coupon                               |
| **Active**   | Switched on and inside its validity window |
| **Upcoming** | Start date is in the future                |
| **Expired**  | End date has passed                        |
| **Inactive** | Switched off                               |

## Use cases

Marketing and operations teams use coupons to:

- Run limited-time, seasonal, or platform-specific promotions.
- Offer bonuses to first-time or all customers.
- Set campaign-specific or brand-aligned coupon offers.
- Control eligibility based on device value, device type, and brand.

## Filters and search

- **Search** – by code, title, description, or brand.
- **Platform** – All platforms, Website, App, Website and app.
- **Customer type** – All customers or first-time customers.
- **Devices** – filter by device type.
- **Extras ₹** – minimum and maximum extra amount.
- **Running between** – coupons valid within a date range.
- **Secret only** – lists code-only (private) coupons _instead of_ public ones, not alongside them.
- **Include generated** – shows single-use bonus codes issued automatically per order (hidden by default).
- **Sort** – Newest first, Oldest first, Ending soonest, Starting latest, Most used, Biggest extras, Code A–Z.
- **Clear filters** – resets all filters.

## Admin capabilities

<Steps>
  <Step title="Add a new coupon" icon="plus" title-type="p">
    Click **Add coupon** to open **Create New Coupon**. Fields marked \* are required. The form is split into three steps – **1 Offer**, **2 Who and what**, **3 Schedule and limits** – and a live summary line at the top shows the extra, device types, eligibility, platform, uses per customer, dates and whether it will be saved switched off. Use **Next** to move between steps.

    **How many coupons** – choose one of three modes:

    - **One coupon** – a single code.
    - **Several codes** – one set of rules, several codes, each with its own **Code**, **Title**, **Extras (₹)** and **Brand** (default **Every brand**). Use **Add code** / remove buttons to manage rows. Everything else in the form applies to every code.
    - **Generate codes** – a batch of one-use, code-only codes for a partner, downloaded as a CSV. Enter a shared **Title**, a **Code prefix** (for example `INFLU`) and **How many codes**. Each code is the prefix plus 6 letters and numbers, works once for one customer, and never shows at checkout. Code-only is always on, and uses-per-customer / user-limit fields are not shown.

    **1 · Offer**

    - **Coupon Code\*:** A unique code customers use to apply the coupon, for example `IPHONE500`.
    - **Title\*:** Descriptive title, for example "Extra ₹500 on iPhone".
    - **Description\*:** Detailed description of the offer.
    - **Platform\*:** `WEB`, `APP`, or `BOTH`.
    - **Extras (₹)\*:** Flat rupee amount added to the order.

    **2 · Who and what**

    - **Customer Eligibility\*:** All Customers or First-time Customers.
    - **Device Types\*:** Mobile, Tablet, Laptop, Mac, Watch, Camera, Console, Headphone.
    - **Brands (optional):** Select brands per chosen device type (with **Select all**). Leave empty to apply to all brands of the selected device types.
    - **Only for devices quoted between (₹):** Lowest and highest quote. The coupon shows at checkout only when the device's quote is in this range, and a requote outside it removes the extra. Leave both empty for any price.
    - **Code-only (Private):** Hides the coupon from checkout offers (see Coupon types below).

    **3 · Schedule and limits**

    - **Start Date & Time\* (IST, Kolkata):** When the coupon goes live.
    - **End Date & Time\*:** Last minute the coupon can be used.
    - **Uses per customer\*:** How many times one customer may use the coupon.
    - **User Limit Type\*:** **All Customers** (no cap) or **Custom** – then set **Customers allowed\***, the total number of different customers who may use it.
    - **Overall cap:** Cap in **Total uses** or **₹ budget**. Leave empty for no overall cap. Once reached, the coupon stops showing at checkout and a typed code is refused.
    - **Switched on:** New coupons are saved switched off. Switch on to make it live from the start time.

    If other coupons cover the same devices and dates, the form lists them with a warning so you can check the offers don't compete at checkout.

    Click **Create Coupon** on the last step. The coupon appears in the list and becomes available based on its status and validity dates.
  </Step>

  <Step title="Edit a coupon" icon="edit" title-type="p">
    Open **Actions → Edit** to update any field, such as platform, extras, device value range, usage limits, eligibility, device types, brands, dates, and status.
  </Step>

  <Step title="Duplicate a coupon" icon="copy" title-type="p">
    Open **Actions → Duplicate** to create a copy as a starting point for a new campaign.
  </Step>

  <Step title="Extend a coupon" icon="calendar-plus" title-type="p">
    Open **Actions → Extend** (or click **Extend** on an expired row) and choose **+7 days**, **+30 days**, or **Pick a date…** to push the end date out so the coupon can be used again.
  </Step>

  <Step title="Switch a coupon on or off" icon="power" title-type="p">
    Use **Actions → Switch off / Switch on** or the **On** toggle in the list. Switched-off coupons cannot be applied.
  </Step>

  <Step title="Delete a coupon" icon="trash" title-type="p">
    Open **Actions → Delete** when a coupon is no longer needed or was created by mistake. Customers can no longer apply that code.

## Coupon types

- **Normal coupon**
  - Device min value and max value are optional.
  - Brand selection is optional.
  - Coupon applies broadly across eligible devices as long as other rules (platform, eligibility, usage limits, dates) are satisfied.
- **Value-bound coupon**
  - Device min value and max value are set.
  - Coupon applies only to devices whose price falls within the configured range.
- **Brand-specific coupon**
  - Brand is selected for a specific device type, such as a particular phone brand.
  - Coupon applies only to the selected brand within the chosen device type.
- **Code-only (Private)**
  - Won't appear in checkout offers — customers must type the code manually.
  - Works only on the **device types** selected on the coupon.
  - Brands and Min/Max Device Value do **not** block a typed code, but a requote outside the Min/Max range still removes the extra.
- **Generated (single-use) codes**
  - Bonus codes issued automatically per order. Hidden from the list unless **Include generated** is turned on.

## Coupon validity rules

Coupon validation happens automatically during checkout (website and app) based on the fields you configure.

- **Platform**
  - WEB coupons are not valid in the app; APP coupons are not valid on the web; BOTH coupons are valid on both.
- **Device type**
  - If the coupon is added for a specific device type, such as laptop, it is valid only when selling that device type.
- **User Limit Type**
  - If **Custom** with Customers allowed set to 3, the coupon is applicable only for the first 3 customers.
  - If **All Customers** is selected, all eligible customers can use the coupon until other limits are reached.
- **Uses per customer**
  - If uses per customer is 2, each customer can redeem the coupon two times.
- **Min / Max Device Value (quote range)**
  - If the highest quote is 20000 and the lowest is 5000, the coupon applies only to devices quoted between 5000 and 20000.
- **Overall cap**
  - When the total-uses or ₹-budget cap is reached, the coupon stops showing at checkout and a typed code is refused.
- **Customer Eligibility**
  - First-time Customers: valid only for customers selling for the first time, up to the uses-per-customer limit.
  - All Customers: valid for both new and existing customers, subject to other limits.
- **Brand**
  - If you add a coupon for the Mobile device type and a specific brand, such as Xiaomi, the coupon applies only to that brand within Mobile.
- **Start / End Date & Time (IST)**
  - The coupon is valid only between its start and end date-time. For example, if it ends on June 26 at 11:59 pm, it is not valid from June 27 onwards.

## Where coupons are applied

- Coupons are shown and applied on both the customer website and app checkout pages (except code-only coupons, which must be typed).
- The system validates each coupon based on platform, device type, brand, customer eligibility, device value range, usage limits, and validity window before applying the extra.
