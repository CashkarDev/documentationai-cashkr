## Overview

The Settings screen ("Manage security settings") is intended for admin panel security settings.

Open it from **System → Admin → Settings** in the left sidebar (route `/settings`).

## What the screen shows

The screen currently displays a placeholder: "Settings configuration will be available here." There are no fields, filters or actions yet.

<Callout kind="info">
Integration settings (GA4, Search Console, search index) live under [Connections](/connections). Other configuration lives on module-specific screens such as Vendor Tiers, Inspection Durations, Review Refund Settings and CX Settings.
</Callout>
