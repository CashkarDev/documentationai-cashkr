## Overview

Manage how website users add and update pickup addresses used during the sell-device flow and from their Profile. This SOP keeps the address experience consistent and within the allowed limits.

## Ways to manage addresses

<Steps>

  <Step title="Update pickup address during sell-device flow" icon="arrow-right">

  Users manage pickup addresses directly while selling a device. During the sell-device flow, they can add a new pickup address or edit an existing one before confirming the order.

  </Step>

  <Step title="Manage addresses from Profile → Address" icon="settings">

  Users manage pickup addresses from the Address screen under Profile. From this screen, they can add a new address or edit an existing address without starting a new sell-device flow.

  </Step>

</Steps>

## Limits

<Callout kind="info">

Users can store a maximum of 3 pickup addresses. If a user already has 3 addresses, they must edit or delete an existing one before adding another.

</Callout>
