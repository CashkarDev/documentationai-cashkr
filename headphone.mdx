## Manage headphone devices

The Headphone page (**Headphone Management**, route `/headphone`) in **Admin Panel → Devices** controls every headphone and earbud model available for buyback. It has four tabs: **Models**, **Brands**, **Classes**, and **Pricing**, using the shared device layout described on the [Phone](/phone) page.

Headphones use the `mobilePriceEvaluation` strategy with a narrow condition set: **age** `W1`–`W4`, **physical and functional** `P1`–`P3`, and **accessories** `A1`–`A3`. There are no body, battery, screen, or technical fault codes, and no additions, so `finalPrice` is `basePrice` minus deductions, floored at `deadPrice`.

<Tabs>
  <Tab title="Models" icon="database">

  ### What you see

  The Models tab lists headphone models, 20 per page.

  | Column | Description |
  | --- | --- |
  | Checkbox | Select rows for bulk actions |
  | Model | Image, model name, and brand • URL slug |
  | Code | Unique code, for example `PODA0001` |
  | Price | Base buyback price |
  | Class | Assigned condition class |
  | Actions | Row menu |

  Headphones have no variants.

  ### Search and filters

  - **Search models…** with **Filter**, and a refresh icon.
  - **All Brands** — Apple, Bose, Google, Marshall, Nothing, OnePlus, Samsung.

  ### Row actions

  **Edit Model**, **View SEO**, **Duplicate**, **Delete**.

  ### Add

  <Steps>
    <Step title="Open the form" icon="plus">

    Click **Add Model** ("Add a new headphone model").

    </Step>
    <Step title="Basic Info" icon="edit">

    Select **Brand***, enter **Model Name*** (for example WH-1000XM5), optional **Series** (for example WH, AirPods), and **Image** (URL or Upload).

    </Step>
    <Step title="URL & Code and SEO" icon="link">

    Generate or enter **Base URL** and **Model Code**. Use **Auto-Generate SEO** or fill Page Description, H1 Heading, and Image Alt Text.

    </Step>
    <Step title="Pricing" icon="bar-chart">

    Enter **Base Price (₹)*** and choose **Pricing Class***. The class sets the `deadPrice` floor and all deduction amounts.

    </Step>
    <Step title="Save" icon="check-circle">

    Click **Create Model**.

    </Step>
  </Steps>

  <Callout kind="info">

  If you change the assigned class, new evaluations use that class's `deadPrice` and deductions immediately.

  </Callout>

  <Callout kind="alert">

  Deleting a model removes it from active assessment flows. Confirm the model is no longer required before you delete it.

  </Callout>

  </Tab>

  <Tab title="Brands" icon="book-open">

  ### What you see

  Headphone brands: **Apple**, **Bose**, **Google**, **Marshall**, **Nothing**, **OnePlus**, and **Samsung**. The table shows Brand ID, Brand Name, Device Type, Brand Link, Brand Image, and Title.

  Search, Filters, **Add New Product** (Add New Brand dialog), and Brand Details (Edit, Delete) work as on the Phone Brands tab. Set **Device Type** to Headphone.

  <Callout kind="alert">

  Delete unused brands only. If models still reference a brand, reassign those models first.

  </Callout>

  </Tab>

  <Tab title="Classes" icon="shield">

  ### What you see

  The **Headphone Classes** table has five classes (A–E) with ID, Class Type, Credit, Dead Price, Tier, and these codes:

  | Group | Codes | Options |
  | --- | --- | --- |
  | Warranty | `W1`–`W4` | 0–3 months, 3–6 months, 6 to 11 months, above 11 months |
  | Physical | `P1`–`P3` | Speaker/Mic Issue, Connectivity Issue, Physical Issue |
  | Accessories | `A1`–`A3` | Bill, Box, Charging Cable |

  <Callout kind="info">

  Headphones have no body `B`, screen `S`, battery, or technical `T` codes.

  </Callout>

  ### Add

  <Steps>
    <Step title="Open the form" icon="plus">

    Click **Add New Class** ("Create a new pricing model for Headphone devices"). Tabs: Basic Info, Warranty, Physical, Accessories.

    </Step>
    <Step title="Basic Info" icon="bar-chart">

    Enter **Class Type***, **Tier**, **Credit**, and **Dead Price** (the lowest possible final price).

    </Step>
    <Step title="Deductions" icon="settings">

    Fill `W1`–`W4`, `P1`–`P3`, and `A1`–`A3`. Each field accepts a flat amount or a percentage ("e.g. 500 or 10%").

    </Step>
    <Step title="Save the class" icon="check-circle">

    Click **Create Class**.

    </Step>
  </Steps>

  Use the row menu to **Edit** or **Delete**, and **Export CSV** to download.

  <Callout kind="alert">

  Do not delete a class that is still assigned to headphone models. Reassign those models first.

  </Callout>

  </Tab>

  <Tab title="Pricing" icon="zap">

  ### What you see

  The Headphone Pricing tab uses the shared layout: Pricing Overview, BuyBack bonus and Bulk bonus, Filters, All Brands, search, Export, and Import. Each row shows Model, Specs, Class (dropdown), Base Price (✎), Bonus, and the **3-6 Months**, **6-11 Months**, and **11+ Months** prices with % change. The row menu has **Price History**. Select rows to use **Update Price** or **Update Class**.

  ### Deduction groups

  | Group | Codes | How it works |
  | --- | --- | --- |
  | Age | `W1`–`W4` | Deduct the amount for the selected age band |
  | Physical and functional | `P1`–`P3` | Deduct the amount for the selected issue |
  | Accessories | `A1`–`A3` | Deduct the amount for each missing accessory |

  ### Formula

  ```text
  finalPrice = basePrice - age(W) - functional(P) - missingAccessories(A)
  finalPrice = max(finalPrice, deadPrice)
  ```

  The result can never be higher than `basePrice` (no additions) or lower than `deadPrice`. Separately, the BuyBack bonus, when switched on, adds a flat ₹ amount per model on top of the device price.

  </Tab>
</Tabs>

## What to review before going live

A complete headphone setup includes one brand, one model with a base price, one linked class, and verified deduction amounts for `W1`–`W4`, `P1`–`P3`, and `A1`–`A3`. Most pricing issues come from the wrong class, missing accessory deductions, or an incorrect `deadPrice`.
