## Overview

Open **Orders → Closed → Failed (No Requote)** (breadcrumb _Dashboard / Orders / Failed No Requote_). This list shows failed orders where no revised quote (requote) was shared before the order failed.

Its companion view, **Failed After Requote**, lists failed orders that had been requoted.

## What the table shows

| Column         | Description                                        |
| -------------- | -------------------------------------------------- |
| **Created At** | Date and time the order was created                |
| **Model**      | Device model                                       |
| **City**       | Pickup city                                        |
| **Type**       | Device category badge                              |
| **Status**     | Failure status badge, for example Failed By Vendor |

The list is paginated with Previous, page numbers and Next. Click a row to open the order detail drawer (see [All Orders → Order detail drawer](/all-orders#order-detail-drawer)) to read the failure details, activity timeline and credit history.

## Filters and search

- **Search orders...** box in the header.
- Click **Filters** to open: **Device Type**, **City**, **From date / To date**, and **Show orders with Test accounts**.
- Click **Apply Filters** to apply or **Reset** to clear.

<Callout kind="info" collapsed="false">
  This is a read-only list for review and reporting. Pending failure decisions (Fail Accept / Fail Reject and credit reversal) are handled in **Orders → To Be Failed**. Customers from failed orders are worked for win-back in **B2C Sales → Retention**.
</Callout>
