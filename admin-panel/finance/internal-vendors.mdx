## Overview

**Sidebar path:** Finance → Internal Vendors (`/finance/internal-vendors`)

The **Internal Vendors** screen (breadcrumb: Dashboard / Vendors) is a Finance view for orders handled by Cashkr's internal vendors — the company-run pickup agents whose completed orders become entries in [Device Purchases](/device-purchases).

<Callout kind="alert">
At the time of writing this screen shows **No Vendors Found** with the default filters. If you expect data here, try widening the filters below, and report it to the tech team if the list stays empty.
</Callout>

---

## Filters & search

| Control | Options |
| --- | --- |
| **Search** | Free-text search (top bar) |
| **Filters** button | Shows / hides the filter row |
| **Status** | Order Generated, Assigned, Out For Pickup, InspectionStarted, Completed |
| **Type** | Mobile, Laptop, Macbook, Tablet, AC, Desktop, Camera, Console, TV, Headphone, Watch, Drone |
| **City** | Filter by city |
| **Date from / Date to** | Limit results to a date range |
| **Reset** | Clear all filters |
| **Apply Filters** | Apply the selected filters |
