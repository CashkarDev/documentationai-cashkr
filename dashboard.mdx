## Overview

The **Coupon Dashboard** gives a single view of how coupons are performing across app and web.

**Sidebar path:** Dashboards → OPERATING → **Coupons** (`/coupon-dashboard`). Coupons themselves are created and edited under **Marketing → Coupons**.

<Callout kind="info">
Use this dashboard to monitor overall coupon health, track campaign impact, and understand how discounts influence orders and abandoned cart recovery.
</Callout>

The header shows:

- **Title** — `Coupon Dashboard`, with the selected range underneath
- **Refresh** — reloads all KPIs, charts and tables
- **Date range selector** — for example `Sep 12, 2026 – Oct 12, 2026` (defaults to the last 30 days)

## How to use

<Steps>
<Step title="Choose the analysis period" icon="calendar" title-type="p">
Set the date range in the top-right selector to match the campaign or review period, such as week-on-week or month-on-month.
</Step>
<Step title="Refresh the dashboard" icon="refresh-ccw" title-type="p">
Click **Refresh** if you need the latest numbers for the selected period.
</Step>
<Step title="Scan the catalogue and period metrics" icon="bar-chart" title-type="p">
Review the all-time **Coupon Catalogue** strip, the **Selected Period** cards and the **Abandoned Cart Recovery** panel.
</Step>
<Step title="Drill into top coupons" icon="list" title-type="p">
Use the **Top Coupons** table to find the best-performing codes and any coupon close to its usage limit.
</Step>
</Steps>

## Filters

The dashboard uses one global filter:

- **Date range** — controls the Selected Period cards, abandoned cart recovery, Device Breakdown, Daily Usage Trend and the Top Coupons table.

<Callout kind="alert">
The **Coupon Catalogue** strip and the Coupon Status, Platform Breakdown, Accessibility and Discount Distribution charts are **all-time** and do not change with the date range.
</Callout>

## Key metrics

### Coupon catalogue (all-time)

- **Campaign Coupons** — coupons someone authored, with an *Active* count ring.
- **Auto-Generated Bonuses** — one-off rows created per abandoned-cart token.
- **All-Time Redemptions** — every coupon ever applied to a lead.
- **First-Customer Campaigns** — campaigns limited to a customer's first order, shown against all campaigns.

### Selected period

- **Redemptions** — coupons applied to leads, with % change vs the previous period.
- **New Campaigns** — campaigns created in the period.
- **Unique Users** — customers redeeming.
- **Device Value Paid** — final price of completed coupon orders.
- **Completed Orders** — coupon orders completed.
- **Discount Given** — discount on this period's redemptions.
- **Avg Discount/Use** — discount given ÷ redemptions.
- **Conversion** — share of this period's redemptions whose order has completed since.

Device value paid and completed orders count orders that reached Completed inside the period, based on the status log rather than the order date.

Compare **Redemptions**, **Device Value Paid** and **Discount Given** to judge whether campaigns are efficient or too costly for the results they generate.

### Abandoned Cart Recovery

Tokens issued in the period and how many have been redeemed since:

- **Recovery %** ring
- **Tokens Issued**
- **Redeemed**
- **Not Redeemed**
- **Bonus Redemptions** — bonus coupons used in the period and their value

Use this panel to decide whether to adjust incentive levels, validity windows or follow-up messaging for abandoned cart campaigns.

## Charts and breakdowns

| Chart | Scope | Shows |
| --- | --- | --- |
| **Coupon Status** | All-time | Campaign coupons by status: Active, Expired. |
| **Platform Breakdown** | All-time | Campaign coupons by platform: APP, WEB, BOTH. |
| **Device Breakdown** | Period | Redemptions by device (for example Mobile). |
| **Accessibility** | All-time | Campaign coupons by who can use them: ALL, FirstCustomer. |
| **Discount Distribution** | All-time | Campaign coupons by discount band, for example ₹0–50, ₹101–200, ₹201–500. |
| **Daily Usage Trend** | Period | Redemptions per day (IST). |

Watch the share of **Expired** vs **Active** coupons so you do not run out of valid offers during live campaigns, and use **Daily Usage Trend** to see how fast a new coupon gains traction.

## Top coupons table

Most-redeemed coupons in the selected period. Total uses and discount both come from redemption records.

| Column | Meaning |
| --- | --- |
| **#** | Rank. |
| **Code** | Coupon code used by customers. |
| **Title** | Coupon name. |
| **Discount** | Discount value. |
| **Platform** | App, Web or Both. |
| **Period Uses** | Redemptions in the selected period. |
| **Discount Given** | Discount given in the period. |
| **All-Time Uses** | Total redemptions. |
| **Max Uses** | Usage limit for the coupon. |
| **Status** | Current coupon status. |

Use this table to spot top performers, coupons close to their **Max Uses**, and underperforming coupons that need better promotion.
