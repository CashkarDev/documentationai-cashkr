## Overview

Use the Tablet page (**Tablet Management**, route `/tablet`) under Admin Panel → Devices to manage all tablet models available for buyback. The layout mirrors the [Phone](/phone) page, with four tabs: **Models**, **Brands**, **Classes**, and **Pricing**. Changes update tablet options and prices on the customer app and website.

<Callout kind="info">
  Tablet differs from Phone in only a few places: there is no SIM Type tab or eSIM deduction in classes, and no SIM options in the model form. Everything else, including bulk actions, SEO preview, and pricing tools, works as described on the Phone page.
</Callout>

## Tabs

<Tabs>
  <Tab title="Models">
    ### What you see

    The tablet model list (20 per page, "Showing 1 to 20 of N models") has the same columns as Phone: checkbox, expand chevron (variants), **Model** (image, name with variant, brand • series), **Code** (for example `TAPP100051`), **Price**, **Class**, **Variants**, and **Actions**.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774767147437-g2snqxhvjms-tablet-model-section.tablet model section?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="834" alt="Tablet models tab showing a list of configured tablet models with columns for code, price, class, variants, and actions." />

    ### Search and filters

    - **Search models…** with the **Filter** button.
    - **All Brands** dropdown — Apple, Honor, Huawei, Lenovo, Motorola, Nokia, Oneplus, Oppo, Poco, Realme, Samsung, Xiaomi.
    - Refresh icon.

    ### Row and bulk actions

    - Row menu: **Edit Model**, **Add Variant**, **View SEO**, **Duplicate**, **Delete**.
    - Expanded variant rows have their own edit and delete icons.
    - Selecting rows shows **Update Class**, **Regenerate SEO**, and **Clear Selection**.

    ### Add model

    <Steps>
      <Step title="Open the form" icon="plus">
        Click **Add Model**. The **Add New Model** dialog ("Add a new tablet model") has tabs Basic Info, URL & Code, SEO, and Pricing.
      </Step>
      <Step title="Basic Info" icon="edit">
        **Brand***, **Model Name*** (for example iPad Air 5), **Series (Optional)** (for example Air, Pro, Mini), **Image** (URL or Upload), **Storage (GB)**, and **RAM (GB)**.
      </Step>
      <Step title="URL & Code" icon="link">
        **Base URL** and **Model Code**, each with **Generate**. Codes follow `[Device prefix][Brand][Sequence 6]`.
      </Step>
      <Step title="SEO" icon="bar-chart">
        **Auto-Generate SEO**, or enter Page Title, Page Description, H1 Heading, Image Alt Text, Variant Title, and Variant Description.
      </Step>
      <Step title="Pricing" icon="settings">
        **Base Price (₹)***, **Pricing Class***, and **Bulk Add Variants** (storage/RAM rows with a variant price).
      </Step>
      <Step title="Save" icon="check-circle">
        Click **Create Model**. The tablet becomes available for selection and price evaluation.
      </Step>
    </Steps>

    <Callout kind="alert">
      Deleting a tablet model removes it from the Tablet catalog and from the customer app and website.
    </Callout>
  </Tab>

  <Tab title="Brands">
    ### What you see

    **Brand Management** (Dashboard / Tablet) lists tablet brands with **Brand ID**, **Brand Name**, **Device Type** (Tablet), **Brand Link**, **Brand Image**, and **Title**.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774767169745-dh6tuh7xziv-tablet-brands-section.tablet brands section?q=85&fm=auto&auto=compress%2Cformat" width="1917" height="828" alt="Tablet brands tab listing available tablet brands like Apple and Samsung." />

    Brand data powers the brand dropdown during tablet model creation and brand labels on the customer app and website.

    ### Search, add, edit, delete

    The brand search, **Filters**, **Add New Product** (Add New Brand dialog), and the **Brand Details** view (with Edit and Delete) work exactly as on the Phone Brands tab. Set **Device Type** to Tablet when adding a brand.

    <Callout kind="alert">
      Review and update or remove dependent models before deleting a tablet brand.
    </Callout>
  </Tab>

  <Tab title="Classes">
    ### What you see

    **Tablet Classes** table with ID, Class Type (for example IPAD A–E, Lenovo A, Huawei A), Credit, Dead Price, Tier, and the condition code columns.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774767201637-6fwhf2sg1gg-tablet-classes-section.tablet classes section?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="827" alt="Tablet classes tab listing tablet condition classes with condition code columns." />

    | Group | Codes | Options |
    | --- | --- | --- |
    | Warranty | W1–W4 | 0–3, 3–6, 6–11, 11+ months |
    | Battery | B1–B4 | Flawless, Good, Average, Below Average |
    | Screen | S1–S5 | Flawless, Scratches, Cracked, Faulty, Not Usable |
    | Physical | P1–P4 | Back Glass Broken, Physical Button, Display Changed, Bend Device |
    | Technical | T1–T15 | Same 15 technical problems as Phone |
    | Accessories | A1–A4 | Bill, Box, Charger, Other Accessories |

    ### Add class

    <Steps>
      <Step title="Open the form" icon="plus">
        Click **Add New Class** ("Create a new pricing model for Tablet devices").
      </Step>
      <Step title="Fill the tabs" icon="edit">
        Basic Info (Class Type*, Tier 1–3, Credit, Dead Price), then Warranty, Battery, Screen, Physical, Technical, and Accessories. Each deduction accepts a flat amount or a percentage ("e.g. 500 or 10%").
      </Step>
      <Step title="Save" icon="check-circle">
        Click **Create Class**.
      </Step>
    </Steps>

    The row menu offers **Edit** and **Delete**. **Export CSV** downloads the class table.

    <Callout kind="alert">
      Before deleting a tablet class that is still assigned to models, reassign those models to another class.
    </Callout>
  </Tab>

  <Tab title="Pricing">
    ### What you see

    The same Pricing layout as Phone: the shared **Pricing Overview**, the **BuyBack bonus** switch and **Bulk bonus**, **Filters** (Storage, RAM, Class, Bonus, Price Range), **All Brands**, search, **Export** and **Import**.

    Table columns: Model, Specs, Class (dropdown), Base Price (✎), Bonus, **3-6 Months**, **6-11 Months**, **11+ Months** (each with % change), and a row menu with **Price History**.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774767283958-cibenph4nh-tablet-pricing-section.tablet pricing section?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="826" alt="Tablet pricing tab showing tablet models with assigned classes and age-bracket prices." />

    ### Edit pricing

    - Edit the base price inline (✎) or change the row's class. The bracket prices recalculate from the class's warranty deductions.
    - Select rows to use **Update Price** (fixed or percentage) or **Update Class** in bulk.

    <Callout kind="alert">
      Tablet pricing changes apply instantly to all new tablet evaluations. Review prices carefully before saving, especially for bulk updates.
    </Callout>

    New tablet models appear here automatically after you add them in the Models tab. To remove a tablet from pricing, delete or retire the model.
  </Tab>
</Tabs>
