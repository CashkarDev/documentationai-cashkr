## Overview

Use the Phone page (**Phone Management**, route `/phone`) in Admin Panel → Devices to manage every mobile phone model available for buyback on the Cashkr platform. Configure models and their storage/RAM variants, brands, condition-based classes, and age-based pricing in one place. Changes you make here update the customer app and website, affecting model search, device selection, and displayed buyback prices.

The page has four tabs: **Models**, **Brands**, **Classes**, and **Pricing**. Tablet, Mac, Watch, Laptop, Console, Camera, and Headphone pages use the same layout, with the per-device differences described on their own pages.

## Tabs

<Tabs>
  <Tab title="Models">
    ### What you see

    The Models tab lists every phone model, 20 per page, with a footer such as "Showing 1 to 20 of N models" and **Previous** / **Next** pagination.

    | Column | Description |
    | --- | --- |
    | Checkbox | Select one or more models for bulk actions. |
    | Expand (chevron) | Expands the row to show each storage/RAM variant with its own code, price, class, and edit/delete icons. |
    | Model | Device image, model name with the variant in brackets (for example `(256GB)`), and brand • series. |
    | Code | Unique model code, for example `PAPP100012`. |
    | Price | Base buyback price of the shown variant. |
    | Class | Assigned pricing class, for example Class 16. |
    | Variants | Number of variants under the model. |
    | Actions | Row menu (⋯). |

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774766753199-adj9bxn49pe-phone-models-section.phone models section?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="825" alt="Phone models tab showing list of models with codes, prices, classes, variants, and actions" />

    ### Search & filters

    - **Search models…** — Type a model name and press Enter or click **Filter** to apply.
    - **All Brands** dropdown — Limit the list to one brand (Apple, Asus, Google, Honor, Huawei, Infinix, iQOO, Motorola, Nokia, Nothing, OnePlus, Oppo, Poco, Realme, Samsung, Tecno, Vivo, Xiaomi, and others).
    - **Refresh** icon — Reload the list.

    ### Row actions

    The ⋯ menu on a model row offers:

    | Action | What it does |
    | --- | --- |
    | Edit Model | Opens the Edit Model dialog (same tabs as Add Model). |
    | Add Variant | Opens **Add Variant** for that model: Storage (GB), RAM (GB), Price (₹), Class, Variant Title, Variant Description, and a **Generate SEO** button. |
    | View SEO | Opens **SEO Preview**: an SEO score, a Google search preview, a field analysis (page title 30–60 chars, description 120–160, H1 20–70, alt text 10–125), recommendations, and the current SEO values and URL. |
    | Duplicate | Copies the model as a starting point for a new one. |
    | Delete | Removes the model. |

    Each expanded variant row has its own **edit** icon (opens Edit Model for that variant) and **delete** icon.

    ### Bulk actions

    Selecting one or more checkboxes shows a bar with "N model selected" and:

    - **Update Class** — Assign a class to all selected models.
    - **Regenerate SEO** — Rebuild SEO fields for the selected models.
    - **Clear Selection**.

    ### Add

    <Steps>
      <Step title="Open the Add Model form" icon="plus">
        Click **Add Model** (top right). The **Add New Model** dialog ("Add a new mobile model") has four tabs: Basic Info, URL & Code, SEO, and Pricing.
      </Step>

      <Step title="Basic Info" icon="edit">
        - **Brand*** — Select from the phone brands.
        - **Model Name*** — For example `iPhone 15 Pro`.
        - **Series (Optional)** — For example Pro, Ultra, Plus.
        - **Image** — Paste an image URL or click **Upload**.
        - **Storage (GB)** and **RAM (GB)** — Leave empty if not applicable.
      </Step>

      <Step title="URL & Code" icon="link">
        - **Base URL** — Slug for the model page (for example `cashkr.com/sell-old-mobile-phones/<model-slug>`), with a **Generate** button.
        - **Model Code** — With a **Generate** button. Auto-generated as `[Device prefix][Brand][Sequence 6]`; leave it unless you need a specific code.
      </Step>

      <Step title="SEO" icon="bar-chart">
        Use **Auto-Generate SEO** or fill in manually:

        - **Page Title** (character counter, optimal 30–60)
        - **Page Description** (counter, optimal 120–160)
        - **H1 Heading**
        - **Image Alt Text**
        - **Variant Title** and **Variant Description**
      </Step>

      <Step title="Pricing" icon="settings">
        - **Base Price (₹)***
        - **Pricing Class*** — Classes are listed as "Class N - Brand Tier" (for example Class 16 - Apple E). After a class is chosen, **Class Details** show its Dead Price, Credit, Tier, and Type.
        - **Bulk Add Variants** — "Add multiple configurations (storage/RAM) instantly". Each **Add Variant** row takes Storage (GB), RAM (GB), and Variant Price (₹).
        - **SIM options** (shown in Edit Model) — Tick every SIM version the model is sold in: Physical SIM only (SIM1), SIM tray + eSIM (SIM2), eSIM only (no SIM tray) (SIM3). Ticking both a tray version and eSIM-only makes the customer flow ask whether their unit has a SIM tray; a "no" applies the class's eSIM deduction. A single tick is only recorded on the order. Applies to all variants of the model.
      </Step>

      <Step title="Save" icon="check-circle">
        Click **Create Model** (or **Update Model** when editing). **Cancel** closes without saving.
      </Step>
    </Steps>

    <Callout kind="alert">
      Deleting a model removes it from the customer app and website. Customers will no longer see or select this model for buyback.
    </Callout>
  </Tab>

  <Tab title="Brands">

    The Brands tab shows **Brand Management** with a breadcrumb (Dashboard / Phone) and a table of phone brands (Apple, Asus, Google, Honor, Huawei, Infinix, IQOO, Motorola, Nokia, Nothing, OnePlus, Oppo, Poco, Realme, Samsung, Tecno, Vivo, Xiaomi, and others).

    | Column | Description |
    | --- | --- |
    | Brand ID | Numeric ID. |
    | Brand Name | Display name. |
    | Device Type | Mobile for this page. |
    | Brand Link | URL slug, for example `apple`. |
    | Brand Image | Logo. |
    | Title | SEO title, for example "Sell Old Apple Mobile Phone for best price at CashKr". |

    Columns are sortable.

    ### Search & filters

    - **Search mobile brands…** search box.
    - **Filters** button opens a panel with **Reset** and **Apply Filters**.

    ### Brand details

    Clicking a brand row opens **Brand Details** with the logo, device type, Title, Description, Brand Link, created / last updated times, and **Visit Website**, **Edit**, and **Delete** buttons.

    ### Add

    <Steps>
      <Step title="Open the form" icon="plus">
        Click **Add New Product**. The **Add New Brand** dialog opens.
      </Step>

      <Step title="Enter brand details" icon="edit">
        - **Brand Name***
        - **Device Type*** — Mobile, Tablet, Laptop, TV, Watch, Headphone, Console, Desktop, Camera, Mac, Drone, or AC.
        - **Brand Link***
        - **Title** — SEO or display title.
        - **Description** — Brand description.
        - **Brand Image** — Drag and drop or **Browse Files** (JPEG, PNG or GIF, max 5MB), or enter an image URL manually. A **Brand Details** preview shows the name, device type, and image URL.
      </Step>

      <Step title="Save the brand" icon="check-circle">
        Click **Create Brand**. The brand becomes available in the Brand dropdown when creating or editing models.
      </Step>
    </Steps>

    <Callout kind="alert">
      Do not delete a brand that still has associated models. Remove or reassign linked models first. Deletion affects brand options on the customer app and website.
    </Callout>
  </Tab>

  <Tab title="Classes">
    ### What you see

    **Device Class Management** ("Configure pricing models for different device conditions") shows a **Mobile Classes** table. Each class is a set of condition deductions applied to every model assigned to it.

    Columns: **ID**, **Class Type** (for example Apple A, Samsung C, OnePlus B), **Credit**, **Dead Price**, **Tier**, then one column per condition code, and a row menu.

    <Image src="https://blob-cdn.documentation.ai/org-39cfb2dd-42b8-41e4-a035-d7210b5839fe/doc-1aebdaec-9f45-458a-9429-3234288b0c70/1774766818707-bqytnj7eg4m-phone-class-section.phone class section?q=85&fm=auto&auto=compress%2Cformat" width="1919" height="830" alt="Phone classes tab listing tier, credits, dead price, and condition parameters for each class" />

    ### Phone condition codes

    | Group | Codes | Options |
    | --- | --- | --- |
    | Warranty | W1–W4 | 0–3 months, 3–6 months, 6–11 months, 11+ months |
    | Battery | B1–B4 | Flawless, Good, Average, Below Average |
    | Screen | S1–S5 | Flawless Screen, Scratches on Screen, Cracked Screen, Faulty Screen, Screen Not Usable |
    | Physical | P1–P4 | Back Glass Broken, Physical Button, Display Changed, Bend Device |
    | Technical | T1–T15 | Restart, Sensors, Front Camera, Back Camera, Microphone, Speaker, Face ID, Fingerprint, Bluetooth, Wifi, Network, Vibration, Charging, Battery/Service, Motherboard problems |
    | Accessories | A1–A4 | Bill, Box, Charger, Other Accessories |
    | SIM type | eSIM | eSIM only (no SIM tray) |

    Each deduction field accepts a flat amount or a percentage (placeholder "e.g. 500 or 10%").

    ### Search & filters

    - **Search classes… (press Enter)** and a refresh button.
    - Sortable Class Type, Credit, Dead Price, and Tier columns.

    ### Add

    <Steps>
      <Step title="Open the Add New Class dialog" icon="plus">
        Click **Add New Class**. The dialog ("Create a new pricing model for Mobile devices") has tabs: Basic Info, Warranty, Battery, Screen, Physical, Technical, Accessories, and SIM Type.
      </Step>

      <Step title="Basic Info" icon="edit">
        - **Class Type*** — for example Premium, Standard, Basic.
        - **Tier** — Tier level (1–3).
        - **Credit** — Credit value.
        - **Dead Price** — Price for a dead device.

        A summary lists all deduction codes. If every critical deduction is zero, the dialog warns: "All critical deductions are zero! … The device will always return the base price regardless of its condition."
      </Step>

      <Step title="Condition tabs" icon="settings">
        Enter the deduction for each option on the Warranty, Battery, Screen, Physical, Technical, Accessories, and SIM Type tabs (codes as in the table above).
      </Step>

      <Step title="Save the class" icon="check-circle">
        Click **Create Class**. Devices assigned to this class use its deductions on the customer app and website.
      </Step>
    </Steps>

    ### Edit and delete

    Open the row menu (**Actions**) and choose **Edit** or **Delete**.

    <Callout kind="alert">
      Deleting or editing a class affects all models that rely on it. Reassign classes for active models first to prevent incorrect or missing prices.
    </Callout>

    ### Export

    **Export CSV** downloads the class table for review or audit.
  </Tab>

  <Tab title="Pricing">
    ### What you see

    The Pricing tab is shared across device categories at the top and scoped to phones in the table.

    - **Pricing Overview** (collapsible, shows the total device count) — Cards for **Total Devices** (with a per-category breakdown), **Price Coverage** (how many devices need pricing), **Class Coverage**, and **Price Changes** (today and last 7 days), plus an **Attention Required** panel listing devices without a price.
    - **BuyBack bonus** — An On/Off switch: "All categories. Flat ₹ per model on top of the device price. Stays on until switched off." The **Bulk bonus** button sets or removes a bonus for the selected models or for all matching models.
    - **Filters**, an **All Brands** dropdown, and **Search by model name… (press Enter)**.
    - Product count, **Export**, and **Import** buttons.

    | Column | Description |
    | --- | --- |
    | Checkbox / expand | Select rows; expand to see variant rows (tagged **Variant**). |
    | Model | Model name and brand. |
    | Specs | Storage and RAM. |
    | Class | Class dropdown for the row. |
    | Base Price | 0–3 month price with a ✎ inline-edit icon. |
    | Bonus | Model bonus in ₹, or **+ Add**. |
    | 3-6 Months / 6-11 Months / 11+ Months | Calculated price for each age bracket with the % drop from base. |
    | ⋯ | Row menu with **Price History**. |

    The bracket prices are derived from the base price and the class's warranty deductions. Changing the base price or class recalculates them.

    ### Advanced Filters

    The **Filters** button opens Advanced Filters: **Storage (GB)**, **RAM (GB)**, **Class**, **Bonus**, and **Price Range (₹)** (min–max).

    ### Bulk updates

    Selecting rows shows "N selected", **Select all N**, and:

    - **Update Price** — **Bulk Price Update**: Update Type (Fixed Amount or Percentage), Operation (for example Increase by), and Amount, then **Apply**.
    - **Update Class** — **Bulk Class Update**: choose a New Class. "Changing the class will recalculate all age-range prices for the selected devices."

    ### Price History

    **Price History** shows the current price and a change log with old → new price, date and time, who changed it, the % change, and the source (for example manual).

    <Callout kind="alert">
      Pricing changes apply to new evaluations immediately. A model without a price does not show a buyback value to customers.
    </Callout>
  </Tab>
