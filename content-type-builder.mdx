## Overview

Content Type Builder lets you design and manage the data structure for articles and other content types, and control how article fields appear in the Strapi admin.

## What it shows

- Tool to design and manage data architecture for articles and other content types.

## Common tasks

Use Content Type Builder to adjust how the Articles content type is structured and presented in the admin.

<Steps>

<Step title="Open Content Type Builder">

Navigate to the Content Type Builder from the sidebar.

</Step>

<Step title="Access the Articles content type view">

Open the Articles content type and click the configure view button.

</Step>

<Step title="Configure article fields and views">

Configure fields and views as needed for how article data is entered and displayed.

</Step>

</Steps>

## System logic

Changes to views update the articles on the website instantly.

## Connections

- Connected to the website's API for data structure reflection.
