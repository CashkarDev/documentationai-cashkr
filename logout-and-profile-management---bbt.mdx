## Logout and profile management overview

Manage your own BigboldTech Strapi account from the profile menu, including logging out securely and updating your basic profile details.

**What it shows**

- Logout option and profile settings for team members.

**System logic**

- Logout clears the current session token.
- Profile updates apply only to the logged-in user and are saved to the user database.

**Connections**

- Uses Strapi authentication for session creation and session clearing.
- Writes profile changes (name and email) to the linked user database record.

## User flow

Use the profile menu at the bottom of the interface to log out or update your profile details.

<Steps>
  <Step title="Open the profile menu" icon="user">
    Click the profile icon at the bottom of the Strapi interface to open the profile menu.
  </Step>

  <Step title="Log out of Strapi" icon="log-out">
    Select <kbd>Logout</kbd> from the menu to end your current session and return to the login screen.
  </Step>

  <Step title="Open profile settings" icon="settings">
    To edit your account, select <kbd>Profile</kbd> from the same menu to open your profile details.
  </Step>

  <Step title="Edit name and email" icon="edit">
    Update your profile fields, such as your display name and email address, in the profile form.
  </Step>

  <Step title="Save changes" icon="check">
    Click the save action in the profile screen to store your updated details in the user database.
  </Step>
</Steps>

<Callout kind="info">

Logging out clears the current session token from Strapi, ending your authenticated session. After logout, you must sign in again to access any protected content or profile settings.

</Callout>

<Callout kind="alert">

Profile changes apply only to your own account but can affect how the system contacts you and how your name appears in the interface. Make sure the email and name you save are correct before confirming your edits.

</Callout>

## UI elements

These interface elements support logout and profile management for team members:

- **Profile menu:** Opens when you click the profile icon at the bottom of the screen and contains account options.
- **Logout:** Ends your current Strapi session and returns you to the login screen.
- **Profile (edit and save):** Opens your profile details, where you can change your name and email, then save to update your user record.
