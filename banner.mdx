## Overview

The Banners section (**Marketing → Acquisition → Banners**) manages the promotional banners customers see on the Cashkr website (desktop and mobile) and in the mobile app. Banners can be shown in **Grid view** (image cards) or **List view**.

<Callout kind="info" collapsed="false">
  Use Banners to control which offers and visuals appear on the website and app, when they run, and in what order.
</Callout>

## What the banner list shows

Each banner card/row includes:

- **Banner image** – the creative shown to customers.
- **Status badge** – Live, Scheduled, Expired, or Inactive.
- **Name** – internal banner name (for example, _App Bonus Offer_).
- **Platform** – Website (desktop), Website (mobile), or Mobile app.
- **Schedule** – start → end date/time in IST, or "From …" when there is no end date.
- **Order** – display position for that platform.

## Status tabs

| Tab           | Shows                                        |
| ------------- | -------------------------------------------- |
| **All**       | Every banner                                 |
| **Live**      | Switched on and inside its start/end window  |
| **Scheduled** | Switched on, with a start time in the future |
| **Expired**   | End time has passed                          |
| **Inactive**  | Switched off (including drafts)              |

## Filters and search options

- **Search by name**.
- **Platform** – All platforms, Website (desktop), Website (mobile), Mobile app.
- **Dates** – show banners running between two dates.
- **Sort** – Newest first, Oldest first, Recently updated, Display order, Starts soonest, Ends soonest, Name A–Z.
- **View toggle** – Grid view or List view.

## Typical use cases

Marketing or operations teams use banners to:

- Push time-bound or permanent offers on the website and app.
- Upload platform-specific creatives (desktop, mobile web, app).
- Schedule campaigns in advance and let them expire automatically.
- Control the display order of banners per platform.

## Admin workflow

<Steps>
  <Step title="Add banners (Unified Form)" icon="plus" title-type="p">
    Click **Add banner** and use the **Unified Form** tab to create one banner across one or more platforms.

    - **Name** (required) – for example, _Diwali Special Offer 2026_.
    - **Starts (IST)** – leave empty to start as soon as the banner is switched on.
    - **Ends (IST)** – leave empty to run indefinitely until switched off.
    - **Active Status** – off by default; the banner is saved as a **draft** (switched off and not visible to users). Turn it on to publish on save.
    - **Platform Placements & Images** – tick each platform and upload the right-sized image:
      - Website (desktop) – 16:9
      - Website (mobile) – 16:9
      - Mobile app – App frame
    - Images must be **JPEG, PNG, or WebP, max 5 MB**.
    - Use **Interactive Preview** to check how the banner will look.

    Click **Create banner(s)**. One banner is created for each ticked platform.
  </Step>

  <Step title="Add banners in bulk (Bulk Drop)" icon="upload" title-type="p">
    Use the **Bulk Drop** tab to upload many banners at once.

    - Set **Shared Defaults For All Dropped Banners**: Platform, **Active on save**, Starts (IST), Ends (IST).
    - Drag and drop **1 to 20 images** (or browse files). Each image becomes a banner row.
    - Review the rows and click **Add N banners**.
  </Step>

  <Step title="Update banner" icon="edit" title-type="p">
    Open **⋮ Actions → Edit banner** to change the name, start/end dates, active status, or image. Each saved banner belongs to a single platform.
  </Step>

  <Step title="Other banner actions" icon="more-horizontal" title-type="p">
    From the **⋮ Actions** menu on a banner:

    - **Copy to another platform** – reuse the banner on a different placement.
    - **Duplicate** – create a copy of the banner.
    - **Switch on / Switch off** – publish or hide the banner.
    - **Delete** – remove the banner.
  </Step>

  <Step title="Bulk actions" icon="check-square" title-type="p">
    Tick banners (or **Select all on this page**) to open the bulk toolbar: **Switch on**, **Switch off**, **Change dates**, **Change page**, **Duplicate**, and **Delete**. Use **Clear selection** to cancel.
  </Step>

  <Step title="Reorder banners" icon="list-ordered" title-type="p">
    Click **Reorder** to set the order customers see.

    - Choose the **Platform** (for example, Website (desktop)).
    - Drag rows in **Live & Scheduled Banners** to adjust the sequence.
    - Click **Save order**.

    Only live banners show to customers in real time.
  </Step>
</Steps>

<Callout kind="tip" collapsed="false">
  All banner dates and times are in IST (Asia/Kolkata).
</Callout>

## Connections and placement

Banners connect directly to:

- **Customer website and app** – banners render on Website (desktop), Website (mobile), and the Mobile app.
- **Display order** – the order set in **Reorder** controls the sequence on each platform.
